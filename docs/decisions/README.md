# decisions — บันทึกการตัดสินใจของ repo

บันทึกเฉพาะการเลือกที่**สวนทางกับค่าเริ่มที่ใครก็คาด** — คนมาใหม่อ่านแล้วไม่ต้องถามว่า "ทำไมไม่ทำแบบปกติ" · การเลือกที่ตรงกับค่าเริ่มอยู่แล้วไม่ต้องเขียน

## กติกา

- 1 ไฟล์ต่อ 1 การตัดสินใจ ชื่อ `YYYY-MM-DD-<เรื่อง>.md` ตัวพิมพ์เล็กคั่นด้วย `-`
- **ไม่แก้ไฟล์เก่า** — เปลี่ยนใจแล้วเขียนไฟล์ใหม่ที่ลิงก์กลับไปหาไฟล์เดิม แล้วเปลี่ยนสถานะไฟล์เดิมเป็น `superseded` หรือ `revised` พร้อมลิงก์ไปไฟล์ใหม่ (แก้ได้แค่บรรทัดสถานะ)
- ข้ออ้างทุกข้อติดป้ายตาม `plugins/superuser/skills/superuser/references/evidence.md` · ตัวเลขที่ไม่ได้วัดเองใส่ `(ยังไม่ได้ตรวจ)`
- การตัดสินใจเองระหว่างทำงานของ agent ลง `.claude/superuser/CONTEXT.md` (skill `decision-log`) ไม่ลงที่นี่ · ที่นี่คือเรื่องที่อยู่ยาวและมีคนถามทีหลังว่าทำไม

## รูปแบบ

```markdown
# <เรื่อง> · <วันที่>

สถานะ: accepted | superseded (→ <ไฟล์ใหม่>) | revised (→ <ไฟล์ใหม่>)

## ตัดสินใจ
<เลือกอะไร 1–3 บรรทัด>

## ทำไมไม่ใช้ทางที่ใครก็คาด
<ทางปกติคืออะไร · ติดตรงไหน · หลักฐาน>

## ขอบเขต
<ใช้กับอะไร · ไม่ใช้กับอะไร>

## ทบทวนเมื่อ
<เหตุการณ์หรือวันที่ที่ควรกลับมาดูว่ายังถูกอยู่ไหม>
```
