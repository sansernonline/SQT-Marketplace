# แถบล่างของ Claude Code (status line)

[← superuser](README.md)

แถบล่างของ superuser บอกว่าตอนนี้ใช้ model อะไร โควตาเหลือเท่าไร และมีงานเบื้องหลังอะไรค้างอยู่ ทุก 1 นาทีจะจดค่าเหล่านี้ลง log ไว้ทำ dashboard ได้

```
Opus 5.5 (high) · Quanton · main* · บริบท 34% · 5 ชม. 7% รีเซ็ต 03:50 · สัปดาห์ 96% รีเซ็ต 03:00
เบื้องหลัง 1 งาน: ตรวจเอกสาร CONNECT (12 นาที)
```

## แต่ละช่องคืออะไร

| ช่อง | ความหมาย |
|---|---|
| `Opus 5.5 (high)` | model ที่ใช้ และระดับความคิด (effort) |
| `Quanton` | โฟลเดอร์ที่เปิดอยู่ |
| `main*` | branch ของ git · `*` = มีไฟล์ที่แก้แล้วยังไม่ commit |
| `บริบท 34%` | แชตนี้ใช้ความจำไปเท่าไร · ใกล้ 100% แล้ว Claude Code จะย่อแชตเอง |
| `5 ชม. 7% รีเซ็ต 03:50` | โควตารอบ 5 ชั่วโมงที่ใช้ไป และเวลาที่จะรีเซ็ต |
| `สัปดาห์ 96% รีเซ็ต 03:00` | โควตารายสัปดาห์ |
| บรรทัด `เบื้องหลัง` | งานที่ส่งให้ลูกทีมทำเบื้องหลังแล้วยังไม่ส่งผลกลับ พร้อมเวลาที่ผ่านไป · ไม่มีงานค้างจะไม่แสดงบรรทัดนี้ |

ตัวเลข 70–89% ขึ้นสีเหลือง ตั้งแต่ 90% ขึ้นสีแดง ช่องโควตาจะขึ้นเฉพาะแผน Pro, Max หรือ Ultra และหลังได้คำตอบแรกของแชต

งานเบื้องหลังบอกเป็น % ไม่ได้ เพราะทั้ง Claude Code และตัวลูกทีมไม่ได้บอกว่างานเหลืออีกเท่าไร จึงแสดงเวลาที่ผ่านไปแทน ข้อมูลส่วนนี้อ่านจาก `runs.jsonl` ที่ hook ของ superuser จด เพราะ Claude Code ไม่ได้ส่งมาให้แถบล่าง (ตรวจกับ [เอกสาร status line](https://code.claude.com/docs/en/statusline) 2026-11-28)

## ติดตั้ง

1. คัดลอก `plugins/superuser/skills/superuser/templates/statusline.mjs` ไปไว้ที่ `~/.claude/superuser/statusline.mjs` ตัวเรียกนี้หาสคริปต์ในรุ่นใหม่สุดของ superuser เอง อัปเดตปลั๊กอินแล้วไม่ต้องแก้อะไร
2. ใส่ใน `~/.claude/settings.json`

```json
"statusLine": {
  "type": "command",
  "command": "node \"C:/Users/<ชื่อผู้ใช้>/.claude/superuser/statusline.mjs\"",
  "refreshInterval": 60
}
```

`refreshInterval: 60` ให้แถบล่างอัปเดตเองทุก 1 นาที ไม่อย่างนั้นแถบจะอัปเดตเฉพาะตอนมีข้อความใหม่ และค้างอยู่ระหว่างรองานเบื้องหลัง

3. เปิด Claude Code ใหม่

## log สำหรับทำ dashboard

ไฟล์ `<ทีม>/log/<วันที่>/statusline.jsonl` เก็บบรรทัดละ 1 snapshot แต่ละแชตจดไม่เกินนาทีละ 1 บรรทัด `<ทีม>` คือ `.claude/superuser/` ของโปรเจกต์ ถ้าโปรเจกต์ไม่มีโฟลเดอร์นี้ จะใช้ `~/.claude/superuser/` แทน ถ้าอยากปิด ให้ใส่ `{"modules": {"log": false}}` ใน `config.json` ของทีม

| ช่อง | ค่า |
|---|---|
| `ts` | เวลาที่จด (ISO, UTC) |
| `session` | 8 ตัวแรกของรหัสแชต ใช้ชื่อเดียวกับใน `runs.jsonl` |
| `project` · `branch` | โฟลเดอร์โปรเจกต์ · branch ของ git |
| `model` · `effort` | รหัส model · ระดับความคิด |
| `context_pct` | % ความจำแชตที่ใช้ไป |
| `five_hour` · `week` | `{ used, reset }` % ที่ใช้ และเวลารีเซ็ต (ISO) · ไม่มีข้อมูลเป็น `null` |
| `cost_usd` | ค่าใช้จ่ายที่ Claude Code คำนวณจากราคามาตรฐาน ไม่ใช่ยอดที่ถูกเก็บจริงของแผนรายเดือน |
| `duration_min` | แชตเปิดมาแล้วกี่นาที |
| `lines_added` · `lines_removed` | จำนวนบรรทัดโค้ดที่เพิ่มและลบในแชตนี้ |
| `workers` | งานเบื้องหลังที่ค้าง `[{ name, role, model, minutes }]` |

นอกจากนี้ตัวเรียกยังจดโควตาลง `~/.claude/superuser/quota/<บัญชี>.json` ให้ด่านโควตาของ hook และ `plan.mjs` ใช้ หน้าที่นี้แต่ก่อนเป็นของ `quota.mjs record`

## ช่องที่ตั้งใจไม่ใส่

ดูจาก status line ที่คนอื่นทำ เช่น [ccstatusline](https://github.com/sirmalloc/ccstatusline) และ [claude-powerline](https://unpkg.com/@owloops/claude-powerline@1.26.0/README.md) แล้ว มีบางช่องที่ไม่ใส่ในแถบล่าง

- ค่าใช้จ่าย ($): ผู้ใช้แผนรายเดือนไม่ได้จ่ายตามตัวเลขนี้ เห็นแล้วจะเข้าใจผิด จึงเก็บไว้ใน log อย่างเดียว
- เวลาแชตและจำนวนบรรทัดที่แก้: มีประโยชน์ตอนดูย้อนหลังมากกว่าตอนกำลังทำงาน จึงเก็บไว้ใน log อย่างเดียว
- ตัวอักษร powerline: ต้องลงฟอนต์พิเศษ ถ้า terminal ไม่มีฟอนต์จะเห็นเป็นกล่องสี่เหลี่ยม
