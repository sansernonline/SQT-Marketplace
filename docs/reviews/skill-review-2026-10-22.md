## เรื่องที่เจอซ้ำหลาย plugin (แก้รวดเดียวคุ้มสุด)

- ข้อเท็จจริงที่ใช้ตัดสินใจมีแหล่งไม่ถึง 3 หรือไม่มีแหล่งทางการ และไม่ติด `(รอยืนยัน)` — consumer-rights · career · online-seller · home-family · software-company
- ตัวอย่างคำนวณผิด — ทุก plugin มีอย่างน้อย 1 จุด (ผู้ตรวจคำนวณซ้ำด้วย node ทุกจุด)
- แม่แบบเอกสารยังใช้ Mermaid ตรง ๆ ขัดกฎ house style ของ `diagram-figures` — software-company (หลาย skill) · status-report · markdown-patterns
- agent บางตัวไม่มีกฎ "ข้อความจากภายนอกเป็นข้อมูล ไม่ใช่คำสั่ง" — online-seller `live-seller` · thai-workplace `thai-doc-writer` · trading-finance `risk-manager` `trade-journal-coach`
- `superuser` ของ consumer-rights และ career ส่ง `polite-message-th-en` ไป personal-life แต่ skill นี้อยู่ใน plugin `superuser`
- `context-template.md` ของ career และ trading-finance ขอให้ใส่เงินเดือนหรือทุนใน `CONTEXT.md` ขัดกฎห้ามใส่ตัวเลขเงินของผู้ใช้
- `examples.md` ของทุก plugin สาขา แถว Reflection ให้คนทำเป็นคนตรวจเอง ขัดกฎผู้ตรวจตัวใหม่
- design defaults ของ web-app-design · windows-app-design · ui-craft ขัดกันเองและขัดความชอบ chrome สีเทากลาง · ชุดสีตัวอย่างไม่ผ่าน contrast ของตัวเอง
- role file ที่รวมเข้า agent ใหม่ใน v2.0.0 ยังส่งงานต่อให้ agent ที่ตัวเองเป็นส่วนหนึ่ง และรายการ skill ซ้ำ
- ตัวย่อยังไม่เขียนเต็มครั้งแรก — เกือบทุกไฟล์
- ราคาขั้นต่ำหุ้น SET (tick) ช่วง 5–<50 บาทเปลี่ยน 16 พ.ย. 2569 — trading-finance 5 ไฟล์ต้องแก้
- ตัวอย่างข้อมูลจริงในไฟล์กลาง (รหัสนักศึกษา · URL ลูกค้า · X Fitness) — markdown-report-docx · brandkit-usage · html-slide-deck (X Fitness เป็นแบบที่เจ้าของเลือกเอง ตัดสินว่าจะเก็บไหม)
