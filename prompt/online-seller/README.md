# prompt / online-seller — ชุดคำสั่งพร้อมวางสำหรับร้านค้าออนไลน์

ใช้คู่กับ plugin `online-seller` · 1 ไฟล์ = 1 ช่วงงานของร้าน · ในไฟล์มีหลายฉบับ แต่ละฉบับทำงาน 1 ชิ้น

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์ร้าน** (1 ร้าน 1 โฟลเดอร์)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วางรูป แชต รายงานยอดขาย ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้าย `ทำข้อ N`
4. ของที่ย้อนไม่ได้ (ลงขายจริง · ส่งข้อความ · คืนเงิน · เปลี่ยนราคา · ส่งอุทธรณ์) agent เตรียมไว้ใน "รออนุมัติ" ให้คุณกดเอง

## รายการไฟล์

| ไฟล์ | ใช้เมื่อ | ฉบับในไฟล์ |
|---|---|---|
| `prompt-open-shop.md` | เปิดร้าน ลงสินค้า แก้หน้าสินค้า ตรวจก่อนใช้ | 1 เทียบขนส่ง · 2 ลงสินค้าใหม่ · **3 คนเข้าดูแต่ไม่ซื้อ** · **4 สินค้าถูกระงับ / โดนเตือน** · 5 ตรวจงานร้านก่อนใช้ |
| `prompt-stock-and-profit.md` | ดูกำไร สต็อก ปิดยอด ภาษี | 1 ไม่เหลือกำไร / จัดโปร · 2 สต็อกหลายแพลตฟอร์ม · **3 ระบายของค้างสต็อก** · **4 ปิดยอดรายเดือน** · 5 ภาษีคนขายออนไลน์ |
| `prompt-campaign-live.md` | ใกล้วันแคมเปญ หรือจะไลฟ์ | **1 เตรียมวันแคมเปญใหญ่** · 2 เตรียมไลฟ์ · **3 สรุปหลังไลฟ์** |
| `prompt-customers.md` | ลูกค้าทักมา หรือมีปัญหาหลังส่งของ | 1 ตอบลูกค้า คืนของ รีวิว · **2 พัสดุหาย เสียหาย ข้อพิพาท** |

ตัวหนา = ฉบับที่เพิ่มใหม่ · ตรวจก่อนใช้มีที่เดียวคือ `prompt-open-shop.md` ฉบับ 5
