# prompt ของ health-wellness — ชุดคำสั่งพร้อมวาง จัดตามสถานการณ์สุขภาพ

1 ไฟล์ต่อ 1 กลุ่มสถานการณ์ · ในไฟล์มีหลาย prompt (เรียกว่า "ฉบับ") แต่ละฉบับทำงาน 1 ชิ้น · ทุกฉบับจัดระเบียบเท่านั้น ไม่วินิจฉัย ไม่บอกขนาดยา · ฉุกเฉินโทร 1669

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์สุขภาพของคนนั้น** (เช่น `health/me/` · `health/mom/`)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · ไม่รู้ปล่อยว่างได้
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้าย เช่น `ทำข้อ 2`

## รายการไฟล์

| ไฟล์ | ใช้เมื่อ | ฉบับในไฟล์ |
|---|---|---|
| `prompt-checkup.md` | ถึงรอบตรวจสุขภาพ · ผลตรวจออกมาแล้ว · ไม่แน่ใจเรื่องสิทธิรักษา | 1 ตรวจสุขภาพประจำปี · **2 ผลตรวจผิดปกติ ติดตามจนตรวจซ้ำ** · **3 ใช้สิทธิรักษาไหน ไปโรงพยาบาลไหน** |
| `prompt-doctor-and-meds.md` | ป่วยต้องไปหาหมอ · ได้ยามา · มีโรคประจำตัว | 1 เตรียม / สรุปหาหมอ · 2 ตารางยา · **3 โรคประจำตัว บันทึกค่าที่วัดเองไปให้หมอ** · 4 ตรวจก่อนใช้ |
| `prompt-family-care.md` | ดูแลสุขภาพพ่อแม่หรือคนในบ้าน | **1 พ่อแม่หลายโรค ยาหลายโรงพยาบาล** · **2 ก่อนผ่าตัด / นอนโรงพยาบาล และหลังกลับบ้าน** · **3 การ์ดสุขภาพฉุกเฉิน** |
| `prompt-lifestyle.md` | อยากเริ่มดูแลตัวเอง · นอนไม่ดี · ทำงานหนัก | 1 ออกกำลังกาย / การนอน · **2 นั่งทำงานทั้งวัน ปวดคอ บ่า หลัง** · **3 เครียดจนนอนไม่หลับ เตรียมไปคุยกับผู้เชี่ยวชาญ** |

ตรวจก่อนใช้มีที่เดียวคือ `prompt-doctor-and-meds.md` ฉบับ 4 · ไฟล์อื่นชี้มาที่นี่

## เลือกจากสถานการณ์

| สถานการณ์ | ใช้ |
|---|---|
| ถึงรอบตรวจสุขภาพประจำปี ไม่รู้ว่าควรตรวจอะไร | `prompt-checkup.md` ฉบับ 1 |
| ไม่รู้ว่าตัวเองมีสิทธิอะไร ควรไปโรงพยาบาลไหน | `prompt-checkup.md` ฉบับ 3 |
| โรงพยาบาลเสนอแพ็กเกจตรวจ ไม่รู้ว่าคุ้มไหม | `prompt-checkup.md` ฉบับ 3 → 1 |
| ผลตรวจออกมามีตัวแดง | `prompt-checkup.md` ฉบับ 1 (บันทึกผล) → 2 → `prompt-doctor-and-meds.md` ฉบับ 1 |
| ไม่สบายมาหลายวัน จะไปหาหมอ กลัวพูดไม่ครบ | `prompt-doctor-and-meds.md` ฉบับ 1 |
| หาหมอกลับมาแล้ว ได้ยาใหม่หลายตัว | `prompt-doctor-and-meds.md` ฉบับ 1 (หลังพบ) → 2 → 4 |
| เป็นความดันหรือเบาหวาน หมอให้วัดเองที่บ้าน | `prompt-doctor-and-meds.md` ฉบับ 3 → 1 ก่อนนัดหน้า |
| ยาหมดก่อนถึงนัดบ่อย ๆ | `prompt-doctor-and-meds.md` ฉบับ 2 |
| พ่อแม่ไปหลายโรงพยาบาล ยาเต็มถุง ไม่รู้ว่าซ้ำไหม | `prompt-family-care.md` ฉบับ 1 → `prompt-doctor-and-meds.md` ฉบับ 4 |
| จ้างผู้ดูแลหรือฝากญาติดูแลพ่อแม่ ต้องส่งต่อเรื่องยา | `prompt-family-care.md` ฉบับ 1 → 3 |
| พ่อแม่มีนัดผ่าตัด | `prompt-family-care.md` ฉบับ 2 (ก่อนเข้า) |
| พ่อแม่ออกจากโรงพยาบาล ได้ยากลับบ้าน | `prompt-family-care.md` ฉบับ 2 (หลังกลับบ้าน) → 1 |
| อยากมีข้อมูลสุขภาพทุกคนในบ้านไว้ใช้ตอนฉุกเฉิน | `prompt-family-care.md` ฉบับ 3 |
| อยากเริ่มออกกำลังกาย ไม่เคยทำมาก่อน | `prompt-lifestyle.md` ฉบับ 1 |
| นั่งทำงานทั้งวัน ปวดคอ บ่า หลัง | `prompt-lifestyle.md` ฉบับ 2 → 1 |
| นอนไม่หลับ ตื่นมาไม่สดชื่น | `prompt-lifestyle.md` ฉบับ 1 (ส่วนการนอน) → `prompt-doctor-and-meds.md` ฉบับ 1 |
| เครียดจากงานหรือเรื่องบ้าน จนนอนไม่หลับ | `prompt-lifestyle.md` ฉบับ 3 → `prompt-doctor-and-meds.md` ฉบับ 1 |
| ทำตารางยาหรือสรุปหาหมอเองแล้ว อยากให้ช่วยตรวจ | `prompt-doctor-and-meds.md` ฉบับ 4 |

สถานการณ์ใหม่ที่ประกอบจากฉบับที่มีอยู่ได้ → เพิ่มแถวในตารางนี้ ไม่ต้องสร้างไฟล์ใหม่
