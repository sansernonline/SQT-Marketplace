# prompt-checkup — ตรวจสุขภาพประจำปี ติดตามผล และสิทธิรักษา

ใช้คู่กับ plugin `health-wellness` · ไฟล์นี้รวม prompt 3 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์สุขภาพ** (แยกโฟลเดอร์ต่อคน เช่น `health/me/` · `health/mom/`)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · ไม่รู้ปล่อยว่างได้
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 2`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `health-wellness` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · ตารางสถานะตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบ 5 รอบยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 2

**ขอบเขต (ห้ามข้าม):** งานจัดระเบียบเท่านั้น · **ไม่วินิจฉัย ไม่แปลผลตรวจว่าเป็นโรคอะไร ไม่บอกขนาดยา ไม่แนะนำให้หยุดหรือเปลี่ยนยา** · ตารางยาคัดจากฉลากหรือใบสั่งแพทย์ตรงตัว · อาการฉุกเฉิน (เจ็บหน้าอก หายใจไม่ออก ปากเบี้ยว แขนขาอ่อนแรง หมดสติ) → บอกให้โทร 1669 ทันที แล้วหยุดงานอื่น · สิทธิการรักษา (ประกันสังคม · บัตรทอง · ข้าราชการ) ตรวจกับแหล่งทางการรอบนี้ ติดวันที่ · การจองโรงพยาบาล ซื้อแพ็กเกจ อยู่ใน "รออนุมัติ"

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด ไม่กำหนด → ใช้ชื่อในตาราง

| # | งาน | playbook | ได้ไฟล์ |
|---|---|---|---|
| 1 | รอบตรวจสุขภาพประจำปี | `checkup-cycle` | `checkup/<ปี>-plan.md` · `checkup/results.csv` |
| 2 | ผลตรวจมีค่าผิดปกติ ติดตามจนถึงนัดตรวจซ้ำ | `checkup-cycle` (ขั้น 5) | `checkup/follow-up-<ชื่อค่า>.md` |
| 3 | ใช้สิทธิรักษาไหน ไปโรงพยาบาลไหน | `checkup-cycle` (ขั้น 1 และ 3) + ประกอบเพิ่ม | `rights.md` |

ใช้ต่อกัน: วางแผนตรวจ → 1 · ผลออกมามีค่าที่แล็บทำเครื่องหมาย → 2 → เตรียมคำถามไปหาหมอ `prompt-doctor-and-meds.md` ฉบับ 1 · ไม่แน่ใจว่าสิทธิครอบคลุมอะไร → 3 ก่อน 1 · ตรวจก่อนใช้ → `prompt-doctor-and-meds.md` ฉบับ 4

## 1. รอบตรวจสุขภาพประจำปี

playbook `checkup-cycle` · agent `health-organizer` · skill `annual-checkup`
**ผลลัพธ์:** `checkup/<ปี>-plan.md` (แผน) · `checkup/results.csv` (ผลย้อนหลังเทียบปีต่อปี) · **รออนุมัติ:** จองคิว ซื้อแพ็กเกจ

### ข้อมูล (ผู้ใช้กรอก)

- ทำให้ใคร / อายุ / เพศ:
- สิทธิที่มี (ประกันสังคม · บัตรทอง · ข้าราชการ · ประกันเอกชน):
- ประวัติครอบครัวที่แพทย์เคยบอกให้เฝ้าระวัง (ไม่บังคับ):
- งานนี้คือ (วางแผน / บันทึกผล / ดูแนวโน้ม):
- ผลตรวจเดิม (path PDF หรือรูป):
- แพ็กเกจโรงพยาบาลที่กำลังดู (ลิงก์):

### ต้องมีในผลงาน

1. รายการตรวจตามช่วงอายุและเพศจากแหล่งทางการ · ข้อไหนสิทธิครอบคลุมฟรี (ตรวจกับแหล่งทางการ ติด `จากแหล่ง` และวันที่)
2. เทียบแพ็กเกจกับรายการที่ควรตรวจ: ซ้ำกับสิทธิฟรี · ขาด · เกินจำเป็น
3. ถ้าบันทึกผล: คัดค่าลงตารางตรงตัวพร้อมหน่วยและช่วงอ้างอิงของแล็บ · **ไม่แปลผล** · ค่าที่แล็บทำเครื่องหมายผิดปกติ → ใส่ในรายการ "ถามแพทย์"
4. ตารางแนวโน้มปีต่อปี (ค่า · ปี · หน่วย) โดยไม่ตีความ

## 2. ผลตรวจมีค่าผิดปกติ ติดตามจนถึงนัดตรวจซ้ำ

playbook `checkup-cycle` (ขั้น 5 คัดค่าลงตาราง) · agent `health-organizer` · skill `annual-checkup` · `doctor-visit-prep`
**ผลลัพธ์:** `checkup/follow-up-<ชื่อค่า>.md` หน้าเดียวต่อ 1 ค่า · แถวใหม่ใน `checkup/results.csv` · **รออนุมัติ:** จองนัดตรวจซ้ำ ซื้อแพ็กเกจตรวจเพิ่ม

### ข้อมูล (ผู้ใช้กรอก)

- ทำให้ใคร:
- ใบผลตรวจที่มีค่าถูกทำเครื่องหมาย (path PDF หรือรูป):
- ผลปีก่อน ๆ ของค่าเดียวกัน (ถ้ามี):
- แพทย์หรือพยาบาลบอกอะไรแล้วบ้าง (เล่าตามที่ได้ยิน · ยังไม่ได้คุย → เว้นว่าง):
- วันนัดตรวจซ้ำ (ถ้ามี):

### ต้องมีในผลงาน

1. ค่าที่ถูกทำเครื่องหมาย คัดตรงตัว: ชื่อค่า · ผล · หน่วย · ช่วงอ้างอิงของแล็บ · วันที่ตรวจ · **ไม่แปลผล ไม่บอกว่าเป็นโรคอะไร**
2. ตารางค่าเดียวกันย้อนหลังทุกปีที่มี (ไม่ตีความแนวโน้ม)
3. สิ่งที่แพทย์สั่งให้ทำ ตามคำผู้ใช้ตรงตัว · ยังไม่ได้คุยกับแพทย์ → เขียนว่า "ยังไม่ได้รับคำแนะนำจากแพทย์" แล้วเสนอให้นัดพบ
4. คำถาม 3–5 ข้อถึงแพทย์เรื่องค่านี้ (ต้องตรวจซ้ำเมื่อไร · ต้องงดอาหารก่อนตรวจไหม · ต้องเปลี่ยนอะไรระหว่างรอ)
5. วันตรวจซ้ำ และวันที่ควรเริ่มจองคิว

### กฎเฉพาะฉบับนี้

- ห้ามเขียนคำแนะนำเรื่องอาหารหรือยาเพื่อแก้ค่านั้นเอง · ถ้าแพทย์ให้คำแนะนำไว้ ให้คัดตามคำผู้ใช้เท่านั้น

## 3. ใช้สิทธิรักษาไหน ไปโรงพยาบาลไหน

playbook `checkup-cycle` (ขั้น 1 ดูสิทธิ · ขั้น 3 เทียบกับของฟรี) ส่วนที่เกินจากนั้นประกอบเพิ่มตาม `playbook-template` (skill `superuser` หัวข้อ 2) · agent `health-organizer` · skill `annual-checkup`
**ผลลัพธ์:** `rights.md` (สิทธิที่มี · โรงพยาบาลตามสิทธิ · ใช้อย่างไรในแต่ละกรณี) · **รออนุมัติ:** ย้ายสิทธิหรือเปลี่ยนโรงพยาบาลตามสิทธิ ซื้อประกันสุขภาพเพิ่ม

### ข้อมูล (ผู้ใช้กรอก)

- ทำให้ใคร / อายุ / ทำงานแบบไหน (ลูกจ้างบริษัท · อาชีพอิสระ · ข้าราชการหรือครอบครัว · ไม่ได้ทำงาน):
- สิทธิที่คิดว่ามี และโรงพยาบาลตามสิทธิตอนนี้ (ไม่รู้ปล่อยว่าง):
- ประกันสุขภาพเอกชนหรือประกันกลุ่มจากที่ทำงาน (path กรมธรรม์ ถ้ามี):
- เรื่องที่สงสัย (ย้ายบ้านแล้วโรงพยาบาลไกล · ฉุกเฉินไปโรงพยาบาลเอกชนได้ไหม · ใช้สิทธิไหนก่อน):

### ต้องมีในผลงาน

1. สิทธิที่คนนี้มีจริง พร้อมแหล่งทางการและวันที่ตรวจ · ตรวจไม่ได้ → `ยังไม่ได้ตรวจ` และบอกช่องทางตรวจเอง
2. ตารางเดียว: กรณี (ป่วยทั่วไป · ตรวจประจำปี · ฉุกเฉิน · นอนโรงพยาบาล · ทำฟัน) · ใช้สิทธิไหน · ไปที่ไหน · ต้องมีเอกสารอะไร
3. เงื่อนไขที่คนมักพลาด เช่น ใบส่งตัว กรณีฉุกเฉินที่ใช้สิทธินอกโรงพยาบาลตามสิทธิได้ — เขียนเฉพาะที่ตรวจจากแหล่งทางการรอบนี้
4. ถ้าอยากเปลี่ยนโรงพยาบาลตามสิทธิ: ขั้นตอน · ช่องทาง · ช่วงเวลาที่เปลี่ยนได้ (ตรวจรอบนี้ ติดวันที่)
5. ประกันเอกชนที่มี: คัดความคุ้มครองจากกรมธรรม์ตรงตัว · บอกว่าเรื่องไหนซ้ำกับสิทธิรัฐ · **ไม่แนะนำให้ซื้อหรือยกเลิกประกัน**

### กฎเฉพาะฉบับนี้

- ตัวเลขวงเงิน จำนวนครั้ง ค่าห้อง ห้ามเขียนจากความจำ → ตรวจกับแหล่งทางการหรือกรมธรรม์รอบนี้ ติดวันที่ หรือ `(รอยืนยัน)`
