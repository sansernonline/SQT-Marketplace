# prompt-lifestyle — ออกกำลังกาย การนอน นั่งทำงานนาน และความเครียด

ใช้คู่กับ plugin `health-wellness` · ไฟล์นี้รวม prompt 3 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์สุขภาพ** (แยกโฟลเดอร์ต่อคน เช่น `health/me/` · `health/mom/`)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · ไม่รู้ปล่อยว่างได้
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 2`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `health-wellness` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · ตารางสถานะตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**ขอบเขต (ห้ามข้าม):** งานจัดระเบียบเท่านั้น · **ไม่วินิจฉัย ไม่แปลผลตรวจว่าเป็นโรคอะไร ไม่บอกขนาดยา ไม่แนะนำให้หยุดหรือเปลี่ยนยา** · ตารางยาคัดจากฉลากหรือใบสั่งแพทย์ตรงตัว · อาการฉุกเฉิน (เจ็บหน้าอก หายใจไม่ออก ปากเบี้ยว แขนขาอ่อนแรง หมดสติ) → บอกให้โทร 1669 ทันที แล้วหยุดงานอื่น · สิทธิการรักษา (ประกันสังคม · บัตรทอง · ข้าราชการ) ตรวจกับแหล่งทางการรอบนี้ ติดวันที่ · การจองโรงพยาบาล ซื้อแพ็กเกจ อยู่ใน "รออนุมัติ"

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด ไม่กำหนด → ใช้ชื่อในตาราง

## 1. เริ่มออกกำลังกาย หรือบันทึกการนอน

playbook `habit-tracking` · agent `health-organizer` · skill `exercise-plan` · `sleep-log`
**ผลลัพธ์:** `exercise-plan.md` และ/หรือ `sleep-log.csv` (บันทึก 2 สัปดาห์)

### ข้อมูล (ผู้ใช้กรอก)

- งานนี้คือ (ออกกำลังกาย / การนอน / ทั้งสอง):
- ตอนนี้ออกกำลังกายแค่ไหน / นอนกี่โมงตื่นกี่โมง:
- เวลาที่ว่างต่อวัน / อุปกรณ์หรือสถานที่ที่มี:
- อายุ / โรคประจำตัว (หัวใจ · ความดัน · เบาหวาน · ตั้งครรภ์ · อื่น ๆ):
- ข้อจำกัดที่แพทย์เคยบอก (ไม่บังคับ):
- เป้า (เดินได้ 30 นาที · นอนให้พอ · เตรียมข้อมูลไปพบแพทย์เรื่องการนอน):

### ต้องมีในผลงาน

1. ออกกำลังกาย: ผลคำถามคัดกรองจาก `exercise-plan` ก่อน · ข้อไหนตอบว่า "ใช่" → แนะนำพบแพทย์ก่อน และไม่ทำแผนออกกำลังกาย · ผ่านคัดกรองแล้วจึงทำแผน 4 สัปดาห์เริ่มจากระดับปัจจุบัน เทียบเป้ารายสัปดาห์ของ WHO (World Health Organization) · ช่วงพักระหว่างนั่งทำงาน · สัญญาณที่ควรหยุดและพบแพทย์ก่อน
2. การนอน: แบบบันทึก 2 สัปดาห์ · เช็กลิสต์สุขอนามัยการนอน · สิ่งที่ต้องนำไปให้แพทย์ดู
3. วิธีตรวจว่าทำได้ตามแผน (ตาราง ติ๊กรายวัน)

## 2. นั่งทำงานทั้งวัน ปวดคอ บ่า หลัง

playbook `habit-tracking` (ขั้น 1 คำถามคัดกรอง · ขั้น 2 จุดทบทวน 2 สัปดาห์ · ขั้น 3 แผนเริ่มต้น + reviewer ตรวจ) · agent `health-organizer` · skill `exercise-plan`
**ผลลัพธ์:** `desk-break-plan.md` (ช่วงพักระหว่างวัน · ท่าขยับระดับเบา · จัดโต๊ะ · ตารางติ๊ก 2 สัปดาห์)

### ข้อมูล (ผู้ใช้กรอก)

- นั่งทำงานวันละกี่ชั่วโมง / ทำที่ออฟฟิศหรือที่บ้าน:
- ปวดตรงไหน เป็นมานานเท่าไร ช่วงไหนของวัน:
- มีชา อ่อนแรง หรือปวดร้าวลงแขนขาไหม:
- โต๊ะ เก้าอี้ จอ ที่ใช้อยู่ (รูปได้):
- ข้อจำกัดที่แพทย์เคยบอก (ไม่บังคับ):

### ต้องมีในผลงาน

1. ผลคำถามคัดกรองจาก `exercise-plan` · ข้อไหนตอบว่า "ใช่" หรือมีชา อ่อนแรง ปวดร้าว → แนะนำพบแพทย์ก่อน แล้วทำเฉพาะส่วนจัดโต๊ะและช่วงพัก
2. ช่วงพักระหว่างวันตาม `exercise-plan` ใส่เวลาจริงของผู้ใช้ (เช่น ทุกต้นชั่วโมง) · ท่าขยับระดับเบาที่ skill มี
3. จัดโต๊ะ เก้าอี้ จอ จากรูปหรือคำเล่า: 3 จุดที่แก้ได้ทันทีโดยไม่ต้องซื้อของ
4. ตารางติ๊กรายวัน 2 สัปดาห์ · จุดทบทวนดูจากบันทึกจริง

### กฎเฉพาะฉบับนี้

- ไม่บอกว่าเป็นโรคหรือกลุ่มอาการอะไร · ไม่แนะนำยาแก้ปวดหรือยานวด
- ของที่ต้องซื้อ (เก้าอี้ ขาตั้งจอ) อยู่ใน "รออนุมัติ"

## 3. เครียดจนนอนไม่หลับ เตรียมไปคุยกับผู้เชี่ยวชาญ

playbook `habit-tracking` (ขั้น 2 จุดทบทวน · ขั้น 4 ไดอารีการนอน 2 สัปดาห์ + reviewer ตรวจ) แล้วทำการ์ดไปพบตาม skill `doctor-visit-prep` · agent `health-organizer` · skill `sleep-log` · `doctor-visit-prep`
**ผลลัพธ์:** `sleep-log.csv` (มีคอลัมน์ระดับความเครียดที่ผู้ใช้ให้คะแนนเอง) · `visits/<ปี-เดือน-วัน>-stress.md` การ์ดหน้าเดียวไปพบแพทย์หรือนักจิตวิทยา · **รออนุมัติ:** นัดแพทย์ จิตแพทย์ หรือนักจิตวิทยา

### ข้อมูล (ผู้ใช้กรอก)

- นอนกี่โมง ตื่นกี่โมง ตื่นกลางดึกบ่อยไหม:
- เป็นมานานเท่าไร / มีเรื่องอะไรเกิดขึ้นช่วงนั้น (เล่าเท่าที่สบายใจ):
- กระทบชีวิตแค่ไหน (งาน · กิน · คนรอบตัว):
- ยาและอาหารเสริมที่ใช้อยู่ (รวมยานอนหลับที่ซื้อเอง):
- อยากไปคุยกับใคร (แพทย์ทั่วไป · จิตแพทย์ · นักจิตวิทยา · ยังไม่แน่ใจ) / สิทธิรักษาที่มี:

### ต้องมีในผลงาน

1. ไดอารีการนอน 2 สัปดาห์ตาม `sleep-log` เพิ่มคอลัมน์ "เครียดวันนี้ 0–10" และ "เรื่องที่คิดก่อนนอน"
2. การ์ดหน้าเดียว: ไทม์ไลน์อาการตามคำผู้ใช้ · สรุปไดอารี (ไม่ตีความ) · ยาที่ใช้อยู่ · คำถาม 3–5 ข้อ
3. ช่องทางพบผู้เชี่ยวชาญตามสิทธิที่มี — ตรวจกับแหล่งทางการรอบนี้ ติดวันที่ · ตรวจไม่ได้ → `ยังไม่ตรวจ`
4. เบอร์สายด่วนสุขภาพจิต — ตรวจกับเว็บกรมสุขภาพจิตเป็น**ขั้นแรกของฉบับนี้** ก่อนรับเรื่องจากผู้ใช้ ติดวันที่ · ห้ามเขียนเบอร์จากความจำ

### กฎเฉพาะฉบับนี้

- **ไม่ประเมินว่าเป็นโรคซึมเศร้าหรือโรควิตกกังวล** · ไม่ใช้แบบคัดกรองให้คะแนนแล้วสรุปผล
- ผู้ใช้พูดถึงการทำร้ายตัวเองหรือไม่อยากมีชีวิตอยู่ → หยุดงานอื่น บอกให้โทร 1669 หรือสายด่วนสุขภาพจิต (เบอร์ที่ตรวจไว้แล้วในข้อ 4 · ยังตรวจไม่ได้ → 1669 อย่างเดียว) ทันที และให้อยู่กับคนที่ไว้ใจ
- ยานอนหลับที่ซื้อเอง → ใส่ในคำถามถึงแพทย์ ไม่แนะนำให้กินต่อหรือหยุด
