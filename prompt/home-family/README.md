# prompt ของ home-family — ชุดคำสั่งพร้อมวาง จัดตามสถานการณ์ในบ้านและครอบครัว

1 ไฟล์ต่อ 1 กลุ่มสถานการณ์ · ในไฟล์มีหลาย prompt (เรียกว่า "ฉบับ") แต่ละฉบับทำงาน 1 ชิ้น · การจ่ายเงิน จ้างช่าง ต่อภาษี อยู่ใน "รออนุมัติ" เสมอ

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์บ้าน** (โฟลเดอร์เดียวใช้ได้ทุกไฟล์)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · รูปบิล ใบเสนอราคา เอกสารรถ วางไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้าย เช่น `ทำข้อ 2`

## รายการไฟล์

| ไฟล์ | ใช้เมื่อ | ฉบับในไฟล์ |
|---|---|---|
| `prompt-house.md` | ค่าบ้าน ซ่อมบ้าน ย้ายบ้าน หน้าฝน | 1 บิลค่าบ้าน · 2 ดูแลบ้าน เทียบราคาช่าง · **3 ย้ายเข้าบ้านหรือคอนโดใหม่** · **4 ฝนหนัก น้ำท่วม** · 5 ตรวจก่อนใช้ |
| `prompt-vehicle.md` | มีรถยนต์หรือมอเตอร์ไซค์ | 1 ภาษี พ.ร.บ. (พระราชบัญญัติคุ้มครองผู้ประสบภัยจากรถ) ตรวจสภาพ ประกัน เข้าศูนย์ · **2 อุบัติเหตุ เคลม** · **3 ซื้อรถมือสอง / โอนรถ** |
| `prompt-family-week.md` | จัดสัปดาห์ของบ้าน · ช่วงพิเศษ | 1 แผนสัปดาห์ครอบครัว · **2 เตรียมเปิดเทอม** · **3 ไม่อยู่บ้านหลายวัน ฝากลูก พ่อแม่ สัตว์เลี้ยง** |
| `prompt-care.md` | ดูแลผู้สูงอายุ ลูก สัตว์เลี้ยง | 1 เริ่มดูแลผู้สูงอายุ / ลูก / สัตว์เลี้ยง · **2 พ่อแม่ออกจากโรงพยาบาล ดูแลที่บ้าน** · **3 สัตว์เลี้ยงป่วยหรือแก่ ไปหาสัตวแพทย์** |

ตรวจก่อนใช้มีที่เดียวคือ `prompt-house.md` ฉบับ 5 · ไฟล์อื่นชี้มาที่นี่

## เลือกจากสถานการณ์

| สถานการณ์ | ใช้ |
|---|---|
| ค่าไฟเดือนนี้แพงผิดปกติ | `prompt-house.md` ฉบับ 1 |
| อยากรู้ว่าบ้านเราจ่ายค่าอะไรบ้างแต่ละเดือน | `prompt-house.md` ฉบับ 1 |
| แอร์ไม่เย็น จะเรียกช่าง ได้ราคามา 3 เจ้า | `prompt-house.md` ฉบับ 2 |
| อยากมีตารางล้างแอร์ ดูแลปั๊มน้ำ หลังคา ทั้งปี | `prompt-house.md` ฉบับ 2 |
| ได้บ้านหรือคอนโดใหม่ จะตรวจรับและย้ายเข้า | `prompt-house.md` ฉบับ 3 → 1 → 2 |
| ใกล้หน้าฝน บ้านเคยน้ำท่วม | `prompt-house.md` ฉบับ 4 (ก่อนฝน) |
| น้ำลดแล้ว ของเสียหาย ต้องเคลมและจ้างซ่อม | `prompt-house.md` ฉบับ 4 (หลังน้ำลด) → 2 |
| ภาษีรถหรือ พ.ร.บ. ใกล้หมด | `prompt-vehicle.md` ฉบับ 1 |
| ประกันรถใกล้หมด ได้ใบเสนอมาหลายที่ | `prompt-vehicle.md` ฉบับ 1 |
| รถชน ไม่รู้ต้องทำอะไรก่อน | `prompt-vehicle.md` ฉบับ 2 → 1 |
| จะซื้อรถมือสอง หรือขายรถให้คนอื่น | `prompt-vehicle.md` ฉบับ 3 → 1 |
| ทุกคนในบ้านยุ่ง กินข้าวนอกบ้านจนงบบาน | `prompt-family-week.md` ฉบับ 1 |
| ลูกจะเปิดเทอม ของต้องซื้อเยอะ ใครรับส่ง | `prompt-family-week.md` ฉบับ 2 |
| ลูกจะเข้าโรงเรียนใหม่หรือย้ายโรงเรียน | `prompt-care.md` ฉบับ 1 → `prompt-family-week.md` ฉบับ 2 |
| จะไปต่างจังหวัดหลายวัน ต้องฝากหมาแมวและพ่อแม่ | `prompt-family-week.md` ฉบับ 3 |
| พ่อแม่อายุมากขึ้น เริ่มต้องมีคนดูแล | `prompt-care.md` ฉบับ 1 → `prompt-family-week.md` ฉบับ 1 |
| พ่อแม่ออกจากโรงพยาบาล ต้องจัดเวรดูแลหรือจ้างคน | `prompt-care.md` ฉบับ 2 |
| รับลูกหมาลูกแมวมาใหม่ | `prompt-care.md` ฉบับ 1 |
| หมาแมวไม่กินอาหาร หรือแก่แล้วป่วยบ่อย | `prompt-care.md` ฉบับ 3 |
| ทำตารางหรือเทียบราคาเองแล้ว อยากให้ช่วยตรวจ | `prompt-house.md` ฉบับ 5 |
