# prompt-house — ค่าบ้านและดูแลบ้าน: บิล ช่าง ย้ายเข้าบ้านใหม่ ฝนหนักน้ำท่วม

ใช้คู่กับ plugin `home-family` · ไฟล์นี้รวม prompt 5 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์บ้าน** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วางรูปบิล ใบเสนอราคา เอกสารรถ ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1 และ 4`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `home-family` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · ตารางสถานะตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · skill ที่อ้างข้าม plugin (ชื่อ plugin อยู่ในวงเล็บ) ไม่ได้ติดตั้ง → ข้ามแล้วบอกในรายงาน · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบเพดานรอบ (งานกลาง 3 · งานใหญ่หรืองานเสี่ยง 5) ยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 2

**ขอบเขต:** อัตราค่าไฟ ค่า Ft ภาษีรถ เบี้ย พ.ร.บ. (พระราชบัญญัติคุ้มครองผู้ประสบภัยจากรถ) และสิทธิผู้สูงอายุ ตรวจกับแหล่งทางการรอบนี้ ติดวันที่ · ไม่วินิจฉัยโรคของคนหรือสัตว์ · การจ่ายเงิน จ้างช่าง ต่อภาษี ตั้งหักบัญชีอัตโนมัติ อยู่ใน "รออนุมัติ"

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด ไม่กำหนด → ใช้ชื่อในตาราง

|---|---|---|---|
| 1 | บิลค่าบ้านรายเดือน / บิลแพงผิดปกติ | `bills` | `bills/tracker.csv` · `bills/<ปี-เดือน>-check.md` |
| 2 | ตารางดูแลบ้าน / เทียบราคาช่าง | `maintenance` | `home/maintenance-<ปี>.md` · `home/quotes-<งาน>.md` |

ใช้ต่อกัน: ตั้งระบบบ้านครั้งแรก → 1 → 2 แล้วต่อ `prompt-vehicle.md` ฉบับ 1 · `prompt-care.md` ฉบับ 1 · ใช้ `prompt-family-week.md` ฉบับ 1 ทุกสัปดาห์ · ย้ายบ้าน → 3 → 1 → 2 · น้ำลดแล้วต้องจ้างช่าง → 4 → 2 (เทียบราคา) · ตรวจก่อนใช้ → 5

## 1. บิลค่าบ้านรายเดือน / บิลแพงผิดปกติ

playbook `bills` · agent `home-manager` · skill `household-bills`
**ผลลัพธ์:** `bills/tracker.csv` (ทุกบิลทุกเดือน) · `bills/<ปี-เดือน>-check.md` เมื่อบิลพุ่ง · **รออนุมัติ:** จ่ายบิล · ตั้งหักบัญชี · ยกเลิกบริการ

### ข้อมูล (ผู้ใช้กรอก)

- บิลเดือนนี้ (รูปหรือตัวเลข: ไฟ · น้ำ · อินเทอร์เน็ต · มือถือ · ส่วนกลาง):
- ผู้ให้บริการ (การไฟฟ้านครหลวง (กฟน.) / การไฟฟ้าส่วนภูมิภาค (กฟภ.) · การประปานครหลวง (กปน.) / การประปาส่วนภูมิภาค (กปภ.) · ค่ายมือถือ):
- บิล 3 เดือนก่อน (ถ้ามี):
- อะไรเปลี่ยนในบ้านช่วงนี้ (แอร์ใหม่ · คนเพิ่ม · ร้อนจัด):

### ต้องมีในผลงาน

1. แถวในตารางติดตาม: เดือน · ประเภท · หน่วย · ยอด · วันครบกำหนด
2. อ่านบิล: ค่าพลังงาน · ค่า Ft · ค่าบริการ · VAT (ภาษีมูลค่าเพิ่ม) คำนวณซ้ำได้ตรงกับบิล
3. ถ้าพุ่ง: เทียบ 3 เดือน แยกส่วนที่มาจาก "ใช้มากขึ้น" กับ "อัตราเปลี่ยน" · สงสัยน้ำรั่ว → วิธีตรวจมิเตอร์
4. 2–3 ทางลดที่มีผลมากสุดสำหรับบ้านนี้ พร้อมตัวเลขประมาณที่คำนวณได้

## 3. ย้ายเข้าบ้านหรือคอนโดใหม่

playbook `maintenance` (ขั้น 1 สำรวจบ้าน · ขั้น 2 ปฏิทิน 12 เดือน · ขั้น 5 ตรวจคนรับผิดชอบ) ส่วนตรวจรับบ้านและย้ายมิเตอร์ประกอบเพิ่มตาม `playbook-template` (skill `superuser` หัวข้อ 2) · agent `home-manager` · skill `home-maintenance` · `household-bills`
**ผลลัพธ์:** `home/move-in.md` (เช็กลิสต์ตรวจรับ · รายการจุดบกพร่อง · งานย้ายมิเตอร์และบริการ · ตารางดูแลปีแรก) · แถวบิลใหม่ใน `bills/tracker.csv` · **รออนุมัติ:** ส่งรายการจุดบกพร่องให้โครงการหรือผู้ขาย · จ้างช่างตรวจบ้าน · จ่ายเงินประกันมิเตอร์ · สมัครอินเทอร์เน็ต

### ข้อมูล (ผู้ใช้กรอก)

- บ้านใหม่จากโครงการ / บ้านมือสอง / เช่า · ประเภทบ้าน:
- วันตรวจรับ / วันโอน / วันย้ายเข้า:
- รูปหรือรายการจุดที่เห็นว่ามีปัญหา (path):
- ผู้ให้บริการไฟและน้ำของพื้นที่ (ไม่รู้ปล่อยว่าง):
- เอกสารที่มี (สัญญาซื้อขายหรือเช่า · โฉนดหรือหนังสือกรรมสิทธิ์ห้องชุด · ทะเบียนบ้าน):

### ต้องมีในผลงาน

1. เช็กลิสต์ตรวจรับแยกตามห้องและระบบ (ไฟ · น้ำ · ประตูหน้าต่าง · พื้นผนัง · หลังคาหรือฝ้า) จาก `home-maintenance`
2. รายการจุดบกพร่อง: ตำแหน่ง · ปัญหา · รูป · ผู้รับผิดชอบแก้ · กำหนดแก้ — เป็นร่างให้ผู้ใช้ส่งเอง
3. งานย้ายหรือเปลี่ยนชื่อมิเตอร์ไฟและน้ำ ย้ายทะเบียนบ้าน ย้ายที่อยู่ในบัญชีต่าง ๆ: เอกสาร · ช่องทาง · ค่าธรรมเนียม — ตรวจกับเว็บผู้ให้บริการและหน่วยงานรอบนี้ ติดวันที่ · ตรวจไม่ได้ → `ยังไม่ได้ตรวจ`
4. แถวบิลใหม่ทุกประเภทใน `bills/tracker.csv` พร้อมวันครบกำหนด
5. ตารางดูแลบ้านปีแรกตามฤดู · ระยะประกันงานจากโครงการ (คัดจากสัญญา) ใส่วันหมดไว้ในตาราง

### กฎเฉพาะฉบับนี้

- เงื่อนไขประกันงานและสิทธิเรียกร้องจากโครงการ → คัดจากสัญญาตรงตัวเท่านั้น ไม่ตีความทางกฎหมายเอง

## 4. ฝนหนัก น้ำท่วม: เตรียมก่อน และจัดการหลังน้ำลด

playbook `maintenance` (ขั้น 2 ปฏิทินก่อนฤดูฝน · ขั้น 3 เทียบใบเสนอราคา · ขั้น 4 คำถามถึงช่าง · ขั้น 5 คนรับผิดชอบ) · agent `home-manager` · skill `home-maintenance`
**ผลลัพธ์:** `home/flood-<ปี>.md` (ก่อนฝน · ตอนน้ำมา · หลังน้ำลด) · **รออนุมัติ:** จ้างช่าง ซื้อของป้องกัน ยื่นเคลมประกันบ้าน ยื่นขอเงินช่วยเหลือจากรัฐ

### ข้อมูล (ผู้ใช้กรอก)

- ช่วงนี้คือ (เตรียมก่อนฝน / น้ำกำลังมา / น้ำลดแล้ว):
- ประเภทบ้าน · กี่ชั้น · เคยท่วมไหม สูงแค่ไหน:
- ของมีค่าและเครื่องใช้ไฟฟ้าชั้นล่าง:
- ประกันบ้านหรือประกันอัคคีภัยที่มี (path กรมธรรม์):
- (น้ำลดแล้ว) รูปความเสียหาย (path):

### ต้องมีในผลงาน

1. ก่อนฝน: งานที่ต้องเสร็จ (รางน้ำ ท่อระบาย หลังคา ปั๊มน้ำ) ใส่เดือนและคนรับผิดชอบ · ของที่ต้องย้ายขึ้นที่สูง · เอกสารสำคัญใส่ถุงกันน้ำ
2. ตอนน้ำมา: ตัดไฟชั้นที่น้ำจะถึง · ห้ามแตะปลั๊กหรือสวิตช์ตอนตัวเปียก · เบอร์ฉุกเฉิน 1669 และเบอร์หน่วยงานบรรเทาสาธารณภัย (ตรวจเบอร์รอบนี้ ติดวันที่)
3. หลังน้ำลด: ถ่ายรูปความเสียหายก่อนซ่อมหรือทิ้งของ · ให้ช่างไฟตรวจก่อนเปิดไฟ · รายการเคลมคัดความคุ้มครองจากกรมธรรม์ตรงตัว · เงินช่วยเหลือจากรัฐ: เงื่อนไขและช่องทาง ตรวจกับแหล่งทางการรอบนี้ ติดวันที่
4. งานซ่อมที่ต้องจ้าง → ตารางเทียบราคาช่างแบบฉบับ 2

### กฎเฉพาะฉบับนี้

- ไม่สั่งให้ผู้ใช้ทำงานไฟฟ้าเอง · งานไฟทั้งหมดให้ช่างไฟ
- เงินช่วยเหลือ วงเงินเคลม ห้ามเขียนตัวเลขจากความจำ
