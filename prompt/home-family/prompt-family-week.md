# prompt-family-week — แผนสัปดาห์ของครอบครัว: อาหาร เปิดเทอม ไม่อยู่บ้านหลายวัน

ใช้คู่กับ plugin `home-family` · ไฟล์นี้รวม prompt 3 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์บ้าน** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วางรูปบิล ใบเสนอราคา เอกสารรถ ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1 และ 4`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `home-family` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · ตารางสถานะตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่าง → ถามรวมครั้งเดียวก่อนเริ่ม ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · skill ที่อ้างข้าม plugin (ชื่อ plugin อยู่ในวงเล็บ) ไม่ได้ติดตั้ง → ข้ามแล้วบอกในรายงาน · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → หยุดและบอกผู้ใช้

**ขอบเขต:** อัตราค่าไฟ ค่า Ft ภาษีรถ เบี้ย พ.ร.บ. (พระราชบัญญัติคุ้มครองผู้ประสบภัยจากรถ) และสิทธิผู้สูงอายุ ตรวจกับแหล่งทางการรอบนี้ ติดวันที่ · ไม่วินิจฉัยโรคของคนหรือสัตว์ · การจ่ายเงิน จ้างช่าง ต่อภาษี ตั้งหักบัญชีอัตโนมัติ อยู่ใน "รออนุมัติ"

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด ไม่กำหนด → ใช้ชื่อในตาราง

## 1. วางแผนสัปดาห์ของครอบครัว

playbook `family-week` · agent `family-planner` · skill `meal-plan-grocery` · `kids-school` · `elder-care` · `pet-care`
**ผลลัพธ์:** `week/<ปี>-W<สัปดาห์>.md` ตารางเดียวแชร์ให้ทุกคนในบ้าน

### ข้อมูล (ผู้ใช้กรอก)

- คนในบ้าน (ผู้ใหญ่ · เด็ก อายุ · ผู้สูงอายุ) และอาหารที่ห้ามหรือไม่กิน:
- งบอาหารต่อสัปดาห์:
- กิจกรรมสัปดาห์นี้ (โรงเรียน · นัดหมอ · งานบ้าน · สัตว์เลี้ยง):
- วันไหนทำกับข้าวได้ / วันไหนไม่มีเวลา:
- ของที่มีในตู้เย็นแล้ว:

### ต้องมีในผลงาน

1. ตาราง 7 วัน: มื้อ · นัด · ของโรงเรียน · ยาและนัดผู้สูงอายุ · งานสัตว์เลี้ยง · ใครรับผิดชอบ
2. รายการซื้อของแยกตามแผนกตลาด พร้อมราคารวมเทียบงบ
3. แผนทำล่วงหน้าวันหยุด (batch cooking) และของเหลือใช้ต่อมื้อไหน
4. วันหยุดราชการในสัปดาห์นี้ (`thai-holidays` ของ thai-workplace ถ้ามี)

## 2. เตรียมเปิดเทอม

playbook `family-week` (ขั้น 1 เก็บข้อมูล · ขั้น 2 รายการซื้อภายในงบ · ขั้น 3 งานโรงเรียน · ขั้น 4 คนรับผิดชอบและยอดรวม) · agent `family-planner` · skill `kids-school` · `meal-plan-grocery`
**ผลลัพธ์:** `week/<ปี>-term-<เทอม>.md` (ของต้องซื้อ · ค่าใช้จ่ายและวันจ่าย · ตารางรับส่ง · ปฏิทินเทอม) · **รออนุมัติ:** จ่ายค่าเทอม สั่งซื้อของ สมัครรถรับส่งหรือกวดวิชา

### ข้อมูล (ผู้ใช้กรอก)

- ลูก (ชื่อเล่น · ชั้น · โรงเรียน):
- รายการของและค่าใช้จ่ายที่โรงเรียนแจ้ง (path ประกาศหรือรูป):
- งบเปิดเทอมรวม:
- ใครรับส่งได้วันไหน เวลาไหน:
- กิจกรรมหลังเลิกเรียน · กวดวิชา (ถ้ามี):
- ต้องทำกล่องข้าวไหม:

### ต้องมีในผลงาน

1. รายการของต้องซื้อต่อคน: ของ · จำนวน · ราคาประมาณ · มีแล้ว/ต้องซื้อ · ยอดรวมเทียบงบ
2. ค่าใช้จ่ายเทอมนี้และวันครบกำหนดจ่าย · รายการที่อยู่ในเรียนฟรีหรือรัฐอุดหนุน ตรวจกับแหล่งทางการรอบนี้ ติดวันที่
3. ตารางรับส่ง 5 วันเรียน: ไป · กลับ · ใคร · แผนสำรองเมื่อคนประจำติดธุระ
4. ปฏิทินเทอม: วันเปิด · วันสอบ · วันหยุด · วันประชุมผู้ปกครอง (คัดจากประกาศโรงเรียน)
5. ถ้าทำกล่องข้าว: เมนู 5 วันและรายการซื้อรวมกับแผนสัปดาห์แรก

## 3. ไม่อยู่บ้านหลายวัน: ฝากลูก พ่อแม่ สัตว์เลี้ยง และบ้าน

playbook `family-week` (ขั้น 3 ใส่งานโรงเรียน นัดผู้สูงอายุ ยา และงานสัตว์เลี้ยง · ขั้น 4 ตรวจว่าทุกงานมีวัน เวลา และคนรับผิดชอบ) · agent `family-planner` · skill `pet-care` · `elder-care` · `kids-school` · `home-maintenance`
**ผลลัพธ์:** `week/away-<ปี-เดือน-วัน>.md` (ตารางวันที่ไม่อยู่ · บันทึกส่งต่อแต่ละคนหรือตัว · เช็กลิสต์ปิดบ้าน) · **รออนุมัติ:** จองโรงแรมสัตว์เลี้ยง จ้างคนดูแล ตั้งจ่ายบิลล่วงหน้า ส่งบันทึกส่งต่อให้คนรับฝาก

### ข้อมูล (ผู้ใช้กรอก)

- ไม่อยู่วันไหนถึงวันไหน / ใครไปบ้าง:
- ใครอยู่บ้าน หรือฝากใคร (ญาติ · เพื่อนบ้าน · โรงแรมสัตว์เลี้ยง · ผู้ดูแล):
- ลูก: ตารางเรียนช่วงนั้น · ใครรับส่ง:
- พ่อแม่: ยาและนัดช่วงนั้น (path `care/<ชื่อ>.md` ถ้ามี):
- สัตว์เลี้ยง: อาหาร · ยาตามที่สัตวแพทย์สั่ง · คลินิกประจำ:
- บิลที่ครบกำหนดช่วงไม่อยู่ (path `bills/tracker.csv` ถ้ามี):

### ต้องมีในผลงาน

1. ตารางวันต่อวันช่วงที่ไม่อยู่: งาน · เวลา · ใครทำ
2. บันทึกส่งต่อ 1 หน้าต่อคนหรือตัว: สิ่งที่ต้องทำ · ยาตามฉลากหรือตามที่สัตวแพทย์สั่งตรงตัว · เบอร์ติดต่อ · โรงพยาบาลหรือคลินิกใกล้สุด · 1669 เมื่อฉุกเฉิน
3. เช็กลิสต์ปิดบ้าน: น้ำ · ไฟ · แก๊ส · ปลั๊ก · หน้าต่าง · ของในตู้เย็น · พัสดุที่จะมาส่ง
4. บิลที่ครบกำหนดช่วงไม่อยู่ และวันที่ต้องจ่ายก่อนออกเดินทาง

### กฎเฉพาะฉบับนี้

- ยาของคนหรือสัตว์ คัดจากฉลากหรือคำสั่งแพทย์ สัตวแพทย์ตรงตัว · ไม่เพิ่มคำแนะนำเอง
