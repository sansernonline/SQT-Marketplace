# prompt-images — ภาพนิ่ง: ชุดภาพ AI แก้รูป ภาพสินค้า โพสต์ทั้งเดือน

ใช้คู่กับ plugin `graphic-design` · ไฟล์นี้รวม prompt 4 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์งานออกแบบของแบรนด์นั้น** (1 แบรนด์ 1 โฟลเดอร์)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วางรูปอ้างอิงไว้ใน `03-source-media/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1 และ 2`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `graphic-design` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · ตารางสถานะตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**ขอบเขต:** ไม่ลอกโลโก้ ตัวการ์ตูน หรืองานที่มีเจ้าของ · ขนาดและ safe zone ของแต่ละแพลตฟอร์มตรวจกับหน้า help ของแพลตฟอร์มรอบนี้ ติดวันที่ · การสร้างภาพหรือวิดีโอด้วยเครื่องมือที่เสียเงิน การโพสต์ และการลบไฟล์ต้นฉบับ อยู่ใน "รออนุมัติ" · ไม่มี plugin สร้างภาพหรือวิดีโอติดตั้ง → ส่ง brief และ prompt พร้อมวาง แทนการสร้างเอง

**ภาษาและไฟล์:** เขียนตาม `human-writing` · โครงโฟลเดอร์ตาม `asset-organize` (`00-brand-kit/` · `01-masters/` · `02-exports/` · `03-source-media/` · `04-archive/`) · ชื่อไฟล์ตามที่ skill กำหนด (เช่น `briefs/<asset-name>.md` · `02-exports/<campaign>/asset-matrix.md`)

## 3. ภาพสินค้าสำหรับร้านออนไลน์

playbook `image-series` · agent `art-director` · skill `style-consistency` · `image-editing-brief` · `social-formats`
**ผลลัพธ์:** `02-exports/products/style-lock-v<N>.md` · `briefs/<sku>-<view>.md` ต่อภาพ · ภาพที่แก้แล้วลง `02-exports/products/` (ไม่ทับต้นฉบับ) · **รออนุมัติ:** สร้างหรือแก้ภาพด้วยเครื่องมือที่เสียเงิน · อัปโหลดขึ้นร้าน

### ข้อมูล (ผู้ใช้กรอก)

- สินค้าและจำนวนรหัสสินค้า (SKU — Stock Keeping Unit):
- รูปที่ถ่ายเอง (path ใน `03-source-media/`):
- ขายที่ไหน (Shopee · Lazada · TikTok Shop · LINE · Facebook):
- ภาพที่ต้องมีต่อสินค้า (ภาพปก · ภาพใช้งานจริง · ภาพบอกขนาด · ภาพรายละเอียด):
- ป้ายหรือโปรที่อยากใส่บนภาพปก:

### ต้องมีในผลงาน

1. ข้อกำหนดภาพของแต่ละร้านค้า (ขนาด · อัตราส่วน · สีพื้น · ใส่ข้อความบนภาพปกได้ไหม) ตรวจกับหน้า help สำหรับผู้ขายรอบนี้ ติดวันที่
2. style lock ของภาพสินค้า: พื้น · แสง · มุม · ระยะ · เงา ให้ทุก SKU ดูเป็นร้านเดียวกัน
3. brief แก้ภาพต่อรูป (ตัดพื้น · ปรับแสง · แก้เงา) ตาม `image-editing-brief` · สีสินค้าอยู่ในรายการ "ต้องคงไว้" ทุกภาพ
4. ชุดภาพต่อ SKU ครบตามรายการที่กรอก ตั้งชื่อตาม `asset-organize`
5. ผลตรวจทั้งชุดกับ style lock และกับข้อกำหนดของร้านค้า

### กฎเฉพาะฉบับนี้

- ห้ามแต่งให้สินค้าต่างจากของจริง (สี · ขนาด · ส่วนประกอบ · ของแถม) — ลูกค้าได้ของไม่ตรงภาพแล้วขอคืนได้
- ห้ามใช้ภาพจากร้านอื่นหรือภาพจากผู้ผลิตที่ไม่ได้รับอนุญาต

## 4. โพสต์ทั้งเดือนให้หน้าตาเป็นชุดเดียวกัน

playbook `image-series` · agent `art-director` + `social-creator` · skill `style-consistency` · `brief-to-image` · `social-formats`
**ผลลัพธ์:** `02-exports/<YYYY-MM>-content/content-calendar.md` (ตารางโพสต์) · `style-lock-v<N>.md` · `briefs/` ต่อโพสต์ · **รออนุมัติ:** สร้างภาพด้วยเครื่องมือที่เสียเงิน · ตั้งเวลาโพสต์หรือโพสต์

### ข้อมูล (ผู้ใช้กรอก)

- เดือน:
- จำนวนโพสต์ต่อสัปดาห์ / แพลตฟอร์ม:
- ประเภทโพสต์ที่ใช้ประจำ (สินค้า · รีวิวลูกค้า · ความรู้ · โปร · วันสำคัญ · เบื้องหลังร้าน):
- โปรหรือวันสำคัญในเดือนนี้:
- brand kit (path):

### ต้องมีในผลงาน

1. แม่แบบโพสต์ 1 แบบต่อประเภท ใช้ซ้ำทั้งเดือน
2. ตารางโพสต์: วันที่ · ประเภท · หัวข้อ · ข้อความบนภาพ · แพลตฟอร์ม · ขนาด
3. style lock เดียวใช้ทั้งเดือน
4. brief ต่อโพสต์ อ้าง style lock และแม่แบบของประเภทนั้น
5. ผลตรวจภาพที่สร้างแล้วกับ style lock (ถ้าสร้างในรอบนี้)

### กฎเฉพาะฉบับนี้

- วันสำคัญของไทยตรวจวันที่จริงของปีนี้กับแหล่งทางการ ติดวันที่ตรวจ
- โพสต์รีวิวลูกค้าใช้ข้อความรีวิวจริงที่ผู้ใช้ให้มาเท่านั้น ไม่แต่งรีวิวขึ้นเอง
- ใช้ชื่อ รูป หรือข้อความของลูกค้าเมื่อลูกค้าอนุญาตแล้วเท่านั้น · ยังไม่ได้รับอนุญาต → ปิดชื่อและหน้า
