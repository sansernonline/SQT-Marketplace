# prompt-video — วิดีโอและ motion: คลิปสั้น โลโก้เคลื่อนไหว

ใช้คู่กับ plugin `graphic-design` · ไฟล์นี้รวม prompt 2 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์งานออกแบบของแบรนด์นั้น** (1 แบรนด์ 1 โฟลเดอร์)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วางรูปอ้างอิงไว้ใน `03-source-media/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1 และ 2`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `graphic-design` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · ตารางสถานะตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่าง → ถามรวมครั้งเดียวก่อนเริ่ม ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**ขอบเขต:** ไม่ลอกโลโก้ ตัวการ์ตูน หรืองานที่มีเจ้าของ · ขนาดและ safe zone ของแต่ละแพลตฟอร์มตรวจกับหน้า help ของแพลตฟอร์มรอบนี้ ติดวันที่ · การสร้างภาพหรือวิดีโอด้วยเครื่องมือที่เสียเงิน การโพสต์ และการลบไฟล์ต้นฉบับ อยู่ใน "รออนุมัติ" · ไม่มี plugin สร้างภาพหรือวิดีโอติดตั้ง → ส่ง brief และ prompt พร้อมวาง แทนการสร้างเอง

**ภาษาและไฟล์:** เขียนตาม `human-writing` · โครงโฟลเดอร์ตาม `asset-organize` (`00-brand-kit/` · `01-masters/` · `02-exports/` · `03-source-media/` · `04-archive/`) · ชื่อไฟล์ตามที่ skill กำหนด (เช่น `briefs/<asset-name>.md` · `02-exports/<campaign>/asset-matrix.md`)

## 1. วิดีโอสั้นและ motion

playbook `video` · agent `social-creator` · skill `video-script-to-clip` · `motion-basics`
**ผลลัพธ์:** `briefs/<clip>-script.md` (บท + shot list) · `briefs/<clip>-shot-<N>.md` · **รออนุมัติ:** สร้างคลิปด้วยเครื่องมือที่เสียเงิน · โพสต์

### ข้อมูล (ผู้ใช้กรอก)

- ข้อความเดียวที่อยากให้คนดูจำ:
- แพลตฟอร์ม / ความยาว (Reels · TikTok · Shorts · โฆษณา):
- มีฟุตเทจหรือรูปไหม (path):
- เสียงพากย์ / เพลง / ซับไทย:
- เครื่องมือสร้างหรือตัดต่อวิดีโอที่ใช้ (หรือ ยังไม่มี):

### ต้องมีในผลงาน

1. hook 3 วินาทีแรก 2–3 แบบ แล้วเลือก 1
2. shot list: ช็อต · วินาที · ภาพ · ข้อความบนจอ · เสียง
3. ซับไทยที่อ่านทัน (ตัวอักษรต่อบรรทัด · เวลาค้าง ตาม skill)
4. timing และ easing ของ motion เป็นมิลลิวินาที
5. brief ต่อช็อตพร้อมส่งให้เครื่องมือสร้างวิดีโอที่ผู้ใช้ระบุ (ยังไม่มี → เสนอ 2–3 ตัว ราคาตรวจรอบนี้ ติดวันที่)
6. เพลง: มาจากคลังเพลงที่ได้สิทธิ์ของแพลตฟอร์ม หรือแหล่งที่อนุญาตใช้เชิงพาณิชย์เท่านั้น · จดแหล่งและสิทธิ์ไว้ · ไม่รู้สิทธิ์ → `(รอยืนยัน)`

## 2. โลโก้เคลื่อนไหว · intro และ outro ของคลิป

playbook `video` (ขั้น 3–5: จังหวะ motion · brief · ตรวจ — ข้าม hook และ shot list ยาวเพราะเป็นช่วงสั้นช่วงเดียว) · agent `social-creator` · skill `motion-basics` · `brand-kit`
**ผลลัพธ์:** `briefs/logo-motion-spec.md` (แนวเคลื่อนไหว · ตารางจังหวะ · brief) · **รออนุมัติ:** สร้างด้วยเครื่องมือที่เสียเงิน

### ข้อมูล (ผู้ใช้กรอก)

- โลโก้ (path · ไฟล์เวกเตอร์ดีที่สุด):
- ใช้ที่ไหน (ต้นคลิป · ท้ายคลิป · มุมจอระหว่างคลิป · สติกเกอร์ LINE):
- ความยาวที่ต้องการ:
- บุคลิกแบรนด์ (อ่านจาก `00-brand-kit/` ถ้ามี):
- เสียงประกอบ (มี / ไม่มี / ยังไม่รู้):
- เครื่องมือสร้างหรือตัดต่อวิดีโอที่ใช้ (หรือ ยังไม่มี):

### ต้องมีในผลงาน

1. แนวเคลื่อนไหว 2–3 แบบที่เข้ากับบุคลิกแบรนด์ แล้วเลือก 1 พร้อมเหตุผล
2. ตารางจังหวะ: ช่วง · มิลลิวินาที · สิ่งที่ขยับ · เส้น easing ตาม `motion-basics`
3. เฟรมสุดท้ายเป็นโลโก้ตามกฎใน brand kit (ระยะเว้น · ขนาด · สี) ค้างนานพอให้อ่านทัน
4. 2 ความยาว: แบบเต็มสำหรับต้นหรือท้ายคลิป และแบบสั้นสำหรับ story หรือ Shorts
5. brief พร้อมส่งเครื่องมือสร้างวิดีโอ หรือขั้นตอนทำในแอปตัดต่อที่ผู้ใช้มี

### กฎเฉพาะฉบับนี้

- ไม่บิดสัดส่วน ไม่เปลี่ยนสี และไม่ตัดส่วนของโลโก้นอกเหนือจากที่กฎใน brand kit อนุญาต
