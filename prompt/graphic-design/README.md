# prompt/graphic-design — ชุดคำสั่งพร้อมวางสำหรับ plugin `graphic-design`

1 ไฟล์ต่อ 1 สถานการณ์ของงานออกแบบ · ในไฟล์มีหลาย prompt (เรียกว่า "ฉบับ") แต่ละฉบับทำงาน 1 ชิ้น

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์งานออกแบบของแบรนด์นั้น** (1 แบรนด์ 1 โฟลเดอร์ ไม่ใช่โฟลเดอร์โปรเจกต์โค้ด)
2. เลือกไฟล์จากตาราง [เลือกจากสถานการณ์](#เลือกจากสถานการณ์) แล้วกรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วางรูปอ้างอิงไว้ใน `03-source-media/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้าย `ทำข้อ N`
4. agent ทำตาม playbook ของ plugin `graphic-design` จนจบในรอบเดียว · การโพสต์ การสร้างภาพด้วยเครื่องมือที่เสียเงิน การส่งโรงพิมพ์ และการลบไฟล์ อยู่ใน "รออนุมัติ" ให้คุณตัดสินเอง

## รายการไฟล์

| ไฟล์ | ใช้เมื่อ | ฉบับในไฟล์ |
|---|---|---|
| `prompt-brand.md` | เริ่มแบรนด์ใหม่ รีแบรนด์ หรือของเดิมรก | 1 brand kit · **2 ของพิมพ์ชุดแรกของร้าน** · 3 จัดไฟล์ |
| `prompt-campaign.md` | ออกแคมเปญ หรือมีงานจะปล่อย | 1 แคมเปญหลายแพลตฟอร์ม · **2 โปรเทศกาลด่วน** · **3 แตกขนาดจากภาพหลัก** · 4 ตรวจก่อนปล่อย · **5 ลูกค้าสั่งแก้คลุมเครือ** |
| `prompt-images.md` | ต้องการภาพนิ่งหลายภาพหรือแก้ภาพ | 1 ชุดภาพ AI · 2 แก้รูป · **3 ภาพสินค้าร้านออนไลน์** · **4 โพสต์ทั้งเดือน** |
| `prompt-video.md` | ทำคลิปหรือ motion | 1 วิดีโอสั้น · **2 โลโก้เคลื่อนไหว** |

ฉบับตัวหนา = ฉบับที่เพิ่มใหม่ · ตรวจงานใช้ `prompt-campaign.md` ฉบับ 4 ที่เดียว ไฟล์อื่นชี้มาที่นี่

## เลือกจากสถานการณ์

| สถานการณ์ | ใช้ |
|---|---|
| เพิ่งเปิดร้าน ยังไม่มีโลโก้หรือสีประจำร้าน | `prompt-brand.md` ฉบับ 1 → 2 |
| โพสต์แต่ละอันหน้าตาเหมือนคนละร้าน | `prompt-brand.md` ฉบับ 1 → `prompt-images.md` ฉบับ 4 |
| ต้องทำป้ายหน้าร้าน เมนู นามบัตร ส่งโรงพิมพ์ | `prompt-brand.md` ฉบับ 2 → `prompt-campaign.md` ฉบับ 4 |
| หาโลโก้ตัวล่าสุดไม่เจอ ไฟล์ชื่อ final_v2 เต็มไปหมด | `prompt-brand.md` ฉบับ 3 → 1 |
| จะเปิดตัวสินค้าใหม่ ต้องมีภาพทุกช่องทาง | `prompt-campaign.md` ฉบับ 1 → 4 |
| พรุ่งนี้เริ่มโปร 11.11 ยังไม่มีภาพเลย | `prompt-campaign.md` ฉบับ 2 → 4 |
| มีภาพโพสต์ Facebook แล้ว อยากได้ขนาด story TikTok LINE ด้วย | `prompt-campaign.md` ฉบับ 3 → 4 |
| ทำเสร็จแล้ว อยากให้ดูก่อนโพสต์ว่ามีอะไรผิดไหม | `prompt-campaign.md` ฉบับ 4 |
| ลูกค้าบอก "ยังไม่ปัง" "ขอดูแพงกว่านี้" แก้มา 3 รอบแล้ว | `prompt-campaign.md` ฉบับ 5 → 4 |
| ภาพสินค้าที่ถ่ายเองพื้นหลังรก สีเพี้ยน | `prompt-images.md` ฉบับ 2 |
| จะลงสินค้าทั้งร้านบน Shopee หรือ TikTok Shop ภาพต้องเหมือนกันทุกชิ้น | `prompt-images.md` ฉบับ 3 → `prompt-campaign.md` ฉบับ 4 |
| วางคอนเทนต์เดือนหน้าทั้งเดือน | `prompt-images.md` ฉบับ 4 → (โพสต์ที่เป็นโปร) `prompt-campaign.md` ฉบับ 2 |
| สร้างภาพ AI แล้วแต่ละภาพไม่เข้าชุดกัน | `prompt-images.md` ฉบับ 1 → 2 (ภาพที่หลุด) |
| อยากได้ตัวละครประจำร้านใช้ทุกโพสต์ | `prompt-images.md` ฉบับ 1 |
| ต้องทำคลิป Reels หรือ TikTok ขายของ | `prompt-video.md` ฉบับ 1 → `prompt-campaign.md` ฉบับ 4 |
| อยากให้ทุกคลิปขึ้นต้นด้วยโลโก้ขยับได้ | `prompt-brand.md` ฉบับ 1 (ถ้ายังไม่มี kit) → `prompt-video.md` ฉบับ 2 → 1 |

สถานการณ์ใหม่ที่ประกอบจากฉบับที่มีอยู่ได้ → เพิ่มแถวในตารางนี้ ไม่ต้องสร้างไฟล์ใหม่
