# prompt-growth — ให้คนเจอและใช้ผลิตภัณฑ์: SEO conversion ภาพประกอบ ประสบการณ์นักพัฒนา

ใช้คู่กับ plugin `software-company` · ไฟล์นี้รวม prompt 4 ฉบับ · ใช้เมื่อผลิตภัณฑ์ใช้งานได้แล้ว และต้องให้คนค้นเจอ สมัคร หรือเริ่มใช้ได้ง่ายขึ้น

## วิธีใช้

วางทั้งไฟล์ใน Claude Code, Codex CLI หรือ Gemini CLI ที่รากโฟลเดอร์โปรเจกต์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1`

### กฎเฉพาะฉบับนี้

- ไม่กดส่งสมัครหรือจ่ายเงินจริงบน production → ทำถึงขั้นก่อนส่ง หรือใช้ sandbox

4. แผน A/B test 1–2 ชุด: แบบ A · แบบ B · ตัววัด · จำนวนคนที่ต้องใช้
5. หน้าร้านแอป: ชื่อ · คำบรรยายสั้น · ภาพหน้าจอ 1–3 ภาพแรกควรแสดงอะไร

- ผลิตภัณฑ์สำหรับนักพัฒนาแบบไหน (API · SDK · CLI · ไลบรารี · แพลตฟอร์ม):
- เอกสารและ repo ตัวอย่าง (path / URL):

- โหมด (ตรวจของที่มี / ออกแบบ SDK ใหม่):
- บัญชีทดสอบ / sandbox / API key (ใส่ใน environment variable ไม่ใช่ในไฟล์):

### กฎเฉพาะฉบับนี้

- ไม่กดส่งสมัครหรือจ่ายเงินจริงบน production → ทำถึงขั้นก่อนส่ง หรือใช้ sandbox

### หัวข้อที่ต้องมี

1. เวลาจากศูนย์ถึง "hello world" — ลองทำตามเอกสารจริง จับเวลา จดทุกจุดที่ติด

3. ความสม่ำเสมอของ API (ชื่อ · รูปแบบ error · pagination · version)
4. ข้อเสนอแก้เรียงตามผลต่อแรงที่ใช้
5. ถ้าออกแบบ SDK: ตัวอย่างการเรียกใช้ในภาษาเป้าหมายก่อนเขียน spec
