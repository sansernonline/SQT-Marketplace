# prompt/consumer-rights — ชุดคำสั่งพร้อมวางของ plugin `consumer-rights` แยกไฟล์ตามช่วงก่อนซื้อ หลังซื้อ และเมื่อมีปัญหา

## วิธีใช้

1. เปิด agent ที่**โฟลเดอร์ผู้บริโภค** (ไม่ใช่โฟลเดอร์โปรเจกต์โค้ด) · โฟลเดอร์เดียวใช้ได้ทุกไฟล์ · หลักฐานวางไว้ใน `evidence/<เรื่อง>/`
2. เลือกไฟล์จากตาราง "เลือกจากสถานการณ์" แล้วกรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ
3. วางทั้งไฟล์ + พิมพ์ `ทำข้อ N` · ของที่ย้อนไม่ได้ (ส่ง · จ่าย · โอน · ยื่น · แจ้งความ) อยู่ใน "รออนุมัติ" เสมอ

## รายการไฟล์

| ไฟล์ | ใช้เมื่อ | ฉบับในไฟล์ |
|---|---|---|
| `prompt-before-buying.md` | ยังไม่ได้จ่ายเงิน | 1 ตัดสินใจซื้อของชิ้นใหญ่ · **2 ตรวจร้านและสินค้าก่อนโอนเงิน** |
| `prompt-money-back.md` | จ่ายแล้ว อยากได้เงินคืน | 1 ขอเงินคืน · **2 โอนแล้วไม่ได้ของ / ถูกหลอกขาย** · **3 บิลผิด / บริการที่ไม่ได้สมัคร** |
| `prompt-complaint.md` | คุยกับร้านแล้วไม่จบ ต้องร้องเรียน | 1 ร้องเรียนตามขั้นบันได · **2 ยกเลิกสมาชิก / สัญญาบริการ** · **3 เคลมประกันภัยถูกปฏิเสธ** · **4 บ้าน คอนโด ผู้รับเหมา** · 5 ตรวจก่อนส่ง |
| `prompt-warranty.md` | ซื้อแล้ว เก็บประกัน หรือของเสีย | 1 ทะเบียนรับประกัน เคลม · **2 ของเสียซ้ำหลังซ่อม** |

ฉบับตรวจก่อนส่งมีที่เดียว: `prompt-complaint.md` ฉบับ 5 · ไฟล์อื่นชี้มาที่นี่

## เลือกจากสถานการณ์

| สถานการณ์ | ใช้ |
|---|---|
| จะซื้อแอร์ ตู้เย็น มือถือ หรือโน้ตบุ๊ก เลือกไม่ถูก | `prompt-before-buying.md` ฉบับ 1 → `prompt-warranty.md` ฉบับ 1 |
| เจอของถูกมากในเพจหรือกลุ่มซื้อขาย ร้านให้โอนก่อน | `prompt-before-buying.md` ฉบับ 2 |
| จะซื้อของมือสองจากคนไม่รู้จัก | `prompt-before-buying.md` ฉบับ 2 |
| เพิ่งซื้อของที่มีประกัน อยากเก็บใบเสร็จให้เป็นระบบ | `prompt-warranty.md` ฉบับ 1 |
| ของเสียแต่ยังอยู่ในประกัน | `prompt-warranty.md` ฉบับ 1 |
| ส่งซ่อมแล้วเสียอีก ซ้ำหลายรอบ | `prompt-warranty.md` ฉบับ 2 → `prompt-complaint.md` ฉบับ 1 |
| ได้ของผิด ปลอม หรือพัง อยากได้เงินคืน | `prompt-money-back.md` ฉบับ 1 → `prompt-complaint.md` ฉบับ 5 |
| ร้านไม่ยอมคืนเงิน | `prompt-money-back.md` ฉบับ 1 → `prompt-complaint.md` ฉบับ 1 |
| โอนเงินแล้ว ร้านเงียบหรือบล็อก | `prompt-money-back.md` ฉบับ 2 → `prompt-complaint.md` ฉบับ 1 |
| มีรายการบัตรที่ไม่รู้จัก หรือถูกตัดซ้ำ | `prompt-money-back.md` ฉบับ 1 |
| บิลมือถือมีบริการเสริมที่ไม่ได้สมัคร | `prompt-money-back.md` ฉบับ 3 → `prompt-complaint.md` ฉบับ 1 |
| ซื้อจากพนักงานขายตรงแล้วเปลี่ยนใจ | `prompt-money-back.md` ฉบับ 1 |
| อยากเลิกฟิตเนสหรือคอร์ส แต่ร้านไม่ให้เลิกหรือยังตัดบัตรต่อ | `prompt-complaint.md` ฉบับ 2 → 5 |
| บริษัทประกันไม่จ่ายเคลม หรือจ่ายไม่ครบ | `prompt-complaint.md` ฉบับ 3 → 5 |
| คอนโดสร้างช้า ห้องไม่ตรงโฆษณา หรือผู้รับเหมาทิ้งงาน | `prompt-complaint.md` ฉบับ 4 → 5 |
| ร้านไม่ทำตามที่สัญญา บริการแย่ อยากร้องเรียน | `prompt-complaint.md` ฉบับ 1 → 5 |
| มีจดหมายร้องเรียนที่เขียนเองแล้ว อยากให้ช่วยดู | `prompt-complaint.md` ฉบับ 5 |

สถานการณ์ใหม่ที่ประกอบจากฉบับที่มีอยู่ได้ → เพิ่มแถวในตารางนี้ ไม่ต้องสร้างไฟล์ใหม่
