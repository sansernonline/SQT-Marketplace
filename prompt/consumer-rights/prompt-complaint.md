# prompt-complaint — ร้องเรียน: ร้านไม่แก้ ยกเลิกสัญญา ประกันภัย บ้านและผู้รับเหมา

ใช้คู่กับ plugin `consumer-rights` · ไฟล์นี้รวม prompt 5 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์ผู้บริโภค** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วางหลักฐาน (ใบเสร็จ แชต รูป) ไว้ใน `evidence/<เรื่อง>/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 2`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `consumer-rights` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · ตารางสถานะตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบ 5 รอบยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 2

**ขอบเขต:** ข้อมูลทั่วไป ไม่ใช่คำปรึกษากฎหมาย · กฎหมาย เลขสายด่วน ช่องทางร้องเรียน และระยะเวลา ต้องตรวจกับแหล่งทางการรอบนี้ (ติดวันที่ตรวจ) · ส่งข้อความถึงร้าน ยื่นเรื่อง สคบ. (สำนักงานคณะกรรมการคุ้มครองผู้บริโภค) หรือขอ chargeback อยู่ใน "รออนุมัติ" เสมอ · ไม่แต่งหลักฐาน · คดีที่มูลค่าสูงหรือซับซ้อน → แนะนำทนาย

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด (เช่น `warranties.csv`) ไม่กำหนด → ใช้ชื่อในตาราง

## 1. ร้องเรียนตามขั้นบันได

playbook `complaint` · agent `consumer-advocate` · skill `complaint-letter-th`
**ผลลัพธ์:** `cases/<ปี-เดือน>-<ร้าน>/complaint.md` · `letter-<ขั้น>.docx` · **รออนุมัติ:** ส่งจดหมาย · ยื่นเรื่อง

### ข้อมูล (ผู้ใช้กรอก)

- ร้าน / ผู้ให้บริการ (ชื่อ ที่อยู่ เลขทะเบียนถ้ารู้):
- เรื่องที่เกิด เรียงตามวันที่:
- ร้านสัญญาอะไรไว้ / ไม่ทำอะไร:
- อยากได้อะไร (เงินคืน · ซ่อม · เปลี่ยน · ชดเชย):
- ยอดเงินที่เกี่ยว:
- หลักฐาน (path) และที่ร้องเรียนไปแล้ว:

### ต้องมีในผลงาน

1. ไทม์ไลน์ข้อเท็จจริง แยก "มีหลักฐาน" ออกจาก "ผู้ใช้เล่า"
2. ขั้นบันได: ร้าน → แพลตฟอร์ม → สคบ. → ศาลคดีผู้บริโภค · แต่ละขั้นมีช่องทาง กำหนดเวลา และเมื่อไรขึ้นขั้นถัดไป
3. จดหมายร้องเรียนภาษาไทยแบบทางการ สำหรับขั้นที่ใช้ตอนนี้
4. รายการเอกสารแนบตามที่หน่วยงานขอ
5. ตารางติดตาม: ขั้น · วันที่ส่ง · ครบกำหนด · ผล

## 2. ยกเลิกสมาชิกหรือสัญญาบริการ แต่ร้านไม่ยอม

playbook `complaint` · agent `consumer-advocate` · skill `complaint-letter-th` · `refund-request`
**ผลลัพธ์:** `cases/<ปี-เดือน>-<ร้าน>/cancel.md` · `letter-cancel.docx` · **รออนุมัติ:** ส่งหนังสือบอกเลิกสัญญา · ขอธนาคารหยุดตัดบัตร · ยื่นเรื่อง

### ข้อมูล (ผู้ใช้กรอก)

- บริการอะไร (ฟิตเนส · คอร์สเรียน · คลินิกความงาม · อินเทอร์เน็ต · แอปสมาชิก · อื่น ๆ):
- สัญญาหรือใบสมัคร (path) · ระยะสัญญา · วันที่เริ่ม:
- จ่ายแบบไหน (จ่ายครั้งเดียว · ผ่อน · ตัดบัตรอัตโนมัติรายเดือน):
- อยากยกเลิกเพราะอะไร (บริการไม่ตรงที่ขาย · ย้ายบ้าน · ป่วย · ร้านปิด · เปลี่ยนใจ):
- ร้านตอบว่าอะไร / เรียกค่าปรับเท่าไร:

### ต้องมีในผลงาน

1. ข้อสัญญาที่เกี่ยวกับการยกเลิก ยกมาจากเอกสารจริงพร้อมเลขข้อ · ข้อที่อาจไม่เป็นธรรมให้ติดป้าย "ควรตรวจกับ สคบ. หรือทนาย" ไม่ตัดสินเอง
2. สิ่งที่ผู้ใช้ขอได้: หยุดตัดเงินเดือนถัดไป · คืนเงินส่วนที่ยังไม่ได้ใช้ · ยกเลิกโดยไม่เสียค่าปรับ — แต่ละข้อบอกว่าอ้างอะไร (สัญญา · เงื่อนไขร้าน · กฎหมายที่ตรวจรอบนี้ ติดวันที่ตรวจ)
3. หนังสือบอกเลิกสัญญาภาษาไทยแบบทางการ ระบุวันที่มีผล และขอหลักฐานรับเรื่อง
4. ถ้าตัดบัตรอัตโนมัติ: ขั้นตอนขอธนาคารหยุดตัดหรือปฏิเสธรายการ ตาม `refund-request`
5. ขั้นบันไดถ้าร้านไม่ตอบ (ร้าน → สคบ. → ศาลคดีผู้บริโภค) พร้อมตารางติดตาม

## 3. เคลมประกันภัยถูกปฏิเสธหรือจ่ายไม่ครบ

playbook `complaint` · agent `consumer-advocate` · skill `complaint-letter-th`
**ผลลัพธ์:** `cases/<ปี-เดือน>-<บริษัทประกัน>/insurance-claim.md` · `letter-<ขั้น>.docx` · **รออนุมัติ:** ส่งหนังสืออุทธรณ์ถึงบริษัทประกัน · ยื่นเรื่องต่อหน่วยงานกำกับ

### ข้อมูล (ผู้ใช้กรอก)

- ประเภทประกัน (รถ · สุขภาพ · อุบัติเหตุ · บ้าน · การเดินทาง · อื่น ๆ):
- กรมธรรม์ (path) · เลขกรมธรรม์ · ช่วงคุ้มครอง:
- เกิดเหตุอะไร วันไหน · ยื่นเคลมวันไหน:
- บริษัทตอบว่าอะไร (ปฏิเสธ · จ่ายบางส่วน · ช้า) และเหตุผลที่ให้ (หนังสือ path):
- ยอดที่เคลม / ยอดที่ได้:
- ตัวแทนหรือนายหน้าที่ขาย (ถ้ามี):

### ต้องมีในผลงาน

1. ตารางเทียบ: เหตุผลที่บริษัทอ้าง → ข้อในกรมธรรม์ที่เกี่ยว (ยกข้อความจริงพร้อมเลขข้อ) → หลักฐานของผู้ใช้ที่ค้าน
2. เอกสารที่ยังขาดและควรขอเพิ่ม (ใบรับรองแพทย์ · บันทึกประจำวันตำรวจ · ใบเสนอราคาซ่อม)
3. หนังสืออุทธรณ์ถึงบริษัทประกัน ขอคำอธิบายเป็นลายลักษณ์อักษรและวันที่ตอบ
4. ขั้นถัดไป: หน่วยงานกำกับธุรกิจประกันภัย คือ สำนักงานคณะกรรมการกำกับและส่งเสริมการประกอบธุรกิจประกันภัย (คปภ.) · ช่องทาง เอกสาร และกรอบเวลาตรวจกับเว็บทางการรอบนี้ ติดวันที่ตรวจ
5. ตารางติดตาม: ขั้น · วันที่ส่ง · ครบกำหนด · ผล

### กฎเฉพาะฉบับนี้

- อ่านเงื่อนไขจากกรมธรรม์ของผู้ใช้เท่านั้น ไม่อ้างเงื่อนไขทั่วไปจากความจำ · ไม่มีกรมธรรม์ให้อ่าน → บอกว่ายังตรวจไม่ได้
- ไม่แนะนำให้ปิดบังหรือเปลี่ยนข้อเท็จจริงเรื่องเหตุที่เกิดหรือประวัติสุขภาพ

## 4. บ้าน คอนโด หรือผู้รับเหมาไม่ทำตามสัญญา

playbook `complaint` · agent `consumer-advocate` · skill `complaint-letter-th`
**ผลลัพธ์:** `cases/<ปี-เดือน>-<โครงการ>/home.md` · `letter-<ขั้น>.docx` · **รออนุมัติ:** ส่งหนังสือทวงถามหรือบอกเลิกสัญญา · จ่ายงวดถัดไป · ยื่นเรื่อง

### ข้อมูล (ผู้ใช้กรอก)

- เรื่องอะไร (โครงการสร้างช้า · ห้องไม่ตรงโฆษณา · ของเสียหลังรับโอน · ผู้รับเหมาทิ้งงาน · งานไม่ตรงแบบ):
- คู่สัญญา (บริษัท · ผู้รับเหมา · ชื่อ ที่อยู่ เลขทะเบียนถ้ารู้):
- สัญญา แบบ ใบเสนอราคา โบรชัวร์ (path):
- จ่ายไปแล้วกี่งวด ยอดเท่าไร · ค้างอีกเท่าไร:
- ปัญหาที่เห็น (รูป · วิดีโอ · รายการ defect — path):
- คุยกับอีกฝ่ายไปแล้วได้คำตอบว่าอะไร:

### ต้องมีในผลงาน

1. ไทม์ไลน์ข้อเท็จจริง และตาราง สัญญาบอกว่า → เกิดจริง → หลักฐาน (รูปที่มีวันที่)
2. ตารางเงิน: งวดที่จ่าย · งานที่ควรเสร็จในงวดนั้น · งานที่เสร็จจริง · ยอดที่จ่ายเกินงาน
3. หนังสือทวงถามให้แก้ไขหรือทำต่อ ภายในวันที่กำหนด อ้างข้อสัญญาตามเลขข้อ
4. ขั้นบันได: คู่สัญญา → สคบ. → ศาลคดีผู้บริโภค · ช่องทางและกรอบเวลาตรวจกับเว็บทางการรอบนี้ ติดวันที่ตรวจ
5. รายการสิ่งที่ไม่ควรทำก่อนปรึกษา (หยุดจ่ายงวดเอง · จ้างคนอื่นมาทำต่อ · เข้ารื้องาน) พร้อมเหตุผล

### กฎเฉพาะฉบับนี้

- มูลค่าสูงหรือจะบอกเลิกสัญญา → แนะนำทนายในบรรทัดแรกของข้อสรุป และเตรียมเอกสารให้ทนายอ่านได้ทันที
- ข้อความถึงอีกฝ่ายไม่ข่มขู่ ไม่หมิ่นประมาท ไม่โพสต์ประจานในโซเชียล

## 5. ตรวจงานผู้บริโภคก่อนส่ง

playbook `review` · agent `consumer-advocate` + agent ตัวใหม่ (มุมร้านหรือเจ้าหน้าที่ที่อ่านเรื่อง)
**ผลลัพธ์:** คำตัดสิน `ผ่าน / แก้ก่อนส่ง` · **ไม่แก้ไฟล์เอง**

### ข้อมูล (ผู้ใช้กรอก)

- ไฟล์ที่จะให้ตรวจ (จดหมาย · ข้อความ · คำร้อง):
- จะส่งให้ใคร:

### ต้องมีในผลงาน

1. คำตัดสิน 1 บรรทัด
2. ตารางปัญหา: ตำแหน่ง · ปัญหา (ข้อเท็จจริงไม่ตรงหลักฐาน · ขาดวันที่หรือยอด · น้ำเสียงที่ทำให้เสียเปรียบ · อ้างกฎหมายผิด) · ระดับ · วิธีแก้ (เดิม → ใหม่)
3. ข้อที่ตรวจแล้วผ่าน
