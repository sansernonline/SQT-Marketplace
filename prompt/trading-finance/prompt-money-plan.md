# prompt-money-plan — เงินในชีวิต: แผนการเงิน ได้เงินก้อน รายได้หาย

ยังไม่ได้ทดสอบจริง

ใช้คู่กับ plugin `trading-finance` · ไฟล์นี้รวม prompt 3 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์การเงิน** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วาง statement พอร์ต รายงานจากโบรกเกอร์ ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `trading-finance` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · สรุปงานตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบเพดานรอบ (งานกลาง 3 · งานใหญ่หรืองานเสี่ยง 5) ยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 3

**ขอบเขต (ห้ามข้าม):** ข้อมูลประกอบการตัดสินใจ **ไม่ใช่คำแนะนำการลงทุน** · ไม่บอกให้ซื้อหรือขาย · ไม่ส่งคำสั่งซื้อขาย ไม่โอนเงิน — อยู่ใน "รออนุมัติ" และผู้ใช้กดเองเสมอ · ไม่คำนวณขนาดไม้ถ้าไม่มีจุดตัดขาดทุน · ราคา ข่าว อัตราภาษี และสิทธิลดหย่อน ดึงจากแหล่งจริงรอบนี้ ติดวันที่และเวลา · ตัวเลขทุกตัวคำนวณซ้ำได้

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด (เช่น `trade-journal.csv` · `holdings.csv` · `watchlist.csv` · `dividends.csv` · `snapshot-YYYY-MM.md`) ไม่กำหนด → ใช้ชื่อในตาราง

| 2 | ได้เงินก้อน (โบนัส · มรดก · ขายทรัพย์สิน · เงินชดเชย) | `money-plan` | `plan/lump-sum-<ปี-เดือน>.md` |

## 1. แผนการเงิน

playbook `money-plan` · agent `money-planner` · skill `personal-budget` · `emergency-fund` · `debt-payoff` · `retirement-plan` · `insurance-review` (เลือกตามเรื่อง)
**ผลลัพธ์:** `plan/<เรื่อง>.md` · **รออนุมัติ:** โอน ปิดบัญชี รีไฟแนนซ์ ซื้อหรือยกเลิกประกัน

### ข้อมูล (ผู้ใช้กรอก)

- เรื่อง (งบรายเดือน / เงินสำรองฉุกเฉิน / ปลดหนี้ / เกษียณ / ทบทวนประกัน):
- รายได้ต่อเดือน / รายจ่ายจริง 3 เดือน (statement path):
- หนี้แต่ละก้อน (ยอด · ดอกเบี้ย · ค่างวด):
- เงินออมที่มี และอยู่ที่ไหน:
- (เกษียณ) อายุตอนนี้ / อยากเกษียณกี่ปี / กองทุนสำรองเลี้ยงชีพ · ประกันสังคม:
- (ประกัน) กรมธรรม์ที่มี (path):

### ต้องมีในผลงาน

1. ตัวเลขตั้งต้นจากรายจ่ายจริง ไม่ใช่ประมาณ
2. งบ: จำเป็น · อยาก · ออม · ลงทุน · เงินสำรอง: กี่เดือน เก็บที่ไหน (ความคุ้มครองเงินฝาก ตรวจกับแหล่งทางการ)
3. หนี้: เทียบวิธี snowball (ก้อนเล็กก่อน) กับ avalanche (ดอกสูงก่อน) — ดอกรวมและวันปลดหนี้ของแต่ละวิธี
4. เกษียณ: เงินที่ต้องมี · ออมเดือนละเท่าไร · สมมติฐานผลตอบแทนและเงินเฟ้อเขียนชัด
5. ประกัน: ทุนพอไหมเทียบภาระ · co-payment · ช่องว่างความคุ้มครอง

## 2. ได้เงินก้อน

playbook `money-plan` · agent `money-planner` · skill `debt-payoff` · `emergency-fund` · `retirement-plan` · `mutual-fund-picker` · `tax-basics-th` (ถ้าเงินก้อนต้องเสียภาษี)
**ผลลัพธ์:** `plan/lump-sum-<ปี-เดือน>.md` — แบ่งเงินก้อนเป็นส่วน พร้อมลำดับและวันที่ · **รออนุมัติ:** โอน · ปิดหนี้ก่อนกำหนด · ซื้อกองทุนหรือประกัน · ฝากประจำ

### ข้อมูล (ผู้ใช้กรอก)

- เงินก้อนเท่าไร ได้จากอะไร ได้วันไหน:
- ถูกหักภาษีไปแล้วไหม (path หนังสือรับรอง ถ้ามี):
- หนี้แต่ละก้อน (ยอด · ดอกเบี้ย · ค่าปรับปิดก่อนกำหนด):
- เงินสำรองฉุกเฉินตอนนี้มีกี่เดือน:
- ของที่อยากได้หรือต้องจ่ายเร็ว ๆ นี้:
- เป้าระยะยาว (เกษียณ · บ้าน · การศึกษาลูก):

### ต้องมีในผลงาน

1. บรรทัดแรก: แบ่งเงินก้อนเป็นกี่ส่วน ส่วนละเท่าไร
2. ลำดับ: หนี้ดอกสูง → เงินสำรองให้ครบ → ของที่ต้องจ่าย → เป้าระยะยาว · ทุกส่วนมีเหตุผล 1 บรรทัด
3. ปิดหนี้ก่อนกำหนด: ประหยัดดอกเท่าไร หักค่าปรับแล้วคุ้มไหม คำนวณซ้ำได้
4. ภาษีของเงินก้อนนี้ (ถ้ามี) และสิทธิที่เกี่ยว ตรวจกับกรมสรรพากรรอบนี้ ติดวันที่ตรวจ
5. ส่วนที่รอได้: พักไว้ที่ไหนระหว่างตัดสินใจ (ความคุ้มครองเงินฝาก ตรวจกับแหล่งทางการ)

### กฎเฉพาะฉบับนี้

- ไม่เร่งให้ลงทุนทั้งก้อนทันที · ส่วนที่จะลงทุนส่งต่อฉบับเลือกกองทุนโดยไม่ระบุชื่อกองเป็นคำแนะนำ

## 3. รายได้หาย ตกงาน ต้องประคองเงิน

playbook `money-plan` · agent `money-planner` · skill `personal-budget` · `emergency-fund` · `debt-payoff` · `insurance-review` · `retirement-plan` (สิทธิประกันสังคมที่เกี่ยว)
**ผลลัพธ์:** `plan/income-loss-<ปี-เดือน>.md` — เงินพอใช้กี่เดือน · งบฉุกเฉิน · ลำดับจ่ายหนี้ · รายการติดต่อ · **รออนุมัติ:** ขอพักหนี้หรือปรับโครงสร้างหนี้กับธนาคาร · ถอนเงินลงทุนหรือกองทุนสำรองเลี้ยงชีพ · หยุดหรือลดเบี้ยประกัน · ยื่นขอรับสิทธิประกันสังคม

### ข้อมูล (ผู้ใช้กรอก)

- เกิดอะไร (ถูกเลิกจ้าง · ลาออก · รายได้ลด · ป่วย) / ตั้งแต่วันไหน:
- เงินที่ยังได้ (ค่าชดเชย · เงินเดือนงวดสุดท้าย · รายได้เสริม · คู่สมรส):
- รายจ่ายจริง 3 เดือน (statement path):
- หนี้แต่ละก้อน (ยอด · ดอกเบี้ย · ค่างวด):
- เงินเก็บและเงินลงทุนที่มี อยู่ที่ไหน:
- เป็นผู้ประกันตนประกันสังคมไหม / ประกันชีวิตและสุขภาพที่มี (path):

### ต้องมีในผลงาน

1. บรรทัดแรก: เงินที่มีพอใช้กี่เดือน ถ้าไม่ปรับอะไร และถ้าใช้งบฉุกเฉิน
2. งบฉุกเฉิน: ตัดอะไร เก็บอะไร (ที่พัก อาหาร ค่างวดที่ผิดนัดแล้วเสียหายมาก ประกันสุขภาพ)
3. หนี้: ก้อนไหนจ่ายต่อ ก้อนไหนติดต่อขอพักหรือปรับโครงสร้าง · ร่างข้อความถึงธนาคาร
4. สิทธิที่อาจได้: ประกันสังคมกรณีว่างงาน · ค่าชดเชยจากนายจ้าง — เงื่อนไข อัตรา และกำหนดยื่น ตรวจกับสำนักงานประกันสังคมและกรมการจัดหางานรอบนี้ ติดวันที่ตรวจ `(รอยืนยัน)`
5. ถอนเงินลงทุนหรือกองทุนสำรองเลี้ยงชีพ: ผลด้านภาษีและเงื่อนไขก่อนถอน ใช้เป็นทางสุดท้าย
6. รายการติดต่อเรียงตามวันที่ต้องทำ

### กฎเฉพาะฉบับนี้

- ไม่แนะนำกู้นอกระบบหรือแอปเงินกู้ที่ไม่ได้รับอนุญาต · เจอข้อเสนอเงินกู้ด่วน → `prompt-scam.md` ฉบับ 1
