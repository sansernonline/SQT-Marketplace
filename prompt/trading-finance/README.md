# prompt/trading-finance — ชุดคำสั่งพร้อมวางสำหรับเงินและการลงทุน (plugin `trading-finance`)

## วิธีใช้

1. เปิด agent ที่**โฟลเดอร์การเงิน** (โฟลเดอร์เดียวใช้ได้ทุกไฟล์) ไม่ใช่โฟลเดอร์โปรเจกต์โค้ด
2. เลือกไฟล์จากตาราง "เลือกจากสถานการณ์" · กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วาง statement ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้าย เช่น `ทำข้อ 1`

ทุกฉบับเป็นข้อมูลประกอบการตัดสินใจ ไม่ใช่คำแนะนำการลงทุน · ส่งคำสั่งซื้อขาย โอน ซื้อ ยื่นแบบ อยู่ใน "รออนุมัติ" เสมอ คุณกดเอง

## รายการไฟล์

| ไฟล์ | ใช้เมื่อ | ฉบับในไฟล์ |
|---|---|---|
| `prompt-trading.md` | เทรดเอง (หุ้น · forex · crypto) | 1 ก่อนเปิดสถานะ · 2 ทบทวนผลเทรด · 3 watchlist + แจ้งเตือน · **4 ซ้อมด้วยเงินจำลอง** · **5 ติดดอย ถือ ตัด หรือถัว** · **6 forex · ทองคำ · crypto** · **7 prop firm challenge** |
| `prompt-investing.md` | ลงทุนระยะยาว | 1 พอร์ต · 2 เลือกกองทุน · **3 เริ่มลงทุนครั้งแรก** · **4 ตลาดร่วงแรง** |
| `prompt-money-plan.md` | วางแผนเงินในชีวิต | 1 แผนการเงิน · **2 ได้เงินก้อน** · **3 รายได้หาย ตกงาน** |
| `prompt-tax.md` | ภาษีเงินได้บุคคล และตรวจงาน | 1 ภาษีปลายปี · **2 ยื่นภาษีต้นปี** · 3 ตรวจงานการเงินก่อนใช้ |
| `prompt-scam.md` | สงสัยมิจฉาชีพ | 1 ตรวจก่อนโอน · **2 กันพ่อแม่โดนหลอก** |

ตัวหนา = ฉบับที่เพิ่มใหม่

## เลือกจากสถานการณ์

| สถานการณ์ | ใช้ |
|---|---|
| จะซื้อหุ้นตัวนี้ ซื้อกี่หุ้นดี | `prompt-trading.md` ฉบับ 1 |
| เทรดแล้วขาดทุนแบบเดิมซ้ำ ๆ | `prompt-trading.md` ฉบับ 2 |
| อยากลองกลยุทธ์ใหม่แต่ยังไม่กล้าใช้เงินจริง | `prompt-trading.md` ฉบับ 4 → 1 |
| หุ้นที่ถือลงหนัก ไม่รู้จะถือหรือตัด | `prompt-trading.md` ฉบับ 5 → 2 |
| อยากตามหุ้นไม่กี่ตัวแล้วให้เตือนเมื่อถึงราคา | `prompt-trading.md` ฉบับ 3 → 1 |
| จะเทรด forex ทองคำ หรือ crypto ไม่รู้จะเปิดกี่ lot | `prompt-trading.md` ฉบับ 6 |
| สมัคร prop firm challenge กลัวชนเพดานขาดทุน | `prompt-trading.md` ฉบับ 7 → 6 ทุกไม้ → 2 ทุกสัปดาห์ |
| อยากให้ EA เทรดแทน (เขียน · backtest · ขาย) | plugin `software-company` → `prompt/software-company/prompt-trading-system.md` |
| สิ้นเดือน อยากรู้ว่าพอร์ตเป็นอย่างไร | `prompt-investing.md` ฉบับ 1 |
| ตลาดร่วง ข่าวใหญ่ นอนไม่หลับ | `prompt-investing.md` ฉบับ 4 → `prompt-trading.md` ฉบับ 5 (ตัวที่ลงหนัก) |
| มีเงินเก็บแล้ว อยากเริ่มลงทุนแต่ไม่รู้เริ่มตรงไหน | `prompt-investing.md` ฉบับ 3 → 2 |
| เงินเดือนหมดก่อนสิ้นเดือน | `prompt-money-plan.md` ฉบับ 1 (งบรายเดือน) |
| หนี้บัตรหลายใบ จ่ายแค่ขั้นต่ำ | `prompt-money-plan.md` ฉบับ 1 (ปลดหนี้) |
| ได้โบนัส หรือได้เงินก้อน | `prompt-money-plan.md` ฉบับ 2 → `prompt-investing.md` ฉบับ 3 |
| ถูกเลิกจ้าง รายได้หาย | `prompt-money-plan.md` ฉบับ 3 → 1 เมื่อรายได้กลับมา |
| อยากรู้ว่าเกษียณแล้วเงินพอไหม | `prompt-money-plan.md` ฉบับ 1 (เกษียณ) → `prompt-investing.md` ฉบับ 2 |
| ปลายปี อยากลดภาษี | `prompt-tax.md` ฉบับ 1 → `prompt-investing.md` ฉบับ 2 → `prompt-tax.md` ฉบับ 3 |
| ต้นปี ต้องยื่นภาษี มีปันผล หรือขายคริปโต | `prompt-tax.md` ฉบับ 2 → 3 |
| มีคนชวนลงทุนผลตอบแทนสูง / ให้โอนเงิน | `prompt-scam.md` ฉบับ 1 |
| โอนไปแล้ว เพิ่งรู้ว่าโดนหลอก | `prompt-scam.md` ฉบับ 1 (ขั้นตอนชั่วโมงแรก) |
| พ่อแม่รับสายแปลก ๆ บ่อย กลัวโดนหลอก | `prompt-scam.md` ฉบับ 2 |
| มีแผนหรือไฟล์ที่ทำเอง อยากให้ตรวจก่อนใช้ | `prompt-tax.md` ฉบับ 3 |

สถานการณ์ใหม่ที่ประกอบจากฉบับที่มีอยู่ได้ → เพิ่มแถวในตารางนี้ ไม่ต้องสร้างไฟล์ใหม่
