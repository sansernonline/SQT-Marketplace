# prompt-trading — เทรด: ก่อนเปิดสถานะ ทบทวนเทรด watchlist ซ้อมเงินจำลอง ติดดอย · forex / crypto · prop firm

ยังไม่ได้ทดสอบจริง

ใช้คู่กับ plugin `trading-finance` · ไฟล์นี้รวม prompt 7 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์การเงิน** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วาง statement พอร์ต รายงานจากโบรกเกอร์ ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `trading-finance` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · สรุปงานตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบเพดานรอบ (งานกลาง 3 · งานใหญ่หรืองานเสี่ยง 5) ยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 3

**ขอบเขต (ห้ามข้าม):** ข้อมูลประกอบการตัดสินใจ **ไม่ใช่คำแนะนำการลงทุน** · ไม่บอกให้ซื้อหรือขาย · ไม่ส่งคำสั่งซื้อขาย ไม่โอนเงิน — อยู่ใน "รออนุมัติ" และผู้ใช้กดเองเสมอ · ไม่คำนวณขนาดไม้ถ้าไม่มีจุดตัดขาดทุน · ราคา ข่าว อัตราภาษี และสิทธิลดหย่อน ดึงจากแหล่งจริงรอบนี้ ติดวันที่และเวลา · ตัวเลขทุกตัวคำนวณซ้ำได้

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด (เช่น `trade-journal.csv` · `holdings.csv` · `watchlist.csv` · `dividends.csv` · `snapshot-YYYY-MM.md`) ไม่กำหนด → ใช้ชื่อในตาราง

## 5. ติดดอย ขาดทุนหนัก: ถือ ตัด หรือถัว

playbook `pre-trade` (การถัวเฉลี่ยขาลงคือเปิดสถานะเพิ่ม ต้องผ่านทุกขั้นเหมือนไม้ใหม่) · agent `risk-manager` + `market-analyst` · skill `position-sizing` · `portfolio-snapshot` · `technical-signals` · `news-impact` · `trade-journal`
**ผลลัพธ์:** `positions/<หลักทรัพย์>-<ปี-เดือน-วัน>.md` — ตาราง 3 ทาง (ถือ · ตัด · ถัว) พร้อมตัวเลข · แถวในบันทึกเทรด · **รออนุมัติ:** ส่งคำสั่งขาย · ส่งคำสั่งซื้อเพิ่ม

### ข้อมูล (ผู้ใช้กรอก)

- หลักทรัพย์ / ต้นทุนเฉลี่ย / จำนวนที่ถือ:
- ราคาตอนนี้ (หรือให้ดึง):
- ตอนซื้อ เหตุผลคืออะไร · ตั้งจุดตัดขาดทุนไว้ไหม:
- เงินทุนในพอร์ต / เงินสดที่เหลือ:
- เงินก้อนนี้ต้องใช้เมื่อไร:
- อารมณ์ตอนนี้ (ปกติ / อยากเอาคืน / ไม่กล้าดูพอร์ต):

### ต้องมีในผลงาน

1. บรรทัดแรก: ขาดทุนตอนนี้กี่บาท กี่ % ของพอร์ต · เหตุผลตอนซื้อยังจริงอยู่ไหม (ข่าวและงบล่าสุด ติดวันที่)
2. ตาราง 3 ทาง: ขาดทุนสูงสุดถ้าผิดต่อ · ต้องขึ้นกี่ % ถึงทุน · สัดส่วนหุ้นตัวนี้ในพอร์ตหลังทำ · เงินสดที่เหลือ
3. ถัว: ต้องมีจุดตัดขาดทุนใหม่ · ขนาดไม้คำนวณแบบฉบับ 1 · การกระจุกตัวเกินเกณฑ์ → บอกตรง ๆ · ไม่มีจุดตัดขาดทุน → ไม่คำนวณ
4. สัญญาณอารมณ์ (อยากเอาคืน · ไม่ยอมรับขาดทุน) ชี้ให้เห็นถ้ามี
5. แถวในบันทึกเทรด: ทางที่ผู้ใช้เลือก · เหตุผล · อารมณ์

### กฎเฉพาะฉบับนี้

- ไม่บอกว่าควรเลือกทางไหน · วางตัวเลขให้เห็นแล้วผู้ใช้เลือกเอง

### ต้องมีในผลงาน

1. pip value ต่อ lot ในสกุลเงินบัญชี พร้อมวิธีคิด · spec ทุกค่ามีแหล่งและวันที่ตรวจ · ไม่รู้ → `(รอยืนยัน)` ไม่เดา
2. ขนาดไม้ (lot หรือจำนวนเหรียญ) จากทุน × % เสี่ยง ÷ (ระยะตัดขาดทุน × pip value + ค่า spread และ commission) · ปัดลงตาม volume step · ต่ำกว่าขั้นต่ำ → บอกว่าจุดตัดขาดทุนกว้างเกินบัญชีนี้
3. margin ที่ใช้ และ free margin ที่เหลือ · บอกตรง ๆ ว่า leverage สูงไม่ได้ลดความเสี่ยง · perpetual → ราคาถูกบังคับปิด (liquidation) ต้องอยู่เลยจุดตัดขาดทุน
4. ต้นทุนระหว่างถือ: swap หรือ funding ต่อคืน · ถือข้ามสุดสัปดาห์ → ขาดทุนที่อาจเกิดจาก gap (1.5–2 เท่าของที่วางแผน)
5. คู่เงินที่เคลื่อนไปทางเดียวกันกับไม้ที่เปิดอยู่ (เช่น EURUSD กับ GBPUSD) → นับรวมเป็นความเสี่ยงก้อนเดียว
6. แถวในบันทึกเทรด: setup · เหตุผล · อารมณ์ · แผนออก

### กฎเฉพาะฉบับนี้

- บัญชีใหม่ หรือโบรกเกอร์ที่ไม่รู้จัก → `scam-check` ก่อน (ใบอนุญาต · ถอนเงินได้จริงไหม)
