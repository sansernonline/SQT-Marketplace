# prompt-tax — ภาษีเงินได้บุคคล: ลดหย่อนปลายปี ยื่นภาษีต้นปี ตรวจงานการเงิน

ยังไม่ได้ทดสอบจริง

ใช้คู่กับ plugin `trading-finance` · ไฟล์นี้รวม prompt 3 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์การเงิน** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วาง statement พอร์ต รายงานจากโบรกเกอร์ ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `trading-finance` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · สรุปงานตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบเพดานรอบ (งานกลาง 3 · งานใหญ่หรืองานเสี่ยง 5) ยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 3

**ขอบเขต (ห้ามข้าม):** ข้อมูลประกอบการตัดสินใจ **ไม่ใช่คำแนะนำการลงทุน** · ไม่บอกให้ซื้อหรือขาย · ไม่ส่งคำสั่งซื้อขาย ไม่โอนเงิน — อยู่ใน "รออนุมัติ" และผู้ใช้กดเองเสมอ · ไม่คำนวณขนาดไม้ถ้าไม่มีจุดตัดขาดทุน · ราคา ข่าว อัตราภาษี และสิทธิลดหย่อน ดึงจากแหล่งจริงรอบนี้ ติดวันที่และเวลา · ตัวเลขทุกตัวคำนวณซ้ำได้

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด (เช่น `trade-journal.csv` · `holdings.csv` · `watchlist.csv` · `dividends.csv` · `snapshot-YYYY-MM.md`) ไม่กำหนด → ใช้ชื่อในตาราง

## 1. ภาษีและลดหย่อนปลายปี

playbook `tax-season` · agent `risk-manager` · skill `tax-deduction-planner` · `tax-basics-th`
**ผลลัพธ์:** `tax/<ปี>-plan.md` · **รออนุมัติ:** ซื้อกองทุน ซื้อประกัน ยื่นแบบ

### ข้อมูล (ผู้ใช้กรอก)

- เงินได้ทั้งปี (เงินเดือน · โบนัส · อาชีพอิสระ · ปันผล · ดอกเบี้ย · ต่างประเทศ):
- ลดหย่อนที่มีแล้ว (กองทุนสำรองเลี้ยงชีพ · ประกันชีวิต/สุขภาพ · กองทุนรวมเพื่อการเลี้ยงชีพ (RMF) · กองทุนรวมไทยเพื่อความยั่งยืน (ThaiESG) · ดอกเบี้ยบ้าน · บุตร · บิดามารดา):
- ภาษีที่ถูกหัก ณ ที่จ่ายแล้ว:
- ขายหุ้น / คริปโต / มีรายได้ต่างประเทศไหม:

### ต้องมีในผลงาน

1. ภาษีก่อน → หลัง วางแผน คำนวณทีละขั้นตามอัตราขั้นบันได
2. ช่องที่เหลือของแต่ละลดหย่อน · เพดานรวมกลุ่มเกษียณ
3. ช่องลดหย่อนที่เหลือ (บาท) และภาษีที่ประหยัดได้ถ้าใช้เต็มช่อง ภายในวันที่ 31 ธันวาคม · เลือกกองตัวจริง → `prompt-investing.md` ฉบับ 2 (ไม่ระบุชื่อกองเป็นคำแนะนำ)
4. ปันผล: ใช้เครดิตภาษีหรือไม่ แบบไหนคุ้มกว่า
5. อัตราและเพดานตรวจกับกรมสรรพากรรอบนี้ ติดวันที่

## 2. ยื่นภาษีต้นปี

playbook `tax-season` (ส่วนยื่นภาษีต้นปี) · agent `risk-manager` · skill `tax-basics-th` · `tax-deduction-planner` · `dividend-tracker` (ปันผลทั้งปี)
**ผลลัพธ์:** `tax/<ปี>-filing.md` — ใช้แบบไหน · ตัวเลขกรอกทีละช่อง · เอกสารที่ต้องแนบหรือเก็บ · ได้คืนหรือต้องจ่ายเพิ่ม · **รออนุมัติ:** ยื่นแบบ · ชำระภาษี · ผูกพร้อมเพย์กับเลขประจำตัวประชาชนเพื่อรับเงินคืน

### ข้อมูล (ผู้ใช้กรอก)

- ปีภาษี:
- หนังสือรับรองการหักภาษี ณ ที่จ่าย (50 ทวิ) ทุกใบ (path):
- เงินได้อื่น (อาชีพอิสระ · ค่าเช่า · ขายของออนไลน์):
- ปันผล ดอกเบี้ย (path statement):
- ขายคริปโตหรือหุ้นต่างประเทศ · โอนเงินได้จากต่างประเทศเข้าไทยปีนั้นไหม:
- ลดหย่อนที่มี พร้อมหลักฐาน (path) หรือ `tax/<ปี>-plan.md` จากฉบับ 1:

### ต้องมีในผลงาน

1. บรรทัดแรก: ใช้แบบไหน · ประมาณได้คืนหรือต้องจ่ายเพิ่มเท่าไร
2. เงินได้แยกตามประเภท · ค่าใช้จ่ายที่หักได้ · ลดหย่อน · ภาษีคำนวณทีละขั้น · ยอดตรงกับ 50 ทวิ
3. ปันผล: รวมคำนวณเพื่อขอเครดิตภาษี หรือไม่รวม — เทียบตัวเลข 2 แบบ · เลือกรวมต้องรวมทุกตัวในปีนั้น
4. คริปโตและรายได้ต่างประเทศ: ต้องรวมไหม คิดอย่างไร ตรวจกับกรมสรรพากรรอบนี้ ติดวันที่ตรวจ · ตีความได้หลายทาง → บอกตรง ๆ และแนะนำถามกรมสรรพากรหรือผู้ทำบัญชี
5. วันสุดท้ายยื่นกระดาษและออนไลน์ของปีนี้ (ตรวจประกาศจริง ติดวันที่) · เลยกำหนดเสียอะไร
6. รายการเอกสารที่ต้องเก็บไว้ ถ้าเจ้าหน้าที่ขอตรวจ

## 3. ตรวจงานการเงินก่อนใช้

playbook `review` · agent `risk-manager` + agent ตัวใหม่
**ผลลัพธ์:** คำตัดสิน `ผ่าน / แก้ก่อนใช้` · **ไม่แก้ไฟล์เอง**

### ข้อมูล (ผู้ใช้กรอก)

- ไฟล์ที่จะให้ตรวจ (แผนเทรด · snapshot · แผนภาษี · แผนการเงิน):

### ต้องมีในผลงาน

1. คำตัดสิน 1 บรรทัด
2. ตารางปัญหา: ตำแหน่ง · ปัญหา (คำนวณผิด · ราคาหรืออัตราเก่า · ไม่มีจุดตัดขาดทุน · ภาษาที่ฟังเป็นคำแนะนำซื้อขาย) · ระดับ · วิธีแก้
3. คำนวณซ้ำตัวเลขสำคัญ 3 ตัว แสดงผล
