# prompt-investing — ลงทุนระยะยาว: พอร์ต กองทุน เริ่มลงทุนครั้งแรก ตลาดร่วงแรง

ใช้คู่กับ plugin `trading-finance` · ไฟล์นี้รวม prompt 4 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์การเงิน** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วาง statement พอร์ต รายงานจากโบรกเกอร์ ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `trading-finance` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · ตารางสถานะตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบเพดานรอบ (งานกลาง 3 · งานใหญ่หรืองานเสี่ยง 5) ยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 2

**ขอบเขต (ห้ามข้าม):** ข้อมูลประกอบการตัดสินใจ **ไม่ใช่คำแนะนำการลงทุน** · ไม่บอกให้ซื้อหรือขาย · ไม่ส่งคำสั่งซื้อขาย ไม่โอนเงิน — อยู่ใน "รออนุมัติ" และผู้ใช้กดเองเสมอ · ไม่คำนวณขนาดไม้ถ้าไม่มีจุดตัดขาดทุน · ราคา ข่าว อัตราภาษี และสิทธิลดหย่อน ดึงจากแหล่งจริงรอบนี้ ติดวันที่และเวลา · ตัวเลขทุกตัวคำนวณซ้ำได้

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด (เช่น `trade-journal.csv` · `holdings.csv` · `watchlist.csv` · `dividends.csv` · `snapshot-YYYY-MM.md`) ไม่กำหนด → ใช้ชื่อในตาราง

| # | งาน | playbook | ได้ไฟล์ |
|---|---|---|---|
| 1 | พอร์ตตอนนี้เป็นอย่างไร | `portfolio-check` | `snapshot-YYYY-MM.md` |
| 2 | เลือกกองทุนรวม / กองทุนรวมเพื่อการเลี้ยงชีพ (RMF) / กองทุนรวมไทยเพื่อความยั่งยืน (ThaiESG) | — (กลาง: ใช้ skill ตรง) | `funds/<ปี-เดือน>-compare.md` |
| 3 | เริ่มลงทุนครั้งแรก | `money-plan` | `plan/first-invest.md` |
| 4 | ตลาดร่วงแรง ข่าวใหญ่ กลัวพอร์ตพัง | `portfolio-check` | `snapshot-YYYY-MM-DD.md` |

ทำประจำ: ฉบับ 1 สิ้นเดือน

ใช้ต่อกัน: ฉบับ 3 → 2 (เลือกกองที่จะซื้อ) · ฉบับ 4 → 1 สิ้นเดือน · ซื้อกองทุนเพื่อลดหย่อน → `prompt-tax.md` ฉบับ 1 → ฉบับ 2 ที่นี่ · ตรวจก่อนใช้ → `prompt-tax.md` ฉบับ 3

## 1. พอร์ตตอนนี้เป็นอย่างไร

playbook `portfolio-check` · agent `market-analyst` · skill `portfolio-snapshot` · `dividend-tracker` · `news-impact`
**ผลลัพธ์:** `snapshot-YYYY-MM.md` หน้าเดียว

### ข้อมูล (ผู้ใช้กรอก)

- รายการถือครอง (`holdings.csv` หรือ statement):
- เงินสดในพอร์ต:
- ต้นทุนเฉลี่ย (ถ้า statement ไม่มี):
- ช่วงนี้ฤดูปันผลไหม / อยากดูข่าวที่กระทบพอร์ตด้วยไหม:

### ต้องมีในผลงาน

1. สัดส่วนตามหลักทรัพย์ · กลุ่ม · ประเภทสินทรัพย์ · ราคาและเวลาที่ดึง
2. กำไร/ขาดทุนแต่ละตัวและรวม · ตัวที่ดึงพอร์ตขึ้นและลงมากสุด
3. ธงความเสี่ยง: ตัวเดียวหรือกลุ่มเดียวเกินเกณฑ์
4. ปันผล: ขึ้นเครื่องหมายไม่ได้รับสิทธิปันผล (XD) วันไหน · ได้ประมาณเท่าไร หลังหักภาษี ณ ที่จ่ายตามตลาด (ไทย / ต่างประเทศ) อัตราตรวจกับแหล่งทางการรอบนี้ ติดวันที่ตรวจ
5. ข่าวที่กระทบพอร์ต ไม่เกิน 5 เรื่อง (ถ้าขอ)

## 2. เลือกกองทุนรวม / RMF / ThaiESG

skill `mutual-fund-picker` · agent `market-analyst` · งานกลาง ไม่ต้องเปิด playbook
**ผลลัพธ์:** `funds/<ปี-เดือน>-compare.md` · **รออนุมัติ:** ซื้อกองทุน ตั้งซื้อรายเดือน (DCA)

### ข้อมูล (ผู้ใช้กรอก)

- ซื้อเพื่ออะไร (ลดหย่อน · ออมระยะยาว · เกษียณ):
- เงินที่จะใส่ (ก้อน / รายเดือน) / ถือได้นานแค่ไหน:
- ยอมขาดทุนชั่วคราวได้แค่ไหน:
- กองที่กำลังดู:

### ต้องมีในผลงาน

1. ตารางเทียบจาก factsheet ฉบับล่าสุด: นโยบาย · ดัชนีอ้างอิง · ค่าธรรมเนียมรวม · ผลตอบแทนย้อนหลังเทียบดัชนี · ความเสี่ยง
2. กองดัชนี vs กองบริหารเชิงรุก สำหรับเป้านี้
3. เงื่อนไขถือครองของ RMF / ThaiESG (ตรวจกับแหล่งทางการ)
4. แผน DCA: ยอด · วันที่ · ทบทวนเมื่อไร

## 3. เริ่มลงทุนครั้งแรก

playbook `money-plan` (ครอบคลุมงบ เงินสำรอง และเลือกกองทุน) · agent `risk-manager` · skill `personal-budget` · `emergency-fund` · `debt-payoff` · `mutual-fund-picker`
**ผลลัพธ์:** `plan/first-invest.md` — พร้อมลงทุนหรือยัง · ลงเดือนละเท่าไร · ลงที่ไหน · ลำดับขั้น · **รออนุมัติ:** เปิดบัญชีกองทุนหรือหุ้น · ซื้อครั้งแรก · ตั้งซื้อรายเดือน (DCA)

### ข้อมูล (ผู้ใช้กรอก)

- อายุ / อาชีพ / รายได้ต่อเดือน:
- รายจ่ายจริง 3 เดือน (statement path):
- หนี้ที่มี (ยอด · ดอกเบี้ย · ค่างวด):
- เงินเก็บที่มี และอยู่ที่ไหน:
- เป้าหมาย (เกษียณ · ซื้อบ้าน · ลดหย่อนภาษี · ยังไม่รู้) / ใช้เงินเมื่อไร:
- เคยลงทุนอะไรมาบ้าง / ถ้าพอร์ตลง 20% จะทำอะไร:

### ต้องมีในผลงาน

1. บรรทัดแรก: พร้อมลงทุนหรือยัง · ยังไม่พร้อม → ต้องทำอะไรก่อน (หนี้ดอกสูง · เงินสำรองฉุกเฉิน)
2. ลำดับขั้น: ปลดหนี้ดอกสูง → เงินสำรองกี่เดือน → ลงทุน · ตัวเลขจากรายจ่ายจริง
3. ลงเดือนละเท่าไรที่ไม่กระทบเงินใช้จ่าย · ซื้อรายเดือน (DCA) หรือก้อนเดียว พร้อมเหตุผล
4. ประเภทที่เข้ากับเป้าและเวลาที่ถือ (กองทุนรวม · หุ้น · สำรองเลี้ยงชีพ) เทียบเป็นตาราง · เลือกกองตัวจริง → ฉบับ 2
5. ขั้นเปิดบัญชี: ตรวจว่าบริษัทได้รับใบอนุญาตจากสำนักงานคณะกรรมการกำกับหลักทรัพย์และตลาดหลักทรัพย์ (ก.ล.ต.) (ผลจริง ติดวันที่)

### กฎเฉพาะฉบับนี้

- ไม่ระบุชื่อกองหรือหุ้นเป็นคำแนะนำให้ซื้อ · เทียบให้เห็นแล้วผู้ใช้เลือกเอง

## 4. ตลาดร่วงแรง ข่าวใหญ่ กลัวพอร์ตพัง

playbook `portfolio-check` · agent `market-analyst` + `risk-manager` · skill `portfolio-snapshot` · `news-impact` · `emergency-fund`
**ผลลัพธ์:** `snapshot-YYYY-MM-DD.md` หน้าเดียว · **รออนุมัติ:** ขาย · ซื้อเพิ่ม · เปลี่ยนแผนซื้อรายเดือน (DCA)

### ข้อมูล (ผู้ใช้กรอก)

- เกิดอะไรขึ้น (ข่าว · ตลาดลงกี่ % · วันไหน):
- รายการถือครอง (`holdings.csv` หรือ statement):
- เงินสดในพอร์ต / เงินสำรองฉุกเฉินแยกไว้กี่เดือน:
- เงินในพอร์ตต้องใช้เมื่อไร:
- แผนเดิมตอนลงทุน (ถือยาว · ซื้อรายเดือน · มีจุดตัดขาดทุน):

### ต้องมีในผลงาน

1. บรรทัดแรก: พอร์ตลดลงกี่บาท กี่ % ตั้งแต่วันไหน · ราคาและเวลาที่ดึง
2. ข่าวนี้กระทบหลักทรัพย์ไหนในพอร์ตจริง ไม่เกิน 5 เรื่อง (กำไร · กฎ · สภาพคล่อง) แยกจากข่าวที่ไม่เกี่ยว
3. เงินที่ต้องใช้ภายในเวลาสั้นอยู่ในหลักทรัพย์ที่เสี่ยงไหม · เงินสำรองพอไหม
4. เทียบกับแผนเดิม: แผนบอกให้ทำอะไรเมื่อเจอแบบนี้ · ตัวไหนชนจุดตัดขาดทุนที่ตั้งไว้
5. ธงความเสี่ยงหลังราคาเปลี่ยน: ตัวเดียวหรือกลุ่มเดียวเกินเกณฑ์

### กฎเฉพาะฉบับนี้

- ไม่ทำนายว่าตลาดจะลงต่อหรือฟื้น · ไม่บอกให้ขายหรือซื้อ
