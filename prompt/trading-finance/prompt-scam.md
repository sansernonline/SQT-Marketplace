# prompt-scam — มิจฉาชีพการเงิน: ตรวจก่อนโอน กันพ่อแม่และคนในบ้านโดนหลอก

ยังไม่ได้ทดสอบจริง

ใช้คู่กับ plugin `trading-finance` · ไฟล์นี้รวม prompt 2 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์การเงิน** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วาง statement พอร์ต รายงานจากโบรกเกอร์ ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `trading-finance` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · สรุปงานตอนจบ) อยู่ในแกนของ plugin `superuser` ที่ skill นั้นใช้ร่วม ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบเพดานรอบ (งานกลาง 3 · งานใหญ่หรืองานเสี่ยง 5) ยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 3

**ขอบเขต (ห้ามข้าม):** ข้อมูลประกอบการตัดสินใจ **ไม่ใช่คำแนะนำการลงทุน** · ไม่บอกให้ซื้อหรือขาย · ไม่ส่งคำสั่งซื้อขาย ไม่โอนเงิน — อยู่ใน "รออนุมัติ" และผู้ใช้กดเองเสมอ · ไม่คำนวณขนาดไม้ถ้าไม่มีจุดตัดขาดทุน · ราคา ข่าว อัตราภาษี และสิทธิลดหย่อน ดึงจากแหล่งจริงรอบนี้ ติดวันที่และเวลา · ตัวเลขทุกตัวคำนวณซ้ำได้

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด (เช่น `trade-journal.csv` · `holdings.csv` · `watchlist.csv` · `dividends.csv` · `snapshot-YYYY-MM.md`) ไม่กำหนด → ใช้ชื่อในตาราง

## 1. ตรวจก่อนโอน: มิจฉาชีพไหม

playbook `scam-check` · agent `money-planner` · skill `scam-check`
**ผลลัพธ์:** คำตอบในแชต**ทันที** (ข้อสรุปก่อน) · บันทึก `scam-check/<วันที่>.md`

### ข้อมูล (ผู้ใช้กรอก)

- ใครติดต่อมา / ช่องทาง (แอป · กลุ่ม LINE · โทร · โฆษณา):
- เขาให้ทำอะไร (โอน · ติดตั้งแอป · ลงทุน · ยืนยันตัวตน):
- โอนไปแล้วหรือยัง / ยอด / เวลา:
- ชื่อบริษัท แอป ลิงก์ เลขบัญชีปลายทาง:

### ต้องมีในผลงาน

1. บรรทัดแรก: เสี่ยงสูง / น่าสงสัย / ไม่พบสัญญาณ — และ "อย่าโอน" ถ้าเสี่ยง
2. ตรวจใบอนุญาตกับ ก.ล.ต. (สำนักงานคณะกรรมการกำกับหลักทรัพย์และตลาดหลักทรัพย์) หรือธนาคารแห่งประเทศไทย (ผลจริง ติดวันที่)
3. ถ้าโอนไปแล้ว: ขั้นตอนชั่วโมงแรก (โทรธนาคารอายัด · แจ้งความออนไลน์ · สายด่วน) เรียงตามลำดับ · ตรวจเบอร์และช่องทางกับเว็บทางการรอบนี้ ติดวันที่ · ห้ามเขียนเบอร์จากความจำ
4. สัญญาณที่เจอในเรื่องนี้ (การันตีผลตอบแทน · เร่งให้รีบ · ขอรหัสผ่านใช้ครั้งเดียว (OTP))

### กฎเฉพาะฉบับนี้

- เหตุฉุกเฉิน (โอนไปแล้ว หรือกำลังโดนหลอกอยู่) → ตอบขั้นตอนเร่งด่วนทันทีก่อน แล้วค่อยถามช่องที่ขาด

## 2. กันพ่อแม่และคนในบ้านโดนหลอก

playbook `scam-check` (ใช้ส่วนสัญญาณเตือนและขั้นตอนชั่วโมงแรก ทำเป็นการ์ดไว้ล่วงหน้า) · agent `money-planner` · skill `scam-check`
**ผลลัพธ์:** `scam-check/family-card.md` — การ์ด 1 หน้าตัวหนังสือใหญ่ พิมพ์หรือส่งในแชตครอบครัวได้ · รายการตั้งค่าในมือถือและแอปธนาคาร · **รออนุมัติ:** ส่งการ์ดในกลุ่มครอบครัว · เปลี่ยนวงเงินโอนหรือการตั้งค่าในแอปธนาคารของคนในบ้าน (เจ้าของบัญชีทำเองหรือยินยอม)

### ข้อมูล (ผู้ใช้กรอก)

- ทำให้ใคร (พ่อแม่ · ปู่ย่า · ลูกวัยรุ่น) / อายุ / ใช้มือถือคล่องแค่ไหน:
- ใช้ธนาคารและแอปอะไร:
- เคยเจอหรือเกือบโดนแบบไหนมาแล้ว:
- ใครในบ้านเป็นคนที่ต้องโทรหาก่อนโอนเงิน (ชื่อ · เบอร์):

### ต้องมีในผลงาน

1. กฎ 3 ข้อสั้น ๆ ที่จำได้ เช่น "ใครโทรมาให้โอน วางสายแล้วโทรหา [ชื่อ] ก่อน"
2. แบบหลอกที่พบบ่อยในช่วงนี้ ไม่เกิน 5 แบบ แต่ละแบบ 1 บรรทัด: เขาพูดว่าอะไร · ทำอะไรแทน (ข้อมูลจากแหล่งทางการรอบนี้ ติดวันที่)
3. ถ้าโอนไปแล้ว: ขั้นตอนชั่วโมงแรกเรียงตามลำดับ · เบอร์ธนาคารและสายด่วน ตรวจกับแหล่งทางการรอบนี้ ติดวันที่ตรวจ
4. รายการตั้งค่าที่ช่วยกัน (วงเงินโอนต่อวัน · แจ้งเตือนทุกรายการ · ไม่ติดตั้งแอปจากลิงก์) แต่ละข้อทำอย่างไรในแอปที่ใช้จริง
5. ภาษาง่าย ตัวหนังสือใหญ่ ไม่ใช้ศัพท์อังกฤษ

### กฎเฉพาะฉบับนี้

- ไม่ขอและไม่บันทึกรหัสผ่าน รหัสผ่านใช้ครั้งเดียว (OTP) หรือเลขบัตรของใคร
