# prompt-doctor-and-meds — หาหมอ ตารางยา และโรคประจำตัว

ใช้คู่กับ plugin `personal-life` · ไฟล์นี้รวม prompt 4 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์สุขภาพ** (แยกโฟลเดอร์ต่อคน เช่น `health/me/` · `health/mom/`)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · ไม่รู้ปล่อยว่างได้
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 2`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `personal-life` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · สรุปงานตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบเพดานรอบ (งานกลาง 3 · งานใหญ่หรืองานเสี่ยง 5) ยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 2

**ขอบเขต (ห้ามข้าม):** งานจัดระเบียบเท่านั้น · **ไม่วินิจฉัย ไม่แปลผลตรวจว่าเป็นโรคอะไร ไม่บอกขนาดยา ไม่แนะนำให้หยุดหรือเปลี่ยนยา** · ตารางยาคัดจากฉลากหรือใบสั่งแพทย์ตรงตัว · อาการฉุกเฉิน (เจ็บหน้าอก หายใจไม่ออก ปากเบี้ยว แขนขาอ่อนแรง หมดสติ) → บอกให้โทร 1669 ทันที แล้วหยุดงานอื่น · สิทธิการรักษา (ประกันสังคม · บัตรทอง · ข้าราชการ) ตรวจกับแหล่งทางการรอบนี้ ติดวันที่ · การจองโรงพยาบาล ซื้อแพ็กเกจ อยู่ใน "รออนุมัติ"

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด ไม่กำหนด → ใช้ชื่อในตาราง

| # | งาน | playbook | ได้ไฟล์ |
|---|---|---|---|
| 1 | เตรียมไปหาหมอ / สรุปหลังพบ | `doctor-visit` | `visits/<ปี-เดือน-วัน>-<เรื่อง>.md` |
| 2 | ตารางยาและการเตือนเติมยา | `medication-routine` | `medications.md` |
| 3 | โรคประจำตัว: บันทึกค่าที่วัดเองที่บ้านไปให้หมอดู | `doctor-visit` (ขั้น 2–4) + ประกอบเพิ่ม | `home-readings.csv` · `visits/<ปี-เดือน-วัน>-<เรื่อง>.md` |
| 4 | ตรวจงานสุขภาพก่อนใช้ | `review` | คำตัดสินในคำตอบ · ไม่สร้างไฟล์ |

ใช้ต่อกัน: ผลตรวจประจำปีมีค่าผิดปกติ → `prompt-checkup.md` ฉบับ 1 (บันทึกผล) → 1 (เตรียมคำถามไปถามหมอ) → 2 ถ้าได้ยา · หมอให้วัดค่าเองที่บ้าน → 3 แล้วพกไปนัดหน้าด้วย 1 · ทำตารางยาหรือสรุปหลังพบเสร็จ → 4 ก่อนใช้จริง

## 1. เตรียมไปหาหมอ / สรุปหลังพบ

playbook `doctor-visit` · agent `health-organizer` · skill `doctor-visit-prep`
**ผลลัพธ์:** `visits/<ปี-เดือน-วัน>-<เรื่อง>.md` หน้าเดียว พิมพ์หรือเปิดในมือถือให้หมอดูได้

### ข้อมูล (ผู้ใช้กรอก)

- ก่อนพบ หรือ หลังพบ:
- ไปหาหมอเรื่องอะไร / แผนกไหน / วันนัด:
- อาการ เริ่มเมื่อไร เป็นแบบไหน อะไรทำให้ดีขึ้นหรือแย่ลง:
- ยาและอาหารเสริมที่ใช้อยู่ (ชื่อตามฉลาก):
- แพ้ยาหรืออาหาร:
- (หลังพบ) หมอบอกอะไร / ให้ยาอะไร / นัดครั้งถัดไป (เล่าหรือรูปใบนัด):

### ต้องมีในผลงาน

1. ก่อนพบ: ไทม์ไลน์อาการ · รายการยาและการแพ้ · คำถาม 3–5 ข้อเรียงตามความสำคัญ · ของที่ต้องพก (บัตร · ผลตรวจเดิม · ยาที่กิน)
2. หลังพบ: สรุปสิ่งที่แพทย์บอกตามคำผู้ใช้ (ไม่เติมการวินิจฉัย) · ยาใหม่ตามฉลาก · นัดครั้งถัดไป · สิ่งที่ต้องทำก่อนนัด
3. คำถามที่ยังไม่ได้ถาม → ยกไปนัดหน้า

## 2. ตารางยาและการเตือนเติมยา

playbook `medication-routine` · agent `health-organizer` · skill `medication-schedule`
**ผลลัพธ์:** `medications.md` (ตารางรายวัน · รายการยาและการแพ้ · วันยาจะหมด) · **รออนุมัติ:** ตั้งการแจ้งเตือนในแอปหรือปฏิทิน

### ข้อมูล (ผู้ใช้กรอก)

- ทำให้ใคร:
- รูปฉลากยาหรือใบสั่งยาทุกตัว (path):
- เวลาตื่น · มื้ออาหาร · เวลานอน:
- จำนวนยาที่เหลือ / วันรับยาครั้งล่าสุด:
- ใครช่วยดูแลเรื่องยา (ถ้ามี):

### ต้องมีในผลงาน

1. ตารางเวลาในวัน คัดจากฉลากตรงตัว (ชื่อยา · ขนาดตามฉลาก · เวลา · ก่อน/หลังอาหาร) · ฉลากอ่านไม่ออก → `(ยืนยันกับเภสัชกร)`
2. รายการยาและการแพ้ ฉบับพกติดตัว
3. วันที่ยาแต่ละตัวจะหมด และวันที่ควรไปรับยา
4. ยาที่ฉลากเขียนต่างกัน หรือดูซ้ำกัน → ใส่ในรายการ "ถามเภสัชกร" ไม่ตัดสินเอง

## 3. โรคประจำตัว: บันทึกค่าที่วัดเองที่บ้านไปให้หมอดู

playbook `doctor-visit` (ขั้น 2 รายการยา · ขั้น 3 คำถาม · ขั้น 4 การ์ด 1 หน้า) ส่วนแบบบันทึกค่ารายวันประกอบเพิ่มตาม `playbook-template` (skill `superuser` หัวข้อ 2) · agent `health-organizer` · skill `doctor-visit-prep` · `medication-schedule`
**ผลลัพธ์:** `home-readings.csv` (บันทึกรายวัน) · `visits/<ปี-เดือน-วัน>-<เรื่อง>.md` สรุปหน้าเดียวไปนัดหน้า · **รออนุมัติ:** ซื้อเครื่องวัด ตั้งการแจ้งเตือนในแอปหรือปฏิทิน

### ข้อมูล (ผู้ใช้กรอก)

- ทำให้ใคร / โรคประจำตัวตามที่แพทย์บอก:
- ค่าที่แพทย์ให้วัดเอง (ความดัน · น้ำตาลปลายนิ้ว · น้ำหนัก · อื่น ๆ) และวัดวันละกี่ครั้ง เวลาไหน:
- เกณฑ์หรือตัวเลขที่แพทย์บอกว่าถ้าเกินให้ทำอะไร (ตามคำแพทย์ตรงตัว · ไม่มีปล่อยว่าง):
- เครื่องวัดที่ใช้ (ยี่ห้อ รุ่น):
- ค่าที่จดไว้แล้ว (รูปสมุด หรือไฟล์):
- วันนัดครั้งถัดไป:

### ต้องมีในผลงาน

1. แบบบันทึกรายวัน: วันที่ · เวลา · ค่า · หน่วย · ก่อน/หลังกินยา · หมายเหตุ (นอนน้อย · ลืมกินยา · ไม่สบาย)
2. ค่าที่จดไว้แล้วคัดลงแบบบันทึกตรงตัว
3. สรุปหน้าเดียวไปนัดหน้า: ตารางค่าช่วงก่อนนัด (ไม่ตีความ ไม่บอกว่าคุมได้ดีหรือไม่) · วันที่ลืมวัดหรือลืมกินยา · คำถาม 3–5 ข้อ
4. ถ้าแพทย์ให้เกณฑ์ไว้: คัดเกณฑ์และสิ่งที่ต้องทำตามคำแพทย์ใส่หัวกระดาษ · ไม่ได้ให้ไว้ → เขียนว่า "ยังไม่มีเกณฑ์จากแพทย์" และใส่คำถามนี้ในรายการถามแพทย์

### กฎเฉพาะฉบับนี้

- ห้ามตั้งเกณฑ์ปกติหรือผิดปกติเอง · ห้ามแนะนำปรับยาตามค่าที่วัดได้
- ผู้ใช้เล่าอาการฉุกเฉินร่วมกับค่าที่วัด → บอกให้โทร 1669 ทันที แล้วหยุดงานอื่น

## 4. ตรวจงานสุขภาพก่อนใช้

playbook `review` · agent `health-organizer` + agent ตัวใหม่ (มุมเภสัชกร / พยาบาลที่อ่านเอกสาร)
**ผลลัพธ์:** คำตัดสิน `ผ่าน / แก้ก่อนใช้` · **ไม่แก้ไฟล์เอง**

### ข้อมูล (ผู้ใช้กรอก)

- ไฟล์ที่จะให้ตรวจ (ตารางยา · สรุปหลังพบแพทย์ · แผนตรวจ):

### ต้องมีในผลงาน

1. คำตัดสิน 1 บรรทัด
2. ตารางปัญหา: ตำแหน่ง · ปัญหา (ไม่ตรงฉลาก · มีการวินิจฉัยหรือขนาดยาที่ไม่ได้มาจากแพทย์ · ข้อมูลสิทธิเก่า · ขาดการแพ้) · ระดับ · วิธีแก้
3. ข้อที่ตรวจแล้วผ่าน
