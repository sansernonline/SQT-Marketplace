# prompt / personal-life — ชุดคำสั่งพร้อมวางสำหรับงานส่วนตัว

ใช้คู่กับ plugin `personal-life` · 1 ไฟล์ = 1 กลุ่มสถานการณ์ในชีวิต · ในไฟล์มีหลายฉบับ แต่ละฉบับทำงาน 1 ชิ้น

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์ส่วนตัว** (โฟลเดอร์เดียวใช้ได้ทุกไฟล์)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วาง statement สแกนเอกสาร โน้ตประชุม ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้าย `ทำข้อ N`
4. ของที่ย้อนไม่ได้ (ส่งข้อความ · จอง · ยกเลิกสมาชิก · เปลี่ยนรหัสผ่าน · อายัดบัตร · ล้างเครื่อง) agent เตรียมไว้ใน "รออนุมัติ" ให้คุณทำเอง

## รายการไฟล์

| ไฟล์ | ใช้เมื่อ | ฉบับในไฟล์ |
