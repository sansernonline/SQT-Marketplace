# prompt-career-change — เปลี่ยนทาง: ปรับโปรไฟล์ เปลี่ยนสายงาน กลับมาทำงาน

ยังไม่ได้ทดสอบจริง

ใช้คู่กับ plugin `personal-life` · ไฟล์นี้รวม prompt 3 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์งานอาชีพ** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · ไม่รู้ปล่อยว่างได้
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1` หรือ `ทำข้อ 1 และ 2`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `personal-life` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · สรุปงานตอนจบ) อยู่ในแกนของ plugin `superuser` ที่ skill นั้นใช้ร่วม ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · skill ที่อ้างข้าม plugin (ชื่อ plugin อยู่ในวงเล็บ) ไม่ได้ติดตั้ง → ข้ามแล้วบอกในรายงาน · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบเพดานรอบ (งานกลาง 3 · งานใหญ่หรืองานเสี่ยง 5) ยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 3

**ขอบเขต:** ไม่แต่งประสบการณ์ ตำแหน่ง ตัวเลข หรือวุฒิ · ตัวเลขเงินเดือนตลาดต้องมีแหล่งและปี · การกดส่งใบสมัคร ส่งอีเมล หรือตอบรับข้อเสนอ อยู่ใน "รออนุมัติ" เสมอ · ข้อพิพาทแรงงาน → จัดข้อเท็จจริงให้ แล้วแนะนำศาลแรงงานหรือทนาย

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด ไม่กำหนด → ใช้ชื่อในตาราง

## 1. ปรับ CV และ LinkedIn ทั้งชุด

playbook `profile-refresh` · agent `career-coach` · skill `resume-th-en` · `linkedin-profile`
**ผลลัพธ์:** `cv/CV_<ชื่อ>_TH.md` · `cv/CV_<ชื่อ>_EN.md` (+ `.docx`) · `linkedin.md`

### ข้อมูล (ผู้ใช้กรอก)

- CV เดิม (path ไฟล์):
- สายงานที่อยากไปต่อ (เดิม / เปลี่ยนสาย → สายอะไร):
- ประวัติงานที่ยังไม่อยู่ใน CV:
- ใบรับรอง หลักสูตร ผลงานล่าสุด:
- ต้องการกี่ภาษา:

### ต้องมีในผลงาน

1. CV ไทยและอังกฤษที่เนื้อหาตรงกันทุกบรรทัด (แก้ภาษาหนึ่ง → แก้อีกภาษาในรอบเดียวกัน)
2. ตัดข้อมูลที่ไม่ควรมีตามธรรมเนียมสากล (ตาม `resume-th-en`) และบอกว่าตัดอะไรเพราะอะไร
3. bullet แบบการกระทำ + ผล + ตัวเลข · ไม่มีตัวเลข → `[ใส่ตัวเลข]`
4. LinkedIn: headline · About · Featured · คำค้นที่ recruiter ใช้
5. รายการช่องว่างที่ควรเติม (ใบรับรอง · ผลงาน) เรียงตามผลต่องานเป้าหมาย

## 2. เปลี่ยนสายงาน

playbook `profile-refresh` (ขั้น 2 ทำ 2 รอบ: สายเดิมกับสายใหม่ เพื่อหาทักษะที่ใช้ข้ามสายได้) · agent `career-coach` · skill `resume-th-en` · `linkedin-profile` · `salary-negotiation`
**ผลลัพธ์:** `career-change/<สายใหม่>-plan.md` · CV ฉบับสายใหม่ใน `cv/` · **รออนุมัติ:** สมัครคอร์สหรือสอบที่ต้องจ่ายเงิน · ลาออกจากงานเดิม

### ข้อมูล (ผู้ใช้กรอก)

- สายงานปัจจุบัน / อายุงาน:
- สายที่อยากไป และเหตุผล:
- ทักษะ งานอดิเรก หรือโปรเจกต์ที่เกี่ยวกับสายใหม่:
- เวลาที่ใช้เรียนเพิ่มได้ต่อสัปดาห์ / งบเรียน:
- รายได้ต่ำสุดที่รับได้ช่วงเปลี่ยนสาย:
- รายจ่ายต่อเดือน / เงินสำรองที่มี:
- ลาออกก่อนแล้วค่อยหา หรือหาไปทำงานไป:

### ต้องมีในผลงาน

1. ตารางทักษะ: สายใหม่ต้องการ (จากประกาศงานจริงอย่างน้อย 5 ประกาศ ติดวันที่ดู) → มีแล้วพร้อมหลักฐาน · ใช้ข้ามสายได้ · ยังขาด
2. แผนเติมช่องว่าง 3–6 เดือน: ทักษะ · วิธีเรียน · ผลงานที่จะทำให้ดูได้ · ค่าใช้จ่าย `(รอยืนยัน)` ถ้ายังไม่ได้ตรวจราคาจริง
3. ตำแหน่งทางเข้า (ตำแหน่งที่ใช้ประสบการณ์เดิมได้มากที่สุด) 2–3 ตำแหน่ง
4. CV ฉบับสายใหม่ที่เรียงทักษะที่ใช้ข้ามสายได้ขึ้นก่อน · ไม่แต่งประสบการณ์ในสายใหม่
5. ข้อมูลเงินเดือนตลาดของตำแหน่งทางเข้า พร้อมแหล่งและปี เทียบกับรายได้ต่ำสุดที่รับได้
6. คำตอบคำถาม "ทำไมเปลี่ยนสาย" สำหรับสัมภาษณ์ ไทยและอังกฤษ

### กฎเฉพาะฉบับนี้

- ไม่แนะนำให้ลาออกก่อนมีรายได้ใหม่โดยไม่บอกตัวเลขเงินที่ต้องมีสำรองตามรายจ่ายที่ผู้ใช้ให้มา

## 3. กลับมาทำงานหลังหยุดไปนาน

playbook `profile-refresh` · agent `career-coach` + `interview-coach` · skill `resume-th-en` · `linkedin-profile` · `interview-prep`
**ผลลัพธ์:** `return-to-work.md` · CV ฉบับใหม่ใน `cv/` · **รออนุมัติ:** กดส่งใบสมัคร · ติดต่อที่ทำงานเก่า

### ข้อมูล (ผู้ใช้กรอก)

- หยุดไปช่วงไหน กี่ปี:
- เหตุผลที่หยุด (เลี้ยงลูก · ดูแลพ่อแม่ · ป่วย · เรียนต่อ · ทำธุรกิจ · อื่น ๆ — บอกเท่าที่สบายใจ):
- งานล่าสุดก่อนหยุด:
- ช่วงที่หยุด ได้ทำอะไรที่เกี่ยวกับงานบ้าง (คอร์ส · งานอิสระ · อาสา):
- อยากกลับสายเดิม หรือเปลี่ยนสาย / เต็มเวลา หรือ part-time:

### ต้องมีในผลงาน

1. CV ที่ใส่ช่วงหยุดตามจริงในบรรทัดเดียว ไม่ซ่อนและไม่อธิบายยาว
2. รายการสิ่งที่เปลี่ยนไปในสายงานช่วงที่หยุด (เครื่องมือ · ทักษะที่ประกาศงานขอ) จากประกาศงานจริง ติดวันที่ดู
3. แผนอัปเดตทักษะ 4–8 สัปดาห์ก่อนเริ่มสมัคร
4. คำตอบเรื่องช่องว่างในประวัติ 30 วินาที ไทยและอังกฤษ + ชุดซ้อมจาก `interview-coach` (หัวหน้าทีมพาซ้อมสด) ถ้าผู้ใช้ต้องการ
5. รายชื่อคนเก่าที่ควรทักกลับ และร่างข้อความทัก

### กฎเฉพาะฉบับนี้

- ไม่ถามรายละเอียดสุขภาพหรือครอบครัวเกินที่ผู้ใช้เล่า · ไม่ใส่เรื่องส่วนตัวลง CV เว้นแต่ผู้ใช้สั่ง
- เปลี่ยนสายด้วย → ทำฉบับ 2 ก่อน
