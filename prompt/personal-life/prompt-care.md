# prompt-care — ดูแลคนและสัตว์ในบ้าน: ผู้สูงอายุ ลูก สัตว์เลี้ยง

ยังไม่ได้ทดสอบจริง

ใช้คู่กับ plugin `personal-life` · ไฟล์นี้รวม prompt 3 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์บ้าน** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วางรูปบิล ใบเสนอราคา เอกสารรถ ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1 และ 4`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `personal-life` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · สรุปงานตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · skill ที่อ้างข้าม plugin (ชื่อ plugin อยู่ในวงเล็บ) ไม่ได้ติดตั้ง → ข้ามแล้วบอกในรายงาน · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบเพดานรอบ (งานกลาง 3 · งานใหญ่หรืองานเสี่ยง 5) ยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 3

**ขอบเขต:** อัตราค่าไฟ ค่า Ft ภาษีรถ เบี้ย พ.ร.บ. (พระราชบัญญัติคุ้มครองผู้ประสบภัยจากรถ) และสิทธิผู้สูงอายุ ตรวจกับแหล่งทางการรอบนี้ ติดวันที่ · ไม่วินิจฉัยโรคของคนหรือสัตว์ · การจ่ายเงิน จ้างช่าง ต่อภาษี ตั้งหักบัญชีอัตโนมัติ อยู่ใน "รออนุมัติ"

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด ไม่กำหนด → ใช้ชื่อในตาราง

## 1. เริ่มดูแล: พ่อแม่สูงอายุ · ลูกเข้าโรงเรียน · สัตว์เลี้ยงตัวใหม่

playbook `care-setup` · agent `family-planner` · skill `elder-care` · `kids-school` · `pet-care`
**ผลลัพธ์:** `care/<ชื่อ>.md` แฟ้มเดียวต่อคนหรือตัว · **รออนุมัติ:** ลงทะเบียนสิทธิ จ่ายค่าเทอม

### ข้อมูล (ผู้ใช้กรอก)

- ดูแลใคร (ผู้สูงอายุ / ลูก / สัตว์เลี้ยง) · อายุ:
- เรื่องที่ต้องจัด (นัดหมอ · สิทธิ · ปรับบ้าน · ย้ายโรงเรียน · ค่าเทอม · วัคซีน · ขึ้นทะเบียน):
- ใครช่วยดูแลบ้าง:
- เอกสารที่มี (path):

### ต้องมีในผลงาน

1. ผู้สูงอายุ: สิทธิที่ได้ (เบี้ยยังชีพ · สิทธิรักษา) พร้อมวิธีขอ · จุดเสี่ยงล้มในบ้านและวิธีแก้ · บันทึกส่งต่อผู้ดูแล
2. ลูก: ปฏิทินเทอม · ค่าใช้จ่ายทั้งปี · เอกสารสมัครหรือย้าย · ลดหย่อนภาษีบุตร (ตรวจกับกรมสรรพากรรอบนี้ ติดวันที่)
3. สัตว์เลี้ยง: ตารางวัคซีน · ขึ้นทะเบียนและไมโครชิป · ยาป้องกันเห็บหมัดพยาธิตามรอบ
4. วันครบกำหนดทุกเรื่อง ใส่ตารางเดียว

## 2. พ่อแม่ออกจากโรงพยาบาล ต้องมีคนดูแลที่บ้าน

playbook `care-setup` (ขั้น 1 สิทธิที่เกี่ยว · ขั้น 2 บันทึกประจำตัว ยา นัดแพทย์ เช็กลิสต์ป้องกันการหกล้ม · ขั้น 3 ไฟล์เตือน .ics · ขั้น 4 ตรวจ) · agent `family-planner` · skill `elder-care`
**ผลลัพธ์:** หัวข้อ "ดูแลที่บ้าน" ใน `care/<ชื่อ>.md` (ตารางเวรดูแล · บันทึกส่งต่อ · ปรับบ้าน · เทียบผู้ดูแลหรือศูนย์ดูแล) · **รออนุมัติ:** จ้างผู้ดูแล จ่ายมัดจำศูนย์ดูแล ซื้อหรือเช่าอุปกรณ์ (เตียง รถเข็น) ยื่นขอสิทธิ

### ข้อมูล (ผู้ใช้กรอก)

- พ่อหรือแม่ อายุ / ออกจากโรงพยาบาลวันไหน:
- สิ่งที่แพทย์สั่งตอนออก (ใบสรุป ใบนัด ฉลากยา — path หรือเล่า):
- ช่วยตัวเองได้แค่ไหน (เดินเอง · ใช้ไม้เท้า · รถเข็น · ติดเตียง):
- คนในบ้านที่ช่วยได้ และเวลาที่ว่าง:
- งบต่อเดือนสำหรับผู้ดูแลหรือศูนย์ (ถ้าคิดจะจ้าง):
- ผู้ดูแลหรือศูนย์ที่กำลังดู (ลิงก์ · ใบเสนอราคา):

### ต้องมีในผลงาน

1. สิ่งที่แพทย์สั่งตอนออก คัดตามใบสรุปหรือคำผู้ใช้ตรงตัว · ยาคัดจากฉลาก · นัดติดตาม · อาการที่แพทย์บอกให้กลับโรงพยาบาล
2. ตารางเวรดูแล 7 วัน: ช่วงเวลา · ใครดูแล · งาน (ยา · อาหาร · พาเดิน · พาไปนัด) · ช่วงที่ไม่มีคน
3. บันทึกส่งต่อผู้ดูแล 1 หน้า · เบอร์ติดต่อ · 1669 เมื่อฉุกเฉิน
4. ปรับบ้านตามระดับที่ช่วยตัวเองได้ จาก `elder-care` (ห้องนอนชั้นล่าง · ราวจับ · ห้องน้ำ)
5. สิทธิที่เกี่ยว (ผู้สูงอายุ · ผู้พิการ ถ้ามีบัตร · สิทธิรักษาที่บ้าน) พร้อมวิธีขอ — ตรวจกับแหล่งทางการรอบนี้ ติดวันที่
6. ถ้าจะจ้าง: เทียบผู้ดูแลหรือศูนย์ 2–3 แห่ง (ค่าใช้จ่ายต่อเดือน · ทำอะไรบ้าง · ใบอนุญาตหรือการรับรอง ตรวจรอบนี้ · ทดลองกี่วัน) และคำถามที่ต้องถามก่อนตกลง

### กฎเฉพาะฉบับนี้

- การดูแลทางการแพทย์ (แผล สายให้อาหาร ยา) → ทำตามที่แพทย์หรือพยาบาลสอนเท่านั้น · ไม่เพิ่มวิธีเอง
- ค่าจ้างผู้ดูแลตามตลาด ใช้เฉพาะตัวเลขจากใบเสนอราคาหรือแหล่งที่มีลิงก์และวันที่ · ไม่มี → `(รอยืนยัน)`

## 3. สัตว์เลี้ยงป่วยหรือแก่ เตรียมไปหาสัตวแพทย์

playbook `care-setup` (ขั้น 2 บันทึกประจำตัว · ขั้น 3 ไฟล์เตือน · ขั้น 4 ตรวจ) · agent `family-planner` · skill `pet-care`
**ผลลัพธ์:** `care/<ชื่อ>-vet-<ปี-เดือน-วัน>.md` หน้าเดียวพกไปคลินิก · อัปเดต `care/<ชื่อ>.md` หลังพบ · **รออนุมัติ:** นัดคลินิก จ่ายค่ารักษา

### ข้อมูล (ผู้ใช้กรอก)

- สัตว์ (ชนิด · พันธุ์ · อายุ · น้ำหนักล่าสุด):
- ก่อนพบ หรือ หลังพบ:
- อาการ เริ่มเมื่อไร (กิน · ดื่ม · ขับถ่าย · พฤติกรรม · อาเจียน):
- วัคซีนและยาที่ใช้อยู่ (path `care/<ชื่อ>.md` หรือรูปสมุดวัคซีน):
- (หลังพบ) สัตวแพทย์บอกอะไร / ให้ยาอะไร / นัดครั้งถัดไป:

### ต้องมีในผลงาน

1. ก่อนพบ: ไทม์ไลน์อาการตามคำผู้ใช้ · วัคซีนและยาที่ใช้ · คำถาม 3–5 ข้อถึงสัตวแพทย์ · ของที่ต้องพก (สมุดวัคซีน · ตัวอย่างหรือรูปอาเจียนหรืออุจจาระ ถ้ามี)
2. หลังพบ: สิ่งที่สัตวแพทย์บอกตามคำผู้ใช้ · ยาตามฉลากตรงตัว · วันนัดถัดไป
3. สัตว์แก่: ตารางตรวจสุขภาพตามรอบที่สัตวแพทย์แนะนำ (คัดตามคำสัตวแพทย์) ใส่ใน `care/<ชื่อ>.md`

### กฎเฉพาะฉบับนี้

- **ไม่วินิจฉัย ไม่แนะนำยาคน หรือยาที่ซื้อเองให้สัตว์**
- หายใจลำบาก ชัก กินสารพิษ เลือดออกไม่หยุด → บอกให้พาไปโรงพยาบาลสัตว์ทันที แล้วหยุดงานอื่น
