# prompt-papers-and-money — เอกสารสำคัญ รายจ่ายรายเดือน คลังโน้ต

ใช้คู่กับ plugin `personal-life` · ไฟล์นี้รวม prompt 5 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์ส่วนตัว** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วาง statement สแกนเอกสาร โน้ตประชุม ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `personal-life` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · ตารางสถานะตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · อีเมลและปฏิทินอ่านผ่าน plugin หรือ connector ที่ติดตั้ง ไม่มี → ให้ผู้ใช้ export มาวางใน `inbox/` · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**ขอบเขต:** ไม่เก็บรหัสผ่าน เลขบัตร หรือเลขบัญชีเต็มลงไฟล์ (เก็บแค่ 4 ตัวท้าย) · การส่งอีเมล ยกเลิกสมาชิก จองตั๋ว เปลี่ยนรหัสผ่าน หรือตั้งค่าบัญชี อยู่ใน "รออนุมัติ" — ผู้ใช้กดเอง · กฎวีซ่าและพาสปอร์ตตรวจกับแหล่งทางการรอบนี้ ติดวันที่

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด (เช่น `weekly-reviews.md` · `subscriptions.md` · `important-docs.csv` · `decision-journal.md` · `goals/YYYY-Qn.md` · `gift-tracker.md` · `kb/index.md`) ไม่กำหนด → ใช้ชื่อในตาราง

| # | งาน | playbook | ได้ไฟล์ |
|---|---|---|---|
| 1 | ทะเบียนเอกสารสำคัญ | `documents` | `important-docs.csv` |
| 2 | กระเป๋าสตางค์ / บัตรหาย | `documents` (ขั้น 1–2) | `lost/YYYY-MM-DD_<ของที่หาย>.md` |
| 3 | แฟ้มฉุกเฉินของครอบครัว (ถ้าเราป่วยหนักกะทันหัน) | `documents` (ขั้น 1–2 และ 4) | `emergency-file.md` |
| 4 | หาและตัดรายจ่ายรายเดือน | `subscriptions` | `subscriptions.md` |
| 5 | คลังโน้ตส่วนตัว (หาโน้ตไม่เจอ) | — (กลาง: ใช้ skill ตรง) | `kb/index.md` + โครงโน้ต |

ทำประจำ: ฉบับ 1 และ 4 ต้นปี · ฉบับ 3 ปีละครั้ง หรือเมื่อมีประกัน บัญชี หรือสมาชิกในบ้านเปลี่ยน · ใช้ต่อกัน: 1 → 3 (แฟ้มฉุกเฉินอ้างทะเบียนเอกสาร) · ของหาย → 2 → 1 (อัปเดตทะเบียน) · ตรวจก่อนใช้ → `prompt-weekly-routine.md` ฉบับ 4

## 1. ทะเบียนเอกสารสำคัญ

playbook `documents` · agent `doc-caretaker` · skill `important-docs` · `personal-kb`
**ผลลัพธ์:** `important-docs.csv` · ชื่อไฟล์สแกนที่ค้นเจอ · **รออนุมัติ:** ตั้งเตือนในปฏิทิน · รันสคริปต์เปลี่ยนชื่อไฟล์

### ข้อมูล (ผู้ใช้กรอก)

- ทำให้ใครบ้างในบ้าน:
- โฟลเดอร์สแกนเอกสาร (path):
- เอกสารที่รู้ว่ามี (บัตรประชาชน · พาสปอร์ต · โฉนด · เล่มรถ · ประกัน · สัญญา · วุฒิการศึกษา):
- ตัวจริงเก็บไว้ที่ไหน:

### ต้องมีในผลงาน

1. ทะเบียนตามหมวด: เอกสาร · ของใคร · ตัวจริงอยู่ไหน · สแกนอยู่ไหน · วันหมดอายุ · ต่อที่ไหน
2. เรียงเอกสารที่จะหมดอายุใน 6 เดือน

4. เอกสารที่ควรมีแต่ยังไม่เจอ

## 2. กระเป๋าสตางค์ / บัตรหาย

playbook `documents` (ขั้น 1–2: รายการเอกสารและที่ต่อ + ขั้นสุดท้าย reviewer ตัวใหม่ตรวจ) · agent `doc-caretaker` · skill `important-docs` · `digital-hygiene` (ส่วนซิมและบัญชีธนาคาร)
**ผลลัพธ์:** `lost/YYYY-MM-DD_<ของที่หาย>.md` (รายการของที่หาย · ลำดับสิ่งที่ต้องทำ · เอกสารที่ต้องใช้ทำใหม่) · **รออนุมัติ:** โทรอายัดบัตร · แจ้งความ · ยื่นทำบัตรใหม่ — ผู้ใช้ทำเองทุกข้อ

### ข้อมูล (ผู้ใช้กรอก)

- หายอะไร (กระเป๋าสตางค์ · บัตรประชาชน · บัตรเดบิต / เครดิต · ใบขับขี่ · พาสปอร์ต · มือถือ):
- หายเมื่อไร ที่ไหน / ถูกขโมยหรือทำตกหาย:
- ในกระเป๋ามีบัตรอะไรบ้าง (ถ้ามี `important-docs.csv` ให้อ่านจากไฟล์นั้น):
- มีสแกนหรือสำเนาเอกสารเก็บไว้ไหม (path):

### ต้องมีในผลงาน

1. ลำดับงาน เรียงจากเสียเงินได้เร็วสุด: อายัดบัตรธนาคารและบัตรเครดิตก่อน → เอกสารที่ใช้สวมรอยได้ → เอกสารที่แค่ต้องทำใหม่
2. ตารางต่อรายการ: ของที่หาย · ติดต่อที่ไหน · ช่องทางติดต่อ (ตรวจจากเว็บทางการรอบนี้) · เอกสารที่ต้องใช้ · ต้องแจ้งความหรือลงบันทึกไหม `(รอยืนยัน)`
3. สิ่งที่ต้องเฝ้าดูหลังจากนี้: รายการแปลกใน statement · การขอเปลี่ยนซิม · สินเชื่อในชื่อเรา (ตาม `digital-hygiene`)
4. อัปเดต `important-docs.csv`: เลขท้ายบัตรใหม่ · วันหมดอายุใหม่ · ของที่ยังรอ
5. ถ้ามือถือหายด้วย → ชี้ไป `prompt-online-safety.md` ฉบับ 3

### กฎเฉพาะฉบับนี้

- เบอร์อายัดบัตร ขั้นตอนทำบัตรประชาชนใหม่ และค่าธรรมเนียม ห้ามเขียนจากความจำ → ตรวจกับเว็บทางการของธนาคารและหน่วยงานรอบนี้ ติดวันที่
- ไม่ขอเลขบัตรเต็ม ใช้ 4 ตัวท้ายพอ

## 3. แฟ้มฉุกเฉินของครอบครัว

playbook `documents` (ขั้น 1–2 และ 4: รายการเอกสาร · ที่เก็บ · เตือนทบทวน) · agent `doc-caretaker` · skill `important-docs` · `digital-hygiene` (การเข้าถึงบัญชีกรณีฉุกเฉิน)
**ผลลัพธ์:** `emergency-file.md` 1–2 หน้า ที่คนในบ้านเปิดแล้วรู้ว่าต้องหาอะไรที่ไหน · **รออนุมัติ:** แชร์ไฟล์ให้คนในบ้าน · ตั้งค่าผู้ติดต่อฉุกเฉินใน password manager หรือบัญชี Apple / Google

### ข้อมูล (ผู้ใช้กรอก)

- ทำให้ใคร และใครจะเป็นคนเปิดแฟ้มนี้ (คู่ · ลูก · พี่น้อง):
- ประกันที่มี (ชีวิต · สุขภาพ · อุบัติเหตุ) และกรมธรรม์อยู่ไหน:
- ธนาคาร / กองทุน / หุ้น ที่มีบัญชี (ชื่อสถาบัน + 4 ตัวท้ายเท่านั้น):
- โรงพยาบาลประจำ / โรคประจำตัว / ยาที่กินประจำ:
- ยาหรืออาหารที่แพ้:
- คนที่ต้องโทรหาก่อน (นายจ้าง · ญาติ · ทนายหรือนักบัญชีถ้ามี):
- ใช้ password manager ไหม:

### ต้องมีในผลงาน

1. หน้าแรก "ถ้าเกิดเรื่องวันนี้ ทำ 5 อย่างนี้ก่อน" เรียงลำดับ
2. ที่อยู่ของเอกสาร: อ้างแถวใน `important-docs.csv` ไม่คัดเนื้อหาซ้ำ
3. รายการประกันและสถาบันการเงิน: ชื่อ · 4 ตัวท้าย · เบอร์ติดต่อจากเว็บทางการ · เอกสารที่ทายาทหรือคนดูแลต้องใช้ `(รอยืนยัน)`
4. ข้อมูลสุขภาพที่หมอต้องรู้: โรงพยาบาลประจำ · โรคประจำตัว · ยา · ยาหรืออาหารที่แพ้ (ไม่ได้ข้อมูล → ใส่ `(รอยืนยัน)` ห้ามเดา)
5. วิธีเข้าถึงบัญชีดิจิทัลโดยไม่เขียนรหัสผ่าน: ผู้ติดต่อฉุกเฉินของ password manager · บัญชี Apple / Google (ตาม `digital-hygiene`)
6. วันทบทวนแฟ้มครั้งถัดไป

### กฎเฉพาะฉบับนี้

- ไม่มีรหัสผ่าน PIN หรือเลขบัญชีเต็มในแฟ้ม ไม่ว่าผู้ใช้จะขอให้ใส่หรือไม่ — บอกเหตุผลและเสนอวิธีข้อ 5 แทน
- พินัยกรรม มรดก และการเบิกประกัน เป็นเรื่องกฎหมายและการเงิน → เขียนเป็นคำถามที่ต้องถามทนายหรือบริษัทประกัน พร้อม `(รอยืนยัน)` · งานทบทวนประกันส่งต่อ plugin `trading-finance` ถ้าติดตั้ง
