# prompt-family-care — ดูแลสุขภาพคนในบ้าน: พ่อแม่หลายโรค นอนโรงพยาบาล การ์ดฉุกเฉิน

ยังไม่ได้ทดสอบจริง

ใช้คู่กับ plugin `personal-life` · ไฟล์นี้รวม prompt 3 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์สุขภาพ** (แยกโฟลเดอร์ต่อคน เช่น `health/me/` · `health/mom/`)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · ไม่รู้ปล่อยว่างได้
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 2`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `personal-life` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · สรุปงานตอนจบ) อยู่ในแกนของ plugin `superuser` ที่ skill นั้นใช้ร่วม ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบเพดานรอบ (งานกลาง 3 · งานใหญ่หรืองานเสี่ยง 5) ยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 3

**ขอบเขต (ห้ามข้าม):** งานจัดระเบียบเท่านั้น · **ไม่วินิจฉัย ไม่แปลผลตรวจว่าเป็นโรคอะไร ไม่บอกขนาดยา ไม่แนะนำให้หยุดหรือเปลี่ยนยา** · ตารางยาคัดจากฉลากหรือใบสั่งแพทย์ตรงตัว · อาการฉุกเฉิน (เจ็บหน้าอก หายใจไม่ออก ปากเบี้ยว แขนขาอ่อนแรง หมดสติ) → บอกให้โทร 1669 ทันที แล้วหยุดงานอื่น · สิทธิการรักษา (ประกันสังคม · บัตรทอง · ข้าราชการ) ตรวจกับแหล่งทางการรอบนี้ ติดวันที่ · การจองโรงพยาบาล ซื้อแพ็กเกจ อยู่ใน "รออนุมัติ"

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด ไม่กำหนด → ใช้ชื่อในตาราง

## 1. พ่อแม่มีหลายโรค ยาจากหลายโรงพยาบาล

playbook `medication-routine` · agent `health-organizer` · skill `medication-schedule` · `doctor-visit-prep`
**ผลลัพธ์:** `medications.md` ตารางยารวมทุกที่ · `appointments.md` นัดทุกโรงพยาบาลในตารางเดียว · บันทึกส่งต่อผู้ดูแล · **รออนุมัติ:** ตั้งการแจ้งเตือนในแอปหรือปฏิทิน · แชร์ไฟล์ให้ผู้ดูแลหรือญาติ

### ข้อมูล (ผู้ใช้กรอก)

- ทำให้ใคร / อายุ:
- ไปรักษาที่ไหนบ้าง (โรงพยาบาล · คลินิก · แผนก):
- รูปฉลากยาทุกตัวจากทุกที่ รวมยาซื้อเองและอาหารเสริม (path):
- ใบนัดทุกที่ (รูปหรือวันที่):
- ใครให้ยาในแต่ละช่วงวัน (ลูก · ผู้ดูแล · กินเอง):
- เบอร์ติดต่อ (ญาติ · โรงพยาบาลหรือเภสัชกรที่โทรถามได้):
- ปัญหาที่เจอ (ลืมกิน · กินซ้ำ · ยาหมดไม่ทันนัด · กลืนเม็ดใหญ่ไม่ได้):

### ต้องมีในผลงาน

1. ตารางยารายวันคัดจากฉลากตรงตัว · เพิ่มคอลัมน์ "ได้มาจากที่ไหน" ทุกแถว
2. ยาชื่อซ้ำ ชื่อคล้ายกัน หรือดูเหมือนตัวเดียวกันจากคนละที่ → ใส่รายการ "ถามเภสัชกรหรือแพทย์" พร้อมชื่อตามฉลากทั้ง 2 ตัว · **ไม่ตัดสินเองว่าตัวไหนเลิก**
3. ปฏิทินนัดทุกที่ เรียงตามวัน · วันรับยาแต่ละที่เทียบกับวันยาหมด
4. บันทึกส่งต่อผู้ดูแล 1 หน้า: ใครให้ยาตัวไหนเวลาไหน · ติ๊กว่าให้แล้ว · เบอร์ที่โทรถามเมื่อสงสัย · 1669 เมื่อฉุกเฉิน
5. ปัญหาการกินยาที่ผู้ใช้เล่า (เช่น กลืนยาก) → ใส่เป็นคำถามถึงเภสัชกร ไม่แนะนำให้บดหรือแบ่งยาเอง

## 2. ก่อนผ่าตัดหรือนอนโรงพยาบาล และหลังกลับบ้าน

playbook `doctor-visit` · agent `health-organizer` · skill `doctor-visit-prep` · `medication-schedule`
**ผลลัพธ์:** `visits/<ปี-เดือน-วัน>-admit.md` (ก่อนเข้า · ระหว่างนอน · หลังกลับบ้าน ในไฟล์เดียว) · **รออนุมัติ:** จองห้อง วางเงินมัดจำ · เอกสารยินยอมรักษาให้ผู้ป่วยหรือญาติเซ็นเอง agent ไม่กรอกแทน

### ข้อมูล (ผู้ใช้กรอก)

- ใครจะเข้าโรงพยาบาล / โรงพยาบาล / วันนัด:
- ผ่าตัดหรือรักษาเรื่องอะไร (ตามที่แพทย์บอก):
- สิทธิที่จะใช้ (ประกันสังคม · บัตรทอง · ข้าราชการ · ประกันเอกชน):
- ยาและอาหารเสริมที่กินอยู่ (path ฉลาก หรือ `medications.md`):
- แพ้ยาหรืออาหาร:
- (หลังกลับบ้าน) ใบสรุปตอนออก ยากลับบ้าน ใบนัด (path หรือเล่า):

### ต้องมีในผลงาน

1. ก่อนเข้า: คำถามถึงแพทย์ (ยาตัวไหนต้องงดก่อนผ่าตัด งดกี่วัน · งดน้ำงดอาหารกี่ชั่วโมง · นอนกี่วัน) — **คำตอบมาจากแพทย์เท่านั้น** agent ไม่ตอบเอง
2. คำถามถึงฝ่ายการเงินหรือฝ่ายสิทธิของโรงพยาบาล: สิทธิครอบคลุมอะไร · ส่วนที่ต้องจ่ายเองประมาณเท่าไร · ต้องวางเงินไหม
3. เช็กลิสต์ของที่ต้องเตรียม: บัตร · เอกสารสิทธิ · รายการยาและการแพ้ · ของใช้ · ใครเฝ้า
4. หลังกลับบ้าน: สิ่งที่แพทย์สั่งตามใบสรุปหรือคำผู้ใช้ · ยากลับบ้านตามฉลาก (ต่อเข้า `medications.md`) · นัดตัดไหมหรือติดตาม · อาการที่แพทย์บอกให้กลับมาโรงพยาบาล (คัดตามคำแพทย์)
5. ตารางวันสำคัญ: วันเข้า · วันผ่าตัด · วันนัดติดตาม · วันยาหมด

### กฎเฉพาะฉบับนี้

- ผู้ใช้ถามว่าต้องงดยาไหม → ตอบว่าต้องถามแพทย์ผู้ผ่าตัด แล้วใส่ในรายการคำถาม · ห้ามตอบจากความรู้ทั่วไป

## 3. การ์ดสุขภาพฉุกเฉินของคนในบ้าน

playbook `medication-routine` (ขั้น 4 รายการแพ้ยาและรายการยาสำหรับพก + ขั้นสุดท้าย reviewer ตัวใหม่ตรวจ) · agent `health-organizer` · skill `medication-schedule` · `doctor-visit-prep`
**ผลลัพธ์:** `emergency-card.md` 1 หน้าต่อคน พิมพ์ติดตู้เย็นหรือเก็บในมือถือ · **รออนุมัติ:** แชร์การ์ดในกลุ่มแชตครอบครัวหรือส่งให้ผู้ดูแล

### ข้อมูล (ผู้ใช้กรอก)

- ทำให้ใครบ้าง (ชื่อ · อายุ):
- โรคประจำตัวที่แพทย์วินิจฉัยแล้ว (คัดจากเอกสาร · ไม่แน่ใจไม่ต้องใส่):
- ยาที่กินประจำ (path ฉลาก หรือ `medications.md`):
- แพ้ยา แพ้อาหาร:
- สิทธิรักษา และโรงพยาบาลที่รักษาประจำ:
- ผู้ติดต่อฉุกเฉิน 2 คน:

### ต้องมีในผลงาน

1. การ์ด 1 หน้าต่อคน: ชื่อ · อายุ · โรคประจำตัวตามเอกสารแพทย์ · ยาประจำ · การแพ้ (ตัวใหญ่ อยู่บนสุด) · สิทธิรักษาและโรงพยาบาลประจำ · ผู้ติดต่อฉุกเฉิน · 1669
2. ช่อง "อัปเดตล่าสุด" พร้อมวันที่ และรอบทบทวน (ทุกครั้งที่ยาเปลี่ยน หรืออย่างน้อยทุก 6 เดือน)
3. ที่เก็บ: ตู้เย็น · กระเป๋าสตางค์ · หน้าจอล็อกมือถือ · บอกว่าข้อมูลไหนไม่ควรโชว์บนหน้าจอล็อก (เลขบัตรประชาชน)

### กฎเฉพาะฉบับนี้

- ข้อมูลสุขภาพเป็นข้อมูลส่วนตัว · แชร์เฉพาะคนที่ต้องใช้ตอนฉุกเฉิน และอยู่ใน "รออนุมัติ" ทุกครั้ง
- ไม่ใส่โรคที่ผู้ใช้ "คิดว่าเป็น" แต่ไม่มีเอกสารแพทย์
