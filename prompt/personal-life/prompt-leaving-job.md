# prompt-leaving-job — ออกจากงาน: ลาออกอย่างดี ถูกเลิกจ้าง

ใช้คู่กับ plugin `personal-life` · ไฟล์นี้รวม prompt 2 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์งานอาชีพ** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · ไม่รู้ปล่อยว่างได้
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1` หรือ `ทำข้อ 1 และ 2`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `personal-life` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · สรุปงานตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · skill ที่อ้างข้าม plugin (ชื่อ plugin อยู่ในวงเล็บ) ไม่ได้ติดตั้ง → ข้ามแล้วบอกในรายงาน · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบเพดานรอบ (งานกลาง 3 · งานใหญ่หรืองานเสี่ยง 5) ยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 3

**ขอบเขต:** ไม่แต่งประสบการณ์ ตำแหน่ง ตัวเลข หรือวุฒิ · ตัวเลขเงินเดือนตลาดต้องมีแหล่งและปี · การกดส่งใบสมัคร ส่งอีเมล หรือตอบรับข้อเสนอ อยู่ใน "รออนุมัติ" เสมอ · ข้อพิพาทแรงงาน → จัดข้อเท็จจริงให้ แล้วแนะนำศาลแรงงานหรือทนาย

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด ไม่กำหนด → ใช้ชื่อในตาราง

## 1. ลาออกอย่างดี

playbook `offer-negotiation` (ใช้ขั้น 1 เก็บตัวเลขจากเอกสารจริง · ขั้น 5 ร่างสิ่งที่จะพูดหรือเขียน · ขั้น 6 ตรวจ · ขั้น 2–4 ใช้เฉพาะเมื่อที่เดิมยื่น counter-offer · ไม่มี playbook ที่ตรงทั้งตัว จึงปรับตามหัวข้อ 2 ของ `superuser`) · agent `career-coach` · skill `salary-negotiation` · `human-writing`
**ผลลัพธ์:** `leaving/<ปี-เดือน>-resign.md` · `leaving/resignation-letter.docx` · **รออนุมัติ:** ยื่นใบลาออก · ส่งอีเมลแจ้งทีม · ตอบรับหรือปฏิเสธ counter-offer

### ข้อมูล (ผู้ใช้กรอก)

- วันที่อยากทำงานวันสุดท้าย / วันเริ่มงานใหม่ (ถ้ามี):
- ระยะแจ้งล่วงหน้าตามสัญญาจ้างหรือระเบียบบริษัท (path ไฟล์ ถ้ามี):
- วันลาพักร้อนที่เหลือ · โบนัสหรือเงินที่รอจ่าย · กองทุนสำรองเลี้ยงชีพ:
- งานที่ค้างอยู่และคนที่ต้องรับต่อ:
- ความสัมพันธ์กับหัวหน้า (ดี / เฉย ๆ / ตึง):
- คาดว่าที่เดิมจะยื่น counter-offer ไหม:
- เซ็นสัญญางานใหม่แล้วหรือยัง (path สัญญา ถ้ามี):

### ต้องมีในผลงาน

1. ไทม์ไลน์: วันยื่นใบลาออก → วันทำงานวันสุดท้าย คำนวณจากระยะแจ้งล่วงหน้าในสัญญาของผู้ใช้ · ไม่มีสัญญาให้อ่าน → `(รอยืนยัน)` กับฝ่ายบุคคล (Human Resources: HR)
2. ใบลาออกภาษาไทยแบบสุภาพ (+ อังกฤษถ้าบริษัทใช้) ระบุวันทำงานวันสุดท้าย ไม่ใส่เหตุผลเชิงตำหนิ
3. บทพูดแจ้งหัวหน้า 3 นาที + คำตอบเมื่อถูกถามว่า "ไปไหน ได้เท่าไร"
4. แผนส่งมอบงาน: งาน · สถานะ · ไฟล์อยู่ไหน · คนรับต่อ · วันที่ส่ง
5. รายการเงินและเอกสารที่ต้องได้ก่อนออก (เงินเดือนงวดสุดท้าย · วันลาที่เหลือ · กองทุนสำรองเลี้ยงชีพ · หนังสือรับรองการทำงาน · เอกสารภาษีสิ้นปี) และสิทธิ์ประกันสังคมหลังลาออก — เงื่อนไขและกำหนดเวลาทุกข้อตรวจกับแหล่งทางการรอบนี้ ติดวันที่ตรวจ
6. ถ้ามี counter-offer: ตารางเทียบตามฉบับ 3 ของ `prompt-job-search.md` และคำตอบปฏิเสธอย่างสุภาพ

### กฎเฉพาะฉบับนี้

- ไม่ร่างข้อความที่ต่อว่าบริษัทหรือคนในทีม แม้ผู้ใช้จะโกรธ · เรื่องที่อยากแจ้งจริงจังแยกเป็นข้อเสนอแนะตอนสัมภาษณ์ออก (exit interview)
- ยังไม่ได้เซ็นสัญญางานใหม่ → เตือนในรายการรออนุมัติก่อนยื่นใบลาออก

## 2. ถูกเลิกจ้าง / ถูกบอกให้ออก

playbook `offer-negotiation` (ใช้ขั้น 1 เก็บตัวเลขจากเอกสารจริง · ขั้น 2 ทำตารางเงินที่ควรได้ · ขั้น 6 คำนวณซ้ำทุกช่อง · ไม่มี playbook ที่ตรงทั้งตัว จึงปรับตามหัวข้อ 2 ของ `superuser`) · agent `career-coach` · skill `salary-negotiation` · `human-writing`
**ผลลัพธ์:** `leaving/<ปี-เดือน>-termination.md` · **รออนุมัติ:** เซ็นหนังสือเลิกจ้าง ข้อตกลง หรือใบลาออกที่บริษัทเตรียมให้ · ส่งข้อความถึงบริษัท · ยื่นคำร้องต่อหน่วยงานแรงงาน · ขึ้นทะเบียนว่างงาน

### ข้อมูล (ผู้ใช้กรอก)

- ถูกแจ้งเมื่อไร ด้วยวิธีไหน (วาจา · อีเมล · หนังสือ) และเหตุผลที่บริษัทให้:
- บริษัทขอให้เขียนใบลาออกเอง หรือให้เซ็นเอกสารอะไรไหม:
- วันเริ่มงาน / ตำแหน่ง / เงินเดือนล่าสุด:
- ประเภทการจ้าง (ประจำ · สัญญาจ้างมีกำหนดเวลา · ทดลองงาน):
- เอกสารที่มี (สัญญาจ้าง · สลิปเงินเดือน · หนังสือเลิกจ้าง · แชตหรืออีเมล — path):
- บริษัทเสนอจ่ายอะไรแล้วบ้าง:
- รายจ่ายต่อเดือน / เงินสำรองที่มี:

### ต้องมีในผลงาน

1. ไทม์ไลน์ข้อเท็จจริงเรียงตามวันที่ แยก "มีหลักฐาน" ออกจาก "ผู้ใช้เล่า"
2. ข้อควรระวังก่อนเซ็นอะไร: สิทธิ์อาจต่างกันระหว่าง "ลาออกเอง" กับ "ถูกเลิกจ้าง" (ตรวจกับแหล่งทางการรอบนี้ ติดวันที่ตรวจ) · ขอสำเนาทุกเอกสาร · ขอเวลาอ่านก่อนเซ็น
3. ตารางเงินที่อาจมีสิทธิ์ได้ (ค่าชดเชย · ค่าจ้างแทนการบอกกล่าวล่วงหน้า · วันลาพักร้อนที่เหลือ · เงินเดือนค้าง) เทียบกับที่บริษัทเสนอ · อัตราและเงื่อนไขทุกบรรทัดตรวจกับแหล่งทางการรอบนี้ ติดวันที่ตรวจ ไม่ได้ตรวจ → `ยังไม่ได้ตรวจ` · ตัวเลขคำนวณซ้ำได้
4. ประกันสังคมกรณีว่างงาน: ขั้นตอนขึ้นทะเบียน เอกสาร และกำหนดเวลา `(รอยืนยัน)` จนกว่าจะตรวจกับเว็บทางการรอบนี้ ติดวันที่ตรวจ
5. ร่างข้อความถึงบริษัทเพื่อขอหนังสือเลิกจ้าง หนังสือรับรองการทำงาน หรือทวงเงินที่ยังไม่ได้ — สุภาพ ชัด มีวันที่ขอคำตอบ
6. ถ้าตกลงกันไม่ได้: ช่องทางถัดไป (หน่วยงานคุ้มครองแรงงาน · ศาลแรงงาน · ทนาย) ตรวจช่องทางจากเว็บทางการรอบนี้ ติดวันที่ตรวจ · พร้อมรายการเอกสารที่ต้องเตรียม
7. แผน 30 วันถัดไป: เงินที่ต้องใช้ต่อเดือนตามรายจ่ายที่ผู้ใช้ให้มา · เริ่มหางานใหม่ → `prompt-career-change.md` ฉบับ 1

### กฎเฉพาะฉบับนี้

- ข้อมูลทั่วไป ไม่ใช่คำปรึกษากฎหมาย · ตัวเลขอัตราค่าชดเชยและกำหนดเวลา ห้ามเขียนจากความจำ
- ข้อพิพาทแรงงาน → จัดข้อเท็จจริงให้ แล้วแนะนำศาลแรงงานหรือทนาย ไม่ตัดสินว่าใครถูก
- ผู้ใช้เครียดหรือตกใจ → เริ่มคำตอบด้วยสิ่งที่ต้องทำใน 24 ชั่วโมงแรก (ไม่เซ็นอะไร · เก็บหลักฐาน) ก่อนรายละเอียดอื่น
