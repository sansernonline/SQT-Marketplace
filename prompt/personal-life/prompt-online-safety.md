# prompt-online-safety — ความปลอดภัยบัญชี ถูกแฮก เปลี่ยนมือถือ

ใช้คู่กับ plugin `personal-life` · ไฟล์นี้รวม prompt 3 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์ส่วนตัว** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วาง statement สแกนเอกสาร โน้ตประชุม ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `personal-life` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · ตารางสถานะตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · อีเมลและปฏิทินอ่านผ่าน plugin หรือ connector ที่ติดตั้ง ไม่มี → ให้ผู้ใช้ export มาวางใน `inbox/` · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบ 5 รอบยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 2

**ขอบเขต:** ไม่เก็บรหัสผ่าน เลขบัตร หรือเลขบัญชีเต็มลงไฟล์ (เก็บแค่ 4 ตัวท้าย) · การส่งอีเมล ยกเลิกสมาชิก จองตั๋ว เปลี่ยนรหัสผ่าน หรือตั้งค่าบัญชี อยู่ใน "รออนุมัติ" — ผู้ใช้กดเอง · กฎวีซ่าและพาสปอร์ตตรวจกับแหล่งทางการรอบนี้ ติดวันที่

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด (เช่น `weekly-reviews.md` · `subscriptions.md` · `important-docs.csv` · `decision-journal.md` · `goals/YYYY-Qn.md` · `gift-tracker.md` · `kb/index.md`) ไม่กำหนด → ใช้ชื่อในตาราง

## 2. ถูกแฮก หรือเพิ่งโอนเงินให้มิจฉาชีพ

playbook `digital-safety` (ขั้น 1: ขั้นตอนชั่วโมงแรก · ขั้น 5: ข้อความเตือน) · agent `life-admin` · skill `digital-hygiene` · `polite-message-th-en` (ข้อความแจ้งเพื่อนและครอบครัว)
**ผลลัพธ์:** รายการทำทันทีในคำตอบ (บรรทัดแรกของคำตอบ) · `incidents/YYYY-MM-DD_<เรื่อง>.md` (ลำดับเหตุการณ์ · หลักฐาน · สิ่งที่ทำแล้ว) · **รออนุมัติ:** เปลี่ยนรหัสผ่าน · ออกจากระบบทุกเครื่อง · โทรแจ้งธนาคารให้ระงับบัญชี · แจ้งความ · โพสต์หรือส่งข้อความเตือนเพื่อน — ผู้ใช้ทำเองทุกข้อ

### ข้อมูล (ผู้ใช้กรอก)

- เกิดอะไร (บัญชีถูกยึด · มีคนส่งข้อความยืมเงินในชื่อเรา · โอนเงินไปแล้ว · กดลิงก์หรือลงแอปแปลก · ให้รหัสใช้ครั้งเดียว (OTP) ไป):
- บัญชีไหน (อีเมล · LINE · Facebook · ธนาคาร):
- เกิดเมื่อไร / ยังเข้าบัญชีได้อยู่ไหม:
- ถ้าโอนเงิน: ธนาคารต้นทาง · ยอด · เวลา · บัญชีปลายทาง (ภาพสลิปใน `inbox/`):
- ภาพหน้าจอแชตหรือข้อความหลอก (path):

### ต้องมีในผลงาน

1. บรรทัดแรกของคำตอบ: 3–5 สิ่งที่ต้องทำใน 15 นาทีนี้ เรียงลำดับ ตามขั้นตอนชั่วโมงแรกของ `digital-hygiene`
2. ช่องทางแจ้งธนาคารและหน่วยงานรับแจ้งเหตุออนไลน์ — ตรวจกับแหล่งทางการรอบนี้ ติดวันที่ ห้ามเขียนเบอร์จากความจำ
3. บัญชีอื่นที่อาจโดนต่อ (ใช้รหัสเดียวกัน · ผูกอีเมลเดียวกัน) เรียงจากเสี่ยงสุด
4. ลำดับเหตุการณ์และรายการหลักฐานที่ต้องเก็บไว้แจ้งความ (สลิป · ภาพหน้าจอ · เลขบัญชีปลายทาง)
5. ร่างข้อความเตือนเพื่อนและครอบครัวว่าบัญชีถูกยึด อย่าโอนเงิน
6. หลังเหตุสงบ: ชี้ไปฉบับ 1 เพื่อปิดช่องโหว่ทั้งบ้าน

### กฎเฉพาะฉบับนี้

- เหตุฉุกเฉิน → ตอบขั้นตอนเร่งด่วนทันทีก่อน แล้วค่อยถามช่องที่ขาด
- ไม่ขอและไม่รับรหัสผ่าน รหัส OTP หรือเลขบัตรเต็มจากผู้ใช้ ถ้าผู้ใช้วางมา → บอกให้เปลี่ยนรหัสนั้นทันที และไม่บันทึกลงไฟล์
- ไม่ติดต่อกลับเบอร์หรือลิงก์ที่มิจฉาชีพส่งมา ใช้ช่องทางจากเว็บทางการเท่านั้น
- ไม่สัญญาว่าจะได้เงินคืน

### ต้องมีในผลงาน

1. ถ้าเครื่องหาย: ลำดับทำทันที — ล็อกหรือล้างเครื่องทางไกล · ระงับซิมกับค่าย · แจ้งธนาคาร · ออกจากระบบ LINE และอีเมลจากเครื่องอื่น (ช่องทางติดต่อตรวจจากเว็บทางการรอบนี้)

5. อัปเดตตารางสถานะใน `digital-hygiene.md`
