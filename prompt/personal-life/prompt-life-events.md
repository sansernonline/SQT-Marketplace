# prompt-life-events — เดินทาง ตัดสินใจเรื่องใหญ่ ย้ายบ้าน คนรอบตัว

ยังไม่ได้ทดสอบจริง

ใช้คู่กับ plugin `personal-life` · ไฟล์นี้รวม prompt 5 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์ส่วนตัว** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วาง statement สแกนเอกสาร โน้ตประชุม ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `personal-life` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · สรุปงานตอนจบ) อยู่ในแกนของ plugin `superuser` ที่ skill นั้นใช้ร่วม ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · อีเมลและปฏิทินอ่านผ่าน plugin หรือ connector ที่ติดตั้ง ไม่มี → ให้ผู้ใช้ export มาวางใน `inbox/` · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบเพดานรอบ (งานกลาง 3 · งานใหญ่หรืองานเสี่ยง 5) ยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 3

**ขอบเขต:** ไม่เก็บรหัสผ่าน เลขบัตร หรือเลขบัญชีเต็มลงไฟล์ (เก็บแค่ 4 ตัวท้าย) · การส่งอีเมล ยกเลิกสมาชิก จองตั๋ว เปลี่ยนรหัสผ่าน หรือตั้งค่าบัญชี อยู่ใน "รออนุมัติ" — ผู้ใช้กดเอง · กฎวีซ่าและพาสปอร์ตตรวจกับแหล่งทางการรอบนี้ ติดวันที่

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด (เช่น `weekly-reviews.md` · `subscriptions.md` · `important-docs.csv` · `decision-journal.md` · `goals/YYYY-Qn.md` · `gift-tracker.md` · `kb/index.md`) ไม่กำหนด → ใช้ชื่อในตาราง

| # | งาน | playbook | ได้ไฟล์ |
|---|---|---|---|
| 1 | เตรียมเดินทาง | `trip` | `trips/YYYY-MM-DD_<ปลายทาง>_itinerary.md` |
| 2 | ตัดสินใจเรื่องใหญ่ / ตั้งเป้าหมาย | `decide-and-goals` | `decision-journal.md` · `goals/YYYY-Qn.md` |
| 3 | ย้ายบ้าน เปลี่ยนที่อยู่ทุกที่ | `documents` (ขั้น 1–2 และ 4) | `moves/YYYY-MM-DD_<ย่านใหม่>.md` |
| 4 | ข้อความลำบากใจ (ขอ · ปฏิเสธ · ทวงเงิน · ขอโทษ) | — (เล็ก ทำเลย) | ร่างในแชต |
| 5 | ของขวัญและวันสำคัญ | — (กลาง: ใช้ skill ตรง) | `gift-tracker.md` |

ใช้ต่อกัน: ลังเลว่าจะย้ายบ้านไหม → 2 → 3 · ไปต่างประเทศแต่พาสปอร์ตใกล้หมด → 1 → `prompt-papers-and-money.md` ฉบับ 1 · ปฏิเสธคำชวนหรือคำขอเงิน → 4 · ตรวจข้อความหรือ itinerary ก่อนส่ง → `prompt-weekly-routine.md` ฉบับ 4

## 1. เตรียมเดินทาง

playbook `trip` · agent `life-admin` · skill `travel-prep`
**ผลลัพธ์:** `trips/YYYY-MM-DD_<ปลายทาง>_itinerary.md` ไฟล์เดียวรวมทุกอย่าง · **รออนุมัติ:** จอง ซื้อประกันเดินทาง ยื่นวีซ่า

### ข้อมูล (ผู้ใช้กรอก)

- ปลายทาง / วันไป-กลับ / เดินทางกี่คน:
- พาสปอร์ตหมดอายุวันไหน (ทุกคน):
- ที่จองแล้ว (ตั๋ว ที่พัก) — วางอีเมลยืนยันใน `inbox/`:
- ไปทำอะไร (เที่ยว · งาน · ต่อเครื่อง):

### ต้องมีในผลงาน

1. ต้องใช้วีซ่าไหม · พาสปอร์ตเหลืออายุพอไหม (ตรวจกับแหล่งทางการ ติดวันที่)
2. เช็กลิสต์: เอกสาร · ประกัน · เงิน/บัตร · ซิม/โรมมิ่ง · ปลั๊กไฟ · ยาประจำ
3. itinerary รายวัน พร้อมเลขยืนยันการจองทุกรายการในที่เดียว
4. งานที่ต้องทำก่อนวันเดินทาง เรียงตามวันครบกำหนด

## 2. ตัดสินใจเรื่องใหญ่ / ตั้งเป้าหมาย

playbook `decide-and-goals` · agent `life-admin` · skill `decision-journal` · `goal-and-habit`
**ผลลัพธ์:** แถวใน `decision-journal.md` และ/หรือ `goals/YYYY-Qn.md` · **รออนุมัติ:** ตั้งเตือนวันทบทวน

### ข้อมูล (ผู้ใช้กรอก)

- งานนี้คือ (ตัดสินใจ / ตั้งเป้า / ทั้งสอง):
- (ตัดสินใจ) เรื่องอะไร 1 ประโยค · ทางเลือกที่มี · ต้องตัดสินใจภายในวันไหน:
- (เป้าหมาย) ไตรมาสหรือปีนี้อยากได้อะไร · นิสัยที่อยากเริ่มหรือเลิก:

### ต้องมีในผลงาน

1. ตัดสินใจ: ทางเลือก · เหตุผล · ผลที่คาด · ความมั่นใจ (%) · วันทบทวน
2. เป้าหมาย: ไม่เกิน 3 เป้า วัดได้ด้วยตัวเลขหรือใช่/ไม่ใช่ · นิสัยเริ่มจากขั้นเล็กที่สุด · ตารางติ๊ก
3. ไม่ตัดสินใจแทนผู้ใช้ · ช่วยให้เห็นข้อมูลครบแล้วให้ผู้ใช้เลือก

## 3. ย้ายบ้าน เปลี่ยนที่อยู่ทุกที่

playbook `documents` (ขั้น 1–2 และ 4: รายการเอกสาร · ที่ต้องแจ้ง · เตือน) · agent `doc-caretaker` · skill `important-docs` · `subscription-audit` (บริการที่ต้องย้ายหรือยกเลิก)
**ผลลัพธ์:** `moves/YYYY-MM-DD_<ย่านใหม่>.md` (รายการที่ต้องแจ้งเปลี่ยนที่อยู่ · ลำดับ · สถานะ) · อัปเดต `important-docs.csv` · **รออนุมัติ:** ยื่นย้ายทะเบียนบ้าน · แจ้งเปลี่ยนที่อยู่ในบัญชีต่าง ๆ · ยกเลิกหรือโอนบริการ — ผู้ใช้ทำเอง

### ข้อมูล (ผู้ใช้กรอก)

- วันย้าย / ย้ายกี่คน:
- ย้ายทะเบียนบ้านด้วยไหม / บ้านใหม่เป็นบ้านตัวเองหรือเช่า:
- บัญชีและสัญญาที่ผูกที่อยู่ (ธนาคาร · บัตรเครดิต · ประกัน · นายจ้าง · โรงเรียนลูก · ใบขับขี่ · เล่มรถ):
- สมาชิกและบริการรายเดือนที่ผูกกับบ้านเก่า (อินเทอร์เน็ต · เคเบิล · ฟิตเนส):
- แอปช้อปปิ้งและที่อยู่จัดส่ง:

### ต้องมีในผลงาน

1. ตารางทุกที่ที่ต้องแจ้ง: หน่วยงาน / บริษัท · ช่องทาง (แอป · สาขา · ออนไลน์) · เอกสารที่ต้องใช้ · ต้องทำภายในวันไหน · สถานะ
2. เรียงลำดับ: เรื่องที่มีกำหนดตามกฎหมาย → เรื่องที่ส่งเอกสารหรือบัตรมาทางไปรษณีย์ → เรื่องที่เหลือ
3. บริการรายเดือนของบ้านเก่า: ย้าย · ยกเลิก · เก็บไว้ พร้อมวันตัดรอบ (ตาม `subscription-audit`)
4. สิ่งที่ต้องทำในบ้านเก่าก่อนส่งคืน (ถ้าเช่า): ถ่ายรูปสภาพ · อ่านมิเตอร์ · ขอเงินประกันคืน
5. อัปเดต `important-docs.csv` และตั้งเตือนเรื่องที่ยังรอ

### กฎเฉพาะฉบับนี้

- กำหนดเวลาแจ้งย้ายทะเบียนบ้าน และเอกสารที่ต้องใช้ → ตรวจกับสำนักทะเบียนหรือเว็บทางการรอบนี้ ติดวันที่ ไม่มีข้อมูล → `(รอยืนยัน)`
- ไม่เขียนที่อยู่เต็มลงชื่อไฟล์ ใช้ชื่อย่าน
- ค่าน้ำ ค่าไฟ ดูแลบ้านใหม่ และสัญญาเช่า ส่งต่อ plugin `personal-life` ถ้าติดตั้ง

## 4. ข้อความลำบากใจ

skill `polite-message-th-en` · งานเล็ก ทำเลยไม่ต้องเปิด playbook
**ผลลัพธ์:** ร่างในแชต · **รออนุมัติ:** ส่ง

### ข้อมูล (ผู้ใช้กรอก)

- ส่งถึงใคร / ความสัมพันธ์ (หัวหน้า · ญาติผู้ใหญ่ · เพื่อน · ลูกค้า):
- อยากบอกอะไร (ขอ · ปฏิเสธ · ทวงเงิน · ขอโทษ · ตามงาน):
- ช่องทาง (LINE · อีเมล · พูด) / ภาษา:

### ต้องมีในผลงาน

1. ร่าง 2 แบบ (นุ่ม / ตรง) ระดับภาษาตามผู้รับ
2. ถ้าอีกฝ่ายตอบไม่ดี — ประโยคตอบต่อ 1 ประโยค

## 5. ของขวัญและวันสำคัญ

skill `gift-idea-tracker` · agent `life-admin` · งานกลาง ไม่ต้องเปิด playbook
**ผลลัพธ์:** `gift-tracker.md` · **รออนุมัติ:** สั่งซื้อ

### ข้อมูล (ผู้ใช้กรอก)

- ให้ใคร / โอกาสอะไร / วันไหน:
- งบ:
- เขาชอบอะไร / เคยให้อะไรไปแล้ว:

### ต้องมีในผลงาน

1. ตัวเลือก 3–5 อย่างในงบ พร้อมเหตุผลว่าทำไมเหมาะกับคนนี้

3. บันทึกลงทะเบียน: คน · วันสำคัญ · ของที่เคยให้ · ปีนี้ให้อะไร
