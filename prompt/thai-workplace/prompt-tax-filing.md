# prompt-tax-filing — ภาษีและงานตามรอบ: ปิดเดือน ปิดปี ปฏิทินภาษี เปิดบริษัทใหม่ ยื่นเลยกำหนด

ยังไม่ได้ทดสอบจริง

ใช้คู่กับ plugin `thai-workplace` · ไฟล์นี้รวม prompt 5 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์งานบริษัท** (1 บริษัท 1 โฟลเดอร์)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · วางไฟล์ที่ได้รับ (รายชื่อพนักงาน · statement · หนังสือจากหน่วยงาน) ไว้ใน `inbox/`
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 2`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `thai-workplace` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ถามแบบเลือกคำตอบตอนเริ่มและตอนจบ ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · สรุปงานตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่างและจุดที่ต้องเลือก → ถามรวมครั้งเดียวก่อนเริ่ม แบบเลือกคำตอบ ทุกตัวเลือกมีหลักฐาน ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**วนจนเสร็จ (agent loop):** ทุกฉบับวน ทำ → ตรวจ → แก้ → ตรวจซ้ำ จนผ่านทุกข้อที่ฉบับนั้นต้องมี · ตรวจด้วยหลักฐานจริง (เปิดไฟล์ · รันคำสั่ง · เทียบแหล่ง) ไม่ใช่คำบอกของตัวที่ทำ · รอบตรวจใช้ `reviewer` ตัวใหม่ทุกรอบ · ไม่ผ่าน → แก้ที่ต้นเหตุแล้วตรวจซ้ำทั้งข้อเดิมและจุดที่แก้ · เหลือแค่ข้อระดับต่ำ → ปิดได้แล้วลงรายงาน · ครบเพดานรอบ (งานกลาง 3 · งานใหญ่หรืองานเสี่ยง 5) ยังไม่ผ่าน → ติดป้าย `ติด` ทำส่วนอื่นให้จบ แล้วรายงานข้อที่เหลือ · รายละเอียดอยู่ใน skill `superuser` กฎข้อ 3

**ขอบเขต:** ข้อมูลทั่วไป ไม่ใช่คำปรึกษากฎหมายหรือบัญชี · อัตราภาษี เพดานประกันสังคม ค่าแรงขั้นต่ำ กำหนดยื่น และค่าปรับ ตรวจกับกรมสรรพากร สำนักงานประกันสังคม และกรมพัฒนาธุรกิจการค้า (DBD) ในรอบนี้ ติดวันที่ · ข้อสัญญาที่มีความเสี่ยงทางกฎหมาย → ติดป้าย `(ให้ทนายตรวจ)` · การยื่นแบบ จ่ายเงิน ส่งเอกสารถึงลูกค้า broadcast ถึงผู้ติดตาม LINE และกด deploy webhook อยู่ใน "รออนุมัติ" · ใช้ token และ secret ของผู้ใช้จาก environment variable เท่านั้น ไม่เขียนลงไฟล์

**ภาษาและไฟล์:** เขียนตาม `human-writing` · เอกสารถึงลูกค้าหรือหน่วยงานส่งเป็น `.docx` (+ `.pdf` ถ้าขอ) · ชื่อไฟล์ตามที่ skill กำหนด ไม่กำหนด → ใช้ชื่อในตาราง

## 1. ปิดงานรายเดือน

playbook `monthly-close` · agent `tax-helper` · skill `payroll-th` · `tax-vat-th` · `social-security-th`
**ผลลัพธ์:** `monthly/<ปี-เดือน>/` — ตารางเงินเดือน · สลิป · ข้อมูลกรอกแบบภาษีหัก ณ ที่จ่าย (ภ.ง.ด.1 / 3 / 53) · แบบภาษีมูลค่าเพิ่ม (ภ.พ.30) · แบบนำส่งเงินสมทบประกันสังคม (สปส.1-10) · **รออนุมัติ:** ยื่นแบบ · โอนเงินเดือน · ชำระภาษี

### ข้อมูล (ผู้ใช้กรอก)

- เดือน:
- รายชื่อพนักงาน เงินเดือน เบี้ยขยัน ค่าล่วงเวลา (OT) ขาด ลา (path):
- กองทุนสำรองเลี้ยงชีพ (มี / ไม่มี · อัตรา):
- ลดหย่อนที่พนักงานแจ้งในแบบแจ้งรายการลดหย่อน (ล.ย.01):
- ค่าจ้างผู้รับเหมา / ค่าบริการที่จ่ายและหัก ณ ที่จ่าย (path):
- ยอดขาย / ซื้อ และใบกำกับภาษีของเดือน (ถ้าจด VAT):

### ต้องมีในผลงาน

1. ตารางเงินเดือน: รวมได้ → ประกันสังคม → กองทุน → ภาษีหักแบบคำนวณทั้งปี → สุทธิ คำนวณซ้ำได้
2. ข้อมูลกรอกแต่ละแบบ พร้อมวันครบกำหนดยื่น (กระดาษ / ออนไลน์)
3. VAT: ภาษีขาย − ภาษีซื้อ · ใบกำกับที่ใช้เครดิตไม่ได้ พร้อมเหตุผล
4. ตรวจกระทบยอด: เงินเดือนรวม = ยอดโอน · ภาษีหักรวม = ภ.ง.ด.1

## 2. ปิดงานสิ้นปี

playbook `year-end` · agent `tax-helper` · skill `dbd-annual-filing` · `payroll-th`
**ผลลัพธ์:** `year-end/<ปี>/timeline.md` (นับถอยหลังจากวันสิ้นรอบบัญชี) · ภ.ง.ด.1ก · หนังสือรับรอง 50 ทวิ · **รออนุมัติ:** ยื่นทุกแบบ · จัดประชุม

### ข้อมูล (ผู้ใช้กรอก)

- ประเภท (บริษัทจำกัด / ห้างหุ้นส่วน):
- วันสิ้นรอบบัญชี:
- ผู้สอบบัญชี / สำนักงานบัญชี:
- ข้อมูลเงินเดือนทั้งปี (path):

### ต้องมีในผลงาน

1. ไทม์ไลน์: ปิดบัญชี → สอบบัญชี → ประชุมผู้ถือหุ้น (เฉพาะบริษัทจำกัด) → บอจ.5 (เฉพาะบริษัทจำกัด) → ส่งงบผ่าน DBD e-Filing → ภ.ง.ด.50 (กำหนดยื่นตรวจกับกรมสรรพากรรอบนี้ ติดวันที่ตรวจ) · วันครบกำหนดจริงของปีนี้
2. ค่าปรับถ้าเลยกำหนด (ตรวจกับแหล่งทางการ)
3. ภ.ง.ด.1ก และ 50 ทวิ รายคน ยอดตรงกับ ภ.ง.ด.1 รวม 12 เดือน
4. รายการเอกสารที่ต้องส่งให้ผู้สอบบัญชี

## 3. ปฏิทินยื่นภาษีทั้งปี

skill `tax-vat-th` · `thai-holidays` · agent `tax-helper` · งานกลาง ไม่ต้องเปิด playbook
**ผลลัพธ์:** `tax/<ปี>-calendar.md`

### ข้อมูล (ผู้ใช้กรอก)

- บริษัท หรือบุคคล:
- จด VAT ไหม / มีพนักงานไหม / จ่ายค่าบริการที่ต้องหัก ณ ที่จ่ายไหม:
- วันสิ้นรอบบัญชี:

### ต้องมีในผลงาน

1. ตาราง 12 เดือน: แบบ · ยื่นภายในวันไหน (กระดาษ / ออนไลน์) · เอกสารที่ต้องเตรียม
2. วันครบกำหนดที่ตรงวันหยุด → เลื่อนเป็นวันไหน (ตรวจประกาศจริง)
3. บริษัท: ภ.ง.ด.51 ครึ่งปี และ ภ.ง.ด.50 สิ้นปี · บุคคล: ภ.ง.ด.94 ครึ่งปี (ถ้ามีเงินได้ที่ต้องยื่น) · ภ.ง.ด.90 หรือ 91 สิ้นปี — กำหนดยื่นตรวจกับกรมสรรพากรรอบนี้ ติดวันที่ตรวจ

## 4. เปิดบริษัทใหม่ ตั้งงานหลังบ้านปีแรก

ไม่มี playbook ตรง → ประกอบเองตาม `playbook-template` (skill `superuser` หัวข้อ 2 งานกลาง) · agent `tax-helper` · skill `tax-vat-th` · `social-security-th` · `payroll-th` · `dbd-annual-filing` · `thai-holidays`
**ผลลัพธ์:** `setup/<ปี>-checklist.md` — รายการงานปีแรก เรียงตามวันครบกำหนด · **รออนุมัติ:** ยื่นจดทะเบียนภาษีมูลค่าเพิ่ม · ขึ้นทะเบียนนายจ้างและลูกจ้างกับประกันสังคม · สมัครยื่นแบบออนไลน์ · เปิดบัญชีธนาคารบริษัท

### ข้อมูล (ผู้ใช้กรอก)

- ประเภท (บริษัทจำกัด / ห้างหุ้นส่วน) / วันจดทะเบียน:
- ขายอะไร / คาดรายได้ปีแรก:
- จะจ้างพนักงานไหม เมื่อไร กี่คน:
- วันสิ้นรอบบัญชีที่เลือก:
- มีสำนักงานบัญชีดูแลไหม:

### ต้องมีในผลงาน

1. ต้องจด VAT ไหม: เกณฑ์รายได้และกำหนดจดตรวจกับกรมสรรพากรรอบนี้ ติดวันที่ตรวจ · จดเองโดยสมัครใจได้อะไรเสียอะไร
2. จ้างพนักงานคนแรก: แบบขึ้นทะเบียนนายจ้างและลูกจ้าง · กำหนดยื่น (ตรวจกับสำนักงานประกันสังคมรอบนี้ ติดวันที่ตรวจ)
3. งานประจำที่เริ่มเกิด: หัก ณ ที่จ่าย · ภ.พ.30 · สปส.1-10 · ภ.ง.ด.51 · ปิดปี → ชี้ไปฉบับ 1 2 3
4. ตารางงานปีแรกเรียงตามวันที่ · ช่องว่าง "ใครทำ" (เจ้าของ / สำนักงานบัญชี)
5. เอกสารที่ต้องเก็บตั้งแต่วันแรก (ใบกำกับภาษีซื้อ · สัญญา · ทะเบียนพนักงาน)

## 5. ยื่นหรือจ่ายภาษีเลยกำหนด · ได้หนังสือจากสรรพากร

playbook `monthly-close` (ขั้น 4 รายการแบบ · ขั้น 5 ไฟล์ยื่นและขั้นตอนทีละคลิก · ขั้น 6 ตรวจ) · agent `tax-helper` · skill `tax-vat-th` · `payroll-th` · `doc-thai-official` (ถ้าต้องตอบหนังสือ)
**ผลลัพธ์:** `monthly/<ปี-เดือน>/late-filing.md` — แบบที่ค้าง · ยอดที่ต้องจ่ายรวมเงินเพิ่มและเบี้ยปรับ · ร่างหนังสือชี้แจง (ถ้ามีหนังสือมา) · **รออนุมัติ:** ยื่นแบบ · ชำระภาษี เงินเพิ่ม เบี้ยปรับ · ส่งหนังสือถึงสรรพากร

### ข้อมูล (ผู้ใช้กรอก)

- แบบที่ค้าง (ภ.ง.ด.1 / 3 / 53 · ภ.พ.30 · สปส.1-10 · อื่น) / เดือนภาษี:
- ยอดภาษีตามแบบ:
- ตั้งใจจะยื่นวันไหน:
- ได้หนังสือจากหน่วยงานไหม (path) · เรื่องอะไร · ให้ตอบภายในวันไหน:

### ต้องมีในผลงาน

1. บรรทัดแรก: ต้องทำอะไรก่อน ภายในวันไหน
2. เงินเพิ่มและเบี้ยปรับ คำนวณทีละบรรทัด · อัตราและการลดเบี้ยปรับเมื่อยื่นเอง ตรวจกับกรมสรรพากรรอบนี้ ติดวันที่ตรวจ · สปส.1-10 ส่งช้า → เงินเพิ่มตรวจกับสำนักงานประกันสังคมรอบนี้ ติดวันที่ตรวจ
3. ยื่นเร็วขึ้น 1 วัน / 1 เดือน ประหยัดได้เท่าไร
4. หนังสือชี้แจง (ถ้ามี): ตามระเบียบงานสารบรรณ · อ้างเลขหนังสือ · แนบหลักฐาน · ข้อที่ตีความได้ → ปรึกษาผู้สอบบัญชีหรือ `(ให้ทนายตรวจ)`
5. กันซ้ำ: เพิ่มวันนี้ลงปฏิทินในฉบับ 3
