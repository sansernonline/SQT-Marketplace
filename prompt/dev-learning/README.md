# prompt/dev-learning — ชุดคำสั่งพร้อมวางสำหรับ plugin `dev-learning`

1 ไฟล์ต่อ 1 สถานการณ์ของการเรียนเทคโนโลยี · ในไฟล์มีหลาย prompt (เรียกว่า "ฉบับ") แต่ละฉบับทำงาน 1 ชิ้น

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์เรียนรู้** (ไม่ใช่โฟลเดอร์โปรเจกต์โค้ด)
2. เลือกไฟล์จากตาราง [เลือกจากสถานการณ์](#เลือกจากสถานการณ์) แล้วกรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้าย `ทำข้อ N`
4. agent ทำตาม playbook ของ plugin `dev-learning` จนจบในรอบเดียว · ของที่เสียเงิน (สมัครสอบ · ซื้อคอร์ส) อยู่ใน "รออนุมัติ" ให้คุณตัดสินเอง

## รายการไฟล์

| ไฟล์ | ใช้เมื่อ | ฉบับในไฟล์ |
|---|---|---|
| `prompt-start-learning.md` | จะเริ่มเรียนของใหม่ | 1 เรียนเทคโนโลยีใหม่เป็นขั้น · **2 งานใหม่ใช้ stack ที่ไม่เคยใช้** · **3 เริ่มจากศูนย์ เลือกสายไม่ได้** · 4 ตรวจงานเรียนรู้ก่อนใช้ |
| `prompt-read-and-apply.md` | มีของต้องอ่านให้เข้าใจแล้วเอาไปใช้ | 1 paper → โค้ด · 2 อ่านเอกสารอังกฤษ · **3 เล่าให้ทีมฟัง** |
| `prompt-keep-up.md` | ตามข่าวไลบรารีและเครื่องมือ | 1 เรดาร์ประจำสัปดาห์ · **2 เวอร์ชันใหญ่ / เลิกสนับสนุน** · **3 ของใหม่ตามกระแส ควรเรียนไหม** |
| `prompt-certification.md` | สอบใบรับรอง | 1 เตรียมสอบ · **2 สอบไม่ผ่าน สอบใหม่** |
| `prompt-portfolio.md` | ทำ side project หรือพอร์ต | 1 เลือกและเริ่ม side project · **2 side project ค้าง** |
| `prompt-thesis.md` | ทำวิทยานิพนธ์ การค้นคว้าอิสระ (IS) หรือบทความวิจัย | **1 โครงร่าง** · **2 ทบทวนวรรณกรรม** · **3 เขียนทีละบท** · **4 ตรวจอ้างอิงและตัวเลข** · **5 สอบป้องกัน / ตอบผู้ทบทวน** |

ฉบับตัวหนา = ฉบับที่เพิ่มใหม่ · ตรวจงานใช้ `prompt-start-learning.md` ฉบับ 4 ที่เดียว ไฟล์อื่นชี้มาที่นี่ · ยกเว้นวิทยานิพนธ์ที่ตรวจด้วย `prompt-thesis.md` ฉบับ 4 (ตรวจอ้างอิงและตัวเลข)

## เลือกจากสถานการณ์

| สถานการณ์ | ใช้ |
|---|---|
| อยากเรียน framework ใหม่ให้ใช้กับงานจริงได้ | `prompt-start-learning.md` ฉบับ 1 |
| ได้งานใหม่ ต้องเขียนภาษาที่ไม่เคยเขียน เริ่มงานอีก 2 สัปดาห์ | `prompt-start-learning.md` ฉบับ 2 → 4 |
| อยากเปลี่ยนสายมาเป็นโปรแกรมเมอร์ ไม่รู้จะเริ่มตรงไหน | `prompt-start-learning.md` ฉบับ 3 → 1 → `prompt-portfolio.md` ฉบับ 1 |
| เรียนจบใหม่ อยากมีพอร์ตไปสมัครงาน | `prompt-portfolio.md` ฉบับ 1 → `prompt-start-learning.md` ฉบับ 4 |
| อยากเปลี่ยนสายภายในวงการ (เช่น จากหน้าเว็บไปทำคลาวด์) แล้วมีใบรับรอง | `prompt-start-learning.md` ฉบับ 1 → `prompt-certification.md` ฉบับ 1 → `prompt-portfolio.md` ฉบับ 1 |
| บริษัทให้สอบใบรับรอง มีเวลา 2 เดือน | `prompt-certification.md` ฉบับ 1 |
| สอบใบรับรองไม่ผ่าน | `prompt-certification.md` ฉบับ 2 |
| หัวหน้าส่ง paper หรือ RFC มาให้อ่าน | `prompt-read-and-apply.md` ฉบับ 1 |
| เจอ error ภาษาอังกฤษยาว ๆ อ่านไม่รู้เรื่อง | `prompt-read-and-apply.md` ฉบับ 2 |
| ต้องเล่าเรื่องที่ไปเรียนมาให้ทีมฟังสัปดาห์หน้า | `prompt-read-and-apply.md` ฉบับ 1 → 3 |
| ไลบรารีอัปเดตบ่อยจนตามไม่ทัน | `prompt-keep-up.md` ฉบับ 1 (ทุกสัปดาห์) |
| framework ที่ใช้ประกาศเลิกสนับสนุนเวอร์ชันที่เราใช้ | `prompt-keep-up.md` ฉบับ 2 → งานอัปเกรดจริงใช้ plugin `software-company` (`prompt-existing-dev.md` ฉบับ 3) |
| ทุกคนพูดถึงเครื่องมือ AI ตัวใหม่ ไม่รู้ว่าต้องเรียนไหม | `prompt-keep-up.md` ฉบับ 3 → (เรียนตอนนี้) `prompt-start-learning.md` ฉบับ 1 |
| เรดาร์สัปดาห์นี้เจอเรื่องที่ต้องลงมือ | `prompt-keep-up.md` ฉบับ 1 → 2 หรือ `prompt-start-learning.md` ฉบับ 1 |
| side project ค้างมาหลายเดือน | `prompt-portfolio.md` ฉบับ 2 |
| มีไอเดียเยอะ เลือกไม่ได้ว่าจะทำอันไหน | `prompt-portfolio.md` ฉบับ 1 |
| ทำแผนเรียนหรือโน้ตเสร็จแล้ว อยากให้ตรวจก่อนใช้ | `prompt-start-learning.md` ฉบับ 4 |
| ต้องส่งโครงร่างวิทยานิพนธ์หรือ IS ยังไม่รู้จะตั้งคำถามวิจัยอย่างไร | `prompt-thesis.md` ฉบับ 1 → 2 |
| อาจารย์สั่งแก้บท | `prompt-thesis.md` ฉบับ 3 → 4 |
| ใกล้สอบป้องกัน หรือวารสารส่งความเห็นกลับมา | `prompt-thesis.md` ฉบับ 4 → 5 |

สถานการณ์ใหม่ที่ประกอบจากฉบับที่มีอยู่ได้ → เพิ่มแถวในตารางนี้ ไม่ต้องสร้างไฟล์ใหม่
