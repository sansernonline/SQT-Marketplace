# prompt/e-commerce — ชุดคำสั่งพร้อมวางของ plugin `e-commerce` ทั้งฝั่งขายและฝั่งซื้อ

ใช้คู่กับ plugin `e-commerce` · 1 ไฟล์ = 1 กลุ่มสถานการณ์ · ในไฟล์มีหลายฉบับ แต่ละฉบับทำงาน 1 ชิ้น

## วิธีใช้

1. เปิด agent ที่**โฟลเดอร์ของเรื่องนั้น** (ร้านค้า → โฟลเดอร์ร้าน · เรื่องซื้อของ → โฟลเดอร์ผู้บริโภค) · หลักฐานวางไว้ใน `evidence/<เรื่อง>/`
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้าย `ทำข้อ N`
4. ของที่ย้อนไม่ได้ (ลงขายจริง · ส่งข้อความ · คืนเงิน · สั่งซื้อ · ยื่นร้องเรียน · จ่ายเงิน) agent เตรียมไว้ใน "รออนุมัติ" ให้คุณทำเอง
