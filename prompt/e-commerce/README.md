# prompt/e-commerce — ชุดคำสั่งพร้อมวางของ plugin `e-commerce` ฝั่งขาย ฝั่งซื้อ และงานหลังบ้านบริษัท

ใช้คู่กับ plugin `e-commerce` · 1 ไฟล์ = 1 กลุ่มสถานการณ์ · ในไฟล์มีหลายฉบับ แต่ละฉบับทำงาน 1 ชิ้น

## วิธีใช้

1. เปิด agent ที่**โฟลเดอร์ของเรื่องนั้น** (ร้านค้า → โฟลเดอร์ร้าน · เรื่องซื้อของ → โฟลเดอร์ผู้บริโภค · งานหลังบ้าน → โฟลเดอร์บริษัท 1 บริษัท 1 โฟลเดอร์ ไม่ใช่โฟลเดอร์โปรเจกต์โค้ด) · หลักฐานวางไว้ใน `evidence/<เรื่อง>/`
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้าย `ทำข้อ N`
4. ของที่ย้อนไม่ได้ (ลงขายจริง · ส่งข้อความ · คืนเงิน · สั่งซื้อ · ยื่นร้องเรียน · จ่ายเงิน · ยื่นแบบ · ส่งเอกสาร · broadcast · ลงนาม) agent เตรียมไว้ใน "รออนุมัติ" ให้คุณทำเอง

## เลือกจากสถานการณ์ — งานหลังบ้านบริษัท

| สถานการณ์ | ใช้ |
|---|---|
| ลูกค้าขอใบเสนอราคา | `prompt-documents.md` ฉบับ 1 → 5 |
| ส่งของแล้ว ต้องวางบิลและให้ลูกค้าสแกนจ่าย | `prompt-documents.md` ฉบับ 1 → 2 → 5 |
| เลยกำหนดแล้ว ลูกค้ายังไม่โอน | `prompt-documents.md` ฉบับ 3 |

| สิ้นเดือน ต้องจ่ายเงินเดือนและยื่นภาษี | `prompt-tax-filing.md` ฉบับ 1 |
| ปิดรอบบัญชีแล้ว ต้องส่งงบ | `prompt-tax-filing.md` ฉบับ 2 |
| เพิ่งจดบริษัท ไม่รู้ต้องทำอะไรบ้าง | `prompt-tax-filing.md` ฉบับ 4 → 3 |
| ลืมยื่นภาษีเดือนก่อน / ได้จดหมายจากสรรพากร | `prompt-tax-filing.md` ฉบับ 5 → 1 |
| จะรับพนักงานคนแรก | `prompt-tax-filing.md` ฉบับ 4 (ข้อ 2) → `prompt-employees.md` ฉบับ 2 → `prompt-pdpa-line.md` ฉบับ 1 |
| รับพนักงานใหม่เพิ่ม | `prompt-employees.md` ฉบับ 2 → `prompt-tax-filing.md` ฉบับ 1 |
| พนักงานยื่นใบลาออก | `prompt-employees.md` ฉบับ 3 → `prompt-tax-filing.md` ฉบับ 1 |

| พนักงานถามเรื่องค่าล่วงเวลา (OT) วันลา ค่าชดเชย | `prompt-employees.md` ฉบับ 1 |
| ต้นปี ต้องประกาศวันหยุดบริษัท | `prompt-employees.md` ฉบับ 4 → `prompt-tax-filing.md` ฉบับ 3 |
| ร้านจะหยุดสงกรานต์ / ปีใหม่ ต้องบอกลูกค้า | `prompt-employees.md` ฉบับ 4 → `prompt-pdpa-line.md` ฉบับ 3 |
| เปิด LINE OA ให้ bot ตอบลูกค้า | `prompt-pdpa-line.md` ฉบับ 1 → 2 |
