# prompt-job-search — หางานใหม่: สมัคร สัมภาษณ์ ต่อรอง งานแรก

ใช้คู่กับ plugin `career` · ไฟล์นี้รวม prompt 5 ฉบับ · 1 ฉบับ = 1 งาน

## วิธีใช้

1. เปิด Claude Code, Codex CLI หรือ Gemini CLI ที่**โฟลเดอร์งานอาชีพ** (โฟลเดอร์เดียวใช้ได้ทุกฉบับ)
2. กรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ · ไม่รู้ปล่อยว่างได้
3. วางทั้งไฟล์ แล้วพิมพ์ต่อท้ายว่าจะทำฉบับไหน เช่น `ทำข้อ 1` หรือ `ทำข้อ 1 และ 2`

**กฎการทำงาน (agent ต้องทำตาม):** เปิด skill `superuser` ของ plugin `career` ก่อนเริ่ม แล้วทำตาม playbook ที่ฉบับนั้นระบุทุกขั้น · กฎร่วม (อ่าน `.claude/superuser/CONTEXT.md` ก่อนเริ่ม · ไม่หยุดถามกลางทาง · บันทึกการตัดสินใจ · รายการ "รออนุมัติ" · รอบเรียนรู้ · ตารางสถานะตอนจบ) อยู่ใน skill นั้นที่เดียว ไม่เขียนซ้ำที่นี่ · ช่อง "ผู้ใช้กรอก" ที่ยังว่าง → ถามรวมครั้งเดียวก่อนเริ่ม ไม่ได้คำตอบ → ใส่ `(รอยืนยัน)` แล้วทำต่อ · skill ที่อ้างข้าม plugin (ชื่อ plugin อยู่ในวงเล็บ) ไม่ได้ติดตั้ง → ข้ามแล้วบอกในรายงาน · เปิดผ่านคำสั่ง skill ไม่ได้ → อ่าน `skills/<ชื่อ>/SKILL.md` ในโฟลเดอร์ plugin แทน · ไม่มี agent ที่อ้าง → ใช้ agent ทั่วไปพร้อมเปิด `agents/<ชื่อ>.md` · หาไม่เจอทั้ง 2 ทาง → ข้ามชิ้นนั้น ทำส่วนอื่นให้จบ แล้วรายงานว่าติด

**ขอบเขต:** ไม่แต่งประสบการณ์ ตำแหน่ง ตัวเลข หรือวุฒิ · ตัวเลขเงินเดือนตลาดต้องมีแหล่งและปี · การกดส่งใบสมัคร ส่งอีเมล หรือตอบรับข้อเสนอ อยู่ใน "รออนุมัติ" เสมอ · ข้อพิพาทแรงงาน → จัดข้อเท็จจริงให้ แล้วแนะนำศาลแรงงานหรือทนาย

**ภาษาและไฟล์:** เขียนตาม `human-writing` · ชื่อไฟล์ตามที่ skill กำหนด ไม่กำหนด → ใช้ชื่อในตาราง

| # | งาน | playbook | ได้ไฟล์ |
|---|---|---|---|
| 1 | สมัครงาน 1 ตำแหน่งครบชุด | `job-application` | `applications/<บริษัท>-<ตำแหน่ง>/` — CV · ข้อความสมัคร · ตารางจับคู่ |
| 2 | เตรียมสัมภาษณ์ + ซ้อม | `interview` | `applications/<บริษัท>-<ตำแหน่ง>/interview-<รอบ>.md` |
| 3 | เทียบข้อเสนอและต่อรองเงินเดือน | `offer-negotiation` | `offers/<ปี-เดือน>-offer-compare.md` |
| 4 | จบใหม่ หางานแรก | `profile-refresh` | `cv/` · `linkedin.md` · `first-job-plan.md` |
| 5 | ตรวจงานอาชีพก่อนส่ง | `review` | คำตัดสินในคำตอบ · ไม่สร้างไฟล์ |

ใช้ต่อกัน: ได้งานใหม่ตั้งแต่ต้น → 1 → 2 → 3 · จบใหม่ยังไม่มี CV → 4 → 1 → 2 · ทุกไฟล์ก่อนส่งจริง → 5 · ได้งานแล้วเริ่มงานใหม่ → `prompt-at-work.md` ฉบับ 2

## 1. สมัครงาน 1 ตำแหน่งครบชุด

playbook `job-application` · agent `career-coach` · skill `resume-th-en` · `linkedin-profile`
**ผลลัพธ์:** โฟลเดอร์ `applications/<บริษัท>-<ตำแหน่ง>/` · **รออนุมัติ:** กดส่งใบสมัคร

### ข้อมูล (ผู้ใช้กรอก)

- ประกาศงาน (ลิงก์ หรือวางข้อความ):
- CV ปัจจุบัน (path ไฟล์):
- ลิงก์ LinkedIn:
- ภาษาที่ต้องการ (ไทย / อังกฤษ / ทั้งสอง):
- เงินเดือนที่คาดหวัง (ถ้าประกาศถาม):
- ผลงานที่อยากเน้นเป็นพิเศษ:

### ต้องมีในผลงาน

1. ตารางประกาศงาน 3 กลุ่ม: ต้องมี · ควรมี · คำค้นที่ระบบ Applicant Tracking System (ATS) จะหา
2. ตารางจับคู่ ข้อต้องมี → หลักฐานใน CV · ข้อที่ไม่มีหลักฐานลงช่อง "ช่องว่าง" พร้อมวิธีพูดถึงตามจริง
3. CV ฉบับสำหรับงานนี้ (`.md` + `.docx`) ทุก bullet = การกระทำ + ผล + ตัวเลข · ตัวเลขที่ไม่มี → `[ใส่ตัวเลข]`
4. ข้อความสมัคร / cover letter สั้น อ้างข้อต้องมี 2–3 ข้อพร้อมหลักฐาน
5. headline และ About ของ LinkedIn ที่ตำแหน่งและวันที่ตรงกับ CV
6. ผลตรวจ: คำค้นครบ · วันที่ตรงกันทุกไฟล์ · ระบบ ATS อ่านได้ (ไม่มีตาราง กล่องข้อความ รูปแทนข้อความ)

## 2. เตรียมสัมภาษณ์ + ซ้อม

playbook `interview` · agent `interview-coach` · skill `interview-prep` · `salary-negotiation`
**ผลลัพธ์:** `applications/<บริษัท>-<ตำแหน่ง>/interview-<รอบ>.md` · ซ้อมในแชตทีละคำถาม

### ข้อมูล (ผู้ใช้กรอก)

- บริษัท / ตำแหน่ง / วันที่สัมภาษณ์:
- รอบ (HR / หัวหน้างาน / technical / รอบสุดท้าย):
- ภาษาที่ใช้สัมภาษณ์:
- ผู้สัมภาษณ์ (ชื่อ ตำแหน่ง ถ้ารู้):
- เรื่องที่กังวล (เช่น ทำไมลาออก · ช่องว่างในประวัติ):
- อยากซ้อมแบบให้คะแนนไหม (ใช่ / ไม่):

### ต้องมีในผลงาน

1. คลังเรื่องเล่าแบบ STAR (Situation · Task · Action · Result) 6–8 เรื่อง จับคู่กับข้อต้องมีของงาน
2. 10 คำถามที่น่าจะเจอในรอบนี้ พร้อมโครงคำตอบ รวมคำถามยากของ HR ไทย (เงินเดือนที่คาดหวัง · ทำไมลาออก · จุดอ่อน)
3. ตัวเลขเงินเดือนที่จะพูด พร้อมแหล่งและปีของข้อมูลตลาด
4. 3 คำถามที่ผู้ใช้ถามกลับ
5. ร่างข้อความขอบคุณหลังสัมภาษณ์
6. ถ้าเลือกซ้อม: ถามทีละข้อ ให้คะแนน 1–5 พร้อมจุดแก้ 1 ข้อต่อคำตอบ แล้วสรุป 3 เรื่องที่ต้องฝึกเพิ่ม

## 3. เทียบข้อเสนอและต่อรองเงินเดือน

playbook `offer-negotiation` · agent `career-coach` · skill `salary-negotiation`
**ผลลัพธ์:** `offers/<ปี-เดือน>-offer-compare.md` · **รออนุมัติ:** ส่งข้อความต่อรอง · ตอบรับ / ปฏิเสธข้อเสนอ

### ข้อมูล (ผู้ใช้กรอก)

- ประเภท (ข้อเสนองานใหม่ / ขอขึ้นเงินเดือน / counter-offer จากที่เดิม):
- ข้อเสนอแต่ละที่ (เงินเดือน · โบนัส · สวัสดิการ · กองทุนสำรองเลี้ยงชีพ · ประกัน · วันลา · WFH · ค่าเดินทาง):
- รายได้ปัจจุบันทั้งปี (ไม่บังคับ):
- เส้นต่ำสุดที่รับได้:
- กำหนดตอบ:
- เรื่องที่ไม่ใช่เงินแต่สำคัญ (ตำแหน่ง · ทีม · เดินทาง):

### ต้องมีในผลงาน

1. ตารางรายได้รวมต่อปีของแต่ละข้อเสนอ คิดทุกบรรทัดเป็นตัวเลขที่คำนวณซ้ำได้
2. ข้อมูลตลาดของตำแหน่งนี้ พร้อมแหล่งและปี · ไม่มีแหล่ง → บอกว่ายังไม่ยืนยัน
3. ตัวเลขที่จะขอ + เหตุผล 2–3 ข้อที่มีหลักฐาน
4. ข้อความต่อรองพร้อมส่ง ไทยและอังกฤษ + คำตอบถ้าอีกฝ่ายปฏิเสธ
5. ข้อสรุปเลือกทางไหน และสิ่งที่ต้องขอเป็นลายลักษณ์อักษรก่อนตอบรับ

## 4. จบใหม่ หางานแรก

playbook `profile-refresh` · agent `career-coach` · skill `resume-th-en` · `linkedin-profile` · `interview-prep`
**ผลลัพธ์:** `cv/CV_<ชื่อ>_TH.md` · `cv/CV_<ชื่อ>_EN.md` (+ `.docx`) · `linkedin.md` · `first-job-plan.md` · **รออนุมัติ:** กดส่งใบสมัคร · ส่งข้อความหาผู้สรรหา

### ข้อมูล (ผู้ใช้กรอก)

- คณะ / สาขา / ปีที่จบ (หรือจะจบ):
- สายงานที่สนใจ 1–2 สาย (ยังไม่รู้ก็บอกว่ายังไม่รู้):
- ฝึกงาน · โปรเจกต์จบ · งานพิเศษ · กิจกรรม · งานอาสา:
- ทักษะและใบรับรอง (ภาษา · โปรแกรม · คะแนนสอบภาษา ถ้ามี):
- จังหวัดหรือพื้นที่ที่อยากทำงาน / รับงานทางไกลไหม:
- CV เดิม (path ไฟล์ ถ้ามี):

### ต้องมีในผลงาน

1. ตารางสายงานเป้าหมาย: ตำแหน่งระดับเริ่มต้นที่ตรงกับวุฒิ · คำค้นจากประกาศงานจริงอย่างน้อย 5 ประกาศ (ติดวันที่ดู)
2. CV ไทยและอังกฤษ 1 หน้า ที่ใช้ฝึกงาน โปรเจกต์ และกิจกรรมแทนประสบการณ์ทำงาน · ทุก bullet = การกระทำ + ผล · ตัวเลขที่ไม่มี → `[ใส่ตัวเลข]`
3. LinkedIn: headline · About · Featured (โปรเจกต์จบ · ผลงาน) ที่ตรงกับ CV
4. `first-job-plan.md`: ช่องทางหางาน (เว็บหางาน · งานรับสมัครของมหาวิทยาลัย · ฝ่ายบุคคลของบริษัทโดยตรง) · เป้าสมัครต่อสัปดาห์ · ตารางติดตาม บริษัท · ตำแหน่ง · วันที่ส่ง · สถานะ
5. คำตอบคำถามที่คนจบใหม่เจอบ่อย (ไม่มีประสบการณ์ · เงินเดือนที่คาดหวัง · แผน 3 ปี) โดยตัวเลขเงินเดือนเริ่มต้นต้องมีแหล่งและปี · ไม่มีแหล่ง → `(รอยืนยัน)`
6. ช่องว่างที่ควรเติมก่อนสมัคร (ใบรับรอง · ผลงานตัวอย่าง) เรียงตามผลต่อสายงานเป้าหมาย

### กฎเฉพาะฉบับนี้

- ไม่ทำให้กิจกรรมหรือฝึกงานดูใหญ่กว่าความจริง · ไม่ใส่เกรดเฉลี่ยถ้าผู้ใช้ไม่ได้ให้มา
- ได้ตำแหน่งเป้าหมายที่จะสมัครแล้ว → ทำฉบับ 1 ต่อทีละตำแหน่ง

## 5. ตรวจงานอาชีพก่อนส่ง

playbook `review` · agent `career-coach` (มุมผู้สมัคร) + agent ตัวใหม่ (มุม recruiter)
**ผลลัพธ์:** คำตัดสิน `ผ่าน / แก้ก่อนส่ง` พร้อมรายการปัญหาที่ยืนยันแล้ว · **ไม่แก้ไฟล์เอง**

### ข้อมูล (ผู้ใช้กรอก)

- ไฟล์ที่จะให้ตรวจ (CV · cover letter · อีเมล · self-review):
- จะส่งให้ใคร / ตำแหน่งอะไร:
- ประกาศงาน (ถ้ามี):

### ต้องมีในผลงาน

1. คำตัดสิน 1 บรรทัด
2. ตารางปัญหา: ตำแหน่งในไฟล์ · ปัญหา · ระดับ (สูง / กลาง / ต่ำ) · วิธีแก้ (เดิม → ใหม่)
3. ข้อที่ตรวจแล้วผ่าน (สั้น ๆ) เพื่อให้รู้ว่าดูอะไรไปแล้ว
