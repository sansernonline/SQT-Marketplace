# prompt/career — ชุดคำสั่งพร้อมวางของ plugin `career` แยกไฟล์ตามช่วงชีวิตการทำงาน

## วิธีใช้

1. เปิด agent ที่**โฟลเดอร์งานอาชีพ** (ไม่ใช่โฟลเดอร์โปรเจกต์โค้ด) · โฟลเดอร์เดียวใช้ได้ทุกไฟล์
2. เลือกไฟล์จากตาราง "เลือกจากสถานการณ์" แล้วกรอกช่อง "ผู้ใช้กรอก" ของฉบับที่จะทำ
3. วางทั้งไฟล์ + พิมพ์ `ทำข้อ N` · ของที่ย้อนไม่ได้ (ส่ง · ยื่น · เซ็น · ตอบรับ) อยู่ใน "รออนุมัติ" เสมอ

## รายการไฟล์

| ไฟล์ | ใช้เมื่อ | ฉบับในไฟล์ |
|---|---|---|
| `prompt-job-search.md` | กำลังหางานใหม่ | 1 สมัครงานครบชุด · 2 เตรียมสัมภาษณ์ + ซ้อม · 3 เทียบข้อเสนอ ต่อรองเงินเดือน · **4 จบใหม่ หางานแรก** · 5 ตรวจก่อนส่ง |
| `prompt-at-work.md` | ทำงานอยู่ ไม่ได้คิดย้าย | 1 ประเมินตัวเอง ขอเลื่อนตำแหน่ง · **2 เริ่มงานใหม่ ผ่านทดลองงาน** · **3 คุยกับหัวหน้าเรื่องยาก** |
| `prompt-career-change.md` | จะเปลี่ยนทาง หรือเตรียมตัวไว้ก่อน | 1 ปรับ CV + LinkedIn · **2 เปลี่ยนสายงาน** · **3 กลับมาทำงานหลังหยุดไปนาน** |
| `prompt-leaving-job.md` | กำลังจะออกจากงาน | **1 ลาออกอย่างดี** · **2 ถูกเลิกจ้าง / ถูกบอกให้ออก** |

ฉบับตรวจก่อนส่งมีที่เดียว: `prompt-job-search.md` ฉบับ 5 · ไฟล์อื่นชี้มาที่นี่

## เลือกจากสถานการณ์

| สถานการณ์ | ใช้ |
|---|---|
| เจอประกาศงานที่อยากสมัคร | `prompt-job-search.md` ฉบับ 1 → 5 |
| ได้นัดสัมภาษณ์แล้ว | `prompt-job-search.md` ฉบับ 2 |
| เปลี่ยนงานใหม่ตั้งแต่ต้นจนได้ข้อเสนอ | `prompt-job-search.md` ฉบับ 1 → 2 → 3 |
| ได้ข้อเสนอ 2 ที่ เลือกไม่ถูก | `prompt-job-search.md` ฉบับ 3 |
| เพิ่งเรียนจบ ยังไม่มี CV | `prompt-job-search.md` ฉบับ 4 → 1 → 2 |
| เพิ่งเริ่มงานใหม่ กลัวไม่ผ่านทดลองงาน | `prompt-at-work.md` ฉบับ 2 |
| ถึงรอบประเมินกลางปีหรือปลายปี | `prompt-at-work.md` ฉบับ 1 → `prompt-job-search.md` ฉบับ 5 |
| อยากขึ้นเงินเดือนโดยไม่ย้ายงาน | `prompt-at-work.md` ฉบับ 1 → `prompt-job-search.md` ฉบับ 3 |
| ขอเลื่อนตำแหน่งแล้วถูกบอกว่า "ยังไม่ถึง" | `prompt-at-work.md` ฉบับ 3 |
| งานล้นมือ ถูกตำหนิ หรืออยากขอย้ายทีม | `prompt-at-work.md` ฉบับ 3 |
| CV เก่าหลายปี ยังไม่มีงานเป้าหมาย | `prompt-career-change.md` ฉบับ 1 |
| อยากเปลี่ยนสายงาน | `prompt-career-change.md` ฉบับ 2 → 1 → `prompt-job-search.md` ฉบับ 1 |
| หยุดงานไปเลี้ยงลูกหรือดูแลพ่อแม่ อยากกลับมาทำงาน | `prompt-career-change.md` ฉบับ 3 → `prompt-job-search.md` ฉบับ 1 → 2 |
| ได้งานใหม่แล้ว จะยื่นใบลาออก | `prompt-job-search.md` ฉบับ 3 → `prompt-leaving-job.md` ฉบับ 1 |
| ยื่นลาออกแล้ว ที่เดิมขอให้อยู่ต่อ (counter-offer) | `prompt-job-search.md` ฉบับ 3 → `prompt-leaving-job.md` ฉบับ 1 |
| ถูกเลิกจ้าง หรือถูกบอกให้เขียนใบลาออกเอง | `prompt-leaving-job.md` ฉบับ 2 |
| ถูกเลิกจ้าง และต้องหางานใหม่เร็ว | `prompt-leaving-job.md` ฉบับ 2 → `prompt-career-change.md` ฉบับ 1 → `prompt-job-search.md` ฉบับ 1 |
| ไม่ผ่านทดลองงาน | `prompt-leaving-job.md` ฉบับ 2 → `prompt-career-change.md` ฉบับ 1 |
| มี CV อีเมล หรือ self-review ที่เขียนเองแล้ว อยากให้ช่วยดู | `prompt-job-search.md` ฉบับ 5 |

สถานการณ์ใหม่ที่ประกอบจากฉบับที่มีอยู่ได้ → เพิ่มแถวในตารางนี้ ไม่ต้องสร้างไฟล์ใหม่
