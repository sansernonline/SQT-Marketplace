# หัวรายงานยอดขายขึ้นปี 3112 บนเครื่อง server

รายงานยอดขายที่ออกจากเครื่อง server ของบริษัท (ตั้งภาษาเป็นไทย th-TH) หัวรายงานขึ้นว่า "รายงานยอดขาย ประจำวันที่ 31/12/3112" แต่บนเครื่องนักพัฒนา (en-US) ขึ้น 31/12/2569 ถูกต้อง · ไฟล์ CSV (Comma-Separated Values) ที่ส่งให้ระบบบัญชีจาก server ก็มีปี 2569 ทำให้ระบบบัญชีนำเข้าไม่ได้

ที่ต้องการ

1. `ReportFormatter.FormatHeader(DateTime)` ต้องคืน `รายงานยอดขาย ประจำวันที่ dd/MM/ปีพ.ศ.` เช่น วันที่ 31 ธันวาคม 2026 → `รายงานยอดขาย ประจำวันที่ 31/12/2569` ไม่ว่าเครื่องจะตั้ง culture เป็น th-TH, en-US หรือ invariant · วันที่ 29 กุมภาพันธ์ 2024 ต้องได้ `29/02/2567`
2. `CsvExporter.Export(...)` ต้องเขียนวันที่เป็น ค.ศ. รูปแบบ `yyyy-MM-dd` เสมอ (เช่น `2026-12-31`) ไม่ว่าเครื่องจะตั้ง culture เป็นอะไร · รูปแบบอื่นของไฟล์ห้ามเปลี่ยน
3. build แล้วต้องไม่มี warning (`dotnet build -warnaserror`)

รัน test จากรากของ repo:

```
dotnet test tests/SalesReport.Tests
```
