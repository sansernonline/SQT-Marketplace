# หน้าเช็กสต็อกช้ามากตอนลูกค้าเข้าพร้อมกัน

ระบบเช็กสต็อก (`app.py` ทำด้วย FastAPI) มีเส้นทาง `GET /stock/{sku}` ที่ถามคลังสินค้าผ่าน `slow_client.get_stock()` ถามทีละคนตอบใน 0.2 วินาที ไม่มีปัญหา แต่ตอนไลฟ์ขายของมีลูกค้าเปิดพร้อมกัน 10 คน คนสุดท้ายรอเกือบ 2 วินาที เหมือนระบบตอบได้ทีละคน

ที่อยากได้

- เปิดพร้อมกัน 10 คำขอ ต้องเสร็จครบภายในไม่เกิน 2.5 เท่าของเวลาคำขอเดียว
- ผลลัพธ์ต้องเหมือนเดิมทุกอย่าง: `{"sku": ..., "qty": ..., "in_stock": ...}` และรหัสสินค้าที่ไม่มีต้องได้ 404 เหมือนเดิม

ข้อห้าม

- ห้ามแก้ `slow_client.py` เป็นไลบรารีของผู้ขาย (vendor) จะถูกเขียนทับทุกครั้งที่อัปเดต และการเรียกคลังสินค้าใช้เวลาจริงประมาณ 0.2 วินาทีต่อครั้ง ลดไม่ได้
- ห้ามใช้ cache หรือเก็บผลไว้ล่วงหน้า สต็อกต้องถามคลังสดทุกครั้ง

ลงไลบรารีด้วย `pip install -r requirements.txt` แล้วรัน test ของ repo ด้วย `python -m pytest -q`
