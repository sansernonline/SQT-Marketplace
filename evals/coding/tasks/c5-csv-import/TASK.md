# นำเข้ารายการสินค้าแล้วพัง ชื่อไทยอ่านไม่ได้ และกดซ้ำแล้วสินค้าเบิ้ล

ร้านเราส่งออกรายการสินค้าจากโปรแกรมหน้าร้านบน Windows เป็นไฟล์ Comma-Separated Values (CSV) แล้วใช้ `importer.py` นำเข้าฐานข้อมูล SQLite (`python importer.py data/products.csv shop.db`) ตอนนี้เจอ 3 เรื่อง

1. ไฟล์จริงเป็นรหัสภาษาไทย Windows-874 (cp874) สคริปต์ล้มทันทีที่เจอชื่อสินค้าภาษาไทย ตัวอย่างอยู่ที่ `data/products.csv`
2. พนักงานกดนำเข้าซ้ำบ่อย ทุกครั้งที่รัน สินค้าเพิ่มเป็น 2 เท่า 3 เท่า
3. ไฟล์บางวันมีบรรทัดว่างหรือแถวที่กรอกผิด สคริปต์ล้มทั้งไฟล์

ที่อยากได้

- ชื่อไทยเข้าฐานข้อมูลถูกต้อง อ่านออก
- รันกี่ครั้งก็ได้ สินค้า 1 รหัส (`sku`) มีแถวเดียวเสมอ ถ้าในไฟล์ราคา ชื่อ หรือจำนวนเปลี่ยน ให้แถวเดิมเปลี่ยนตาม
- บรรทัดว่าง (หรือมีแต่ช่องว่าง) ให้ข้ามไปเฉย ๆ ไม่นับเป็นข้อผิดพลาด
- แถวเสีย ได้แก่ จำนวนช่องไม่ครบ 4 ช่อง ไม่มี `sku` หรือ `price` / `qty` ไม่ใช่ตัวเลข ให้ข้ามแถวนั้น นำเข้าแถวอื่นต่อ แล้วรายงานกลับมา ห้ามล้ม
- `import_csv(csv_path, db_path)` คืนค่าเป็น `{"imported": จำนวนแถวที่บันทึก, "errors": [{"line": เลขบรรทัดในไฟล์, "reason": "สาเหตุ"}]}` โดยบรรทัดหัวตารางคือบรรทัดที่ 1

ไฟล์มีหัวตาราง `sku,name,price,qty` เสมอ ไม่มี Byte Order Mark (BOM) ใช้แค่ไลบรารีมาตรฐานของ Python

รัน test ของ repo ด้วย `python -m pytest -q`
