# รายงานยอดขายรายเดือนช้าเกิน 2 วินาที

รายงานยอดขายรายเดือนแยกสาขา (`monthly_sales(conn, year)` ใน `report.py`) ช้ามาก ฐานข้อมูลจริงมียอดขาย 1,000,000 แถว เปิดรายงานปี 2024 ทีไรต้องรอเกิน 2 วินาที หน้าจอค้างจนพนักงานกดซ้ำ

อยากให้แก้ดังนี้

1. รายงานปีหนึ่งบนข้อมูล 1,000,000 แถว ต้องเสร็จภายใน 2 วินาที
2. ตัวเลขต้องเหมือนเดิมทุกแถว รูปแบบผลลัพธ์ตามที่เขียนไว้ใน `monthly_sales` นับเฉพาะบิล `paid` และบิลที่ขายช่วงต้นปีหรือท้ายปีพอดีต้องตกปีถูก
3. ฐานข้อมูลต้องไม่อ่านตาราง `sales` ทั้งตารางทุกครั้งที่เปิดรายงาน เพราะข้อมูลจะโตขึ้นทุกเดือน
4. ถ้าต้องเพิ่มดัชนี (index) ให้เพิ่มเป็นไฟล์ Structured Query Language (SQL) ใหม่ในโฟลเดอร์ `migrations/` ทีมเรารันไฟล์ในนั้นเรียงตามชื่อไฟล์ด้วย `apply_migrations(conn)` ใน `db.py` อย่าแก้ไฟล์ migration เดิม

ฐานข้อมูลเป็น SQLite ใช้ Python ไลบรารีมาตรฐานเท่านั้น สร้างข้อมูลทดลองได้ด้วย `python make_db.py sales.db 1000000`

รัน test ของ repo ด้วย `python -m pytest -q`
