# evals/coding — วัดว่าทีมเขียนโค้ดเก่งขึ้นจริงไหม

แก้ skill หรือ agent ที่เกี่ยวกับโค้ดแล้ว → ให้ plugin รุ่นก่อนกับรุ่นหลังทำงานชุดเดียวกัน แล้วเทียบคะแนน
ต่างจาก `evals/speed` ตรงที่วัด **คุณภาพ** (เต็ม 10 ต่องาน) ไม่ใช่ความเร็ว · วิธีให้คะแนนอยู่ใน skill `coding-evals` ของ software-company

## วิธีรัน

```powershell
# 1. ตรวจชุดงานก่อนใช้ (ไม่เรียก claude ไม่เสียเงิน): โค้ดตั้งต้นต้องตก · คำตอบอ้างอิงต้องผ่านครบ
node evals/coding/run-coding.mjs --verify

# 2. เทียบ commit ล่าสุด (รุ่นก่อน) กับไฟล์ที่แก้อยู่ตอนนี้ (รุ่นหลัง) · งาน c1 กับ c5 · รุ่นละ 1 รอบ
node evals/coding/run-coding.mjs --old HEAD --tasks c1,c5

# 3. เทียบครบ 8 งาน · รุ่นละ 2 รอบ · จำกัดรอบละ $5
node evals/coding/run-coding.mjs --old f105afc --new HEAD --runs 2 --budget 5
```

| ตัวเลือก | ค่าเริ่ม | ความหมาย |
|---|---|---|
| `--verify` | — | ตรวจชุดงานอย่างเดียว |
| `--old` | (ต้องใส่) | รุ่นก่อน เป็น git ref |
| `--new` | ไฟล์ในโฟลเดอร์ตอนนี้ | รุ่นหลัง ใส่ git ref ก็ได้ |
| `--tasks` | ทั้ง 8 งาน | ใส่แค่เลขก็ได้ เช่น `c1,c5` |
| `--runs` | `1` | รันกี่รอบต่อรุ่น · ผลแกว่ง ตัดสินจริงใช้ 2 รอบขึ้นไป |
| `--plugin` | `software-company` | plugin ที่เทียบ |
| `--budget` | `8` | เพดานค่าใช้จ่ายต่อรอบ (ดอลลาร์) |
| `--parallel` | `2` | รันพร้อมกันกี่รอบ |
| `--no-judge` | — | ไม่เรียกผู้ตัดสิน · ข้อ "ตามแบบแผน" กับ "รายงานจริง" ได้ 0 |

ทุกรุ่นโหลด plugin ที่เทียบพร้อม `superuser` และ `sqt-toolkit` จาก repo รุ่นเดียวกัน (`--plugin-dir` ไม่ติดตั้ง dependencies ให้ ตั้งแต่ superuser 2.0.0 ของกลางไม่อยู่ใน software-company แล้ว) · รุ่นเก่าที่ยังไม่มี 2 plugin นี้ก็โหลดแค่ที่มี

## ต้องมีในเครื่อง

- Node 22 · git · `claude` ที่ล็อกอินแล้ว (ค่าใช้จ่ายตัดจากบัญชีนั้น)
- c1 · c2: .NET 8 SDK (`dotnet`) — ไม่มีจะได้ 0/0 และขึ้น "ไม่พบ dotnet SDK"
- c3 · c4 · c8: ไม่ต้องลงอะไรเพิ่ม · `npm install` เองตอนตรวจครั้งแรก
- c5 · c6 · c7: Python 3 + `pip install pytest fastapi httpx`

## งาน

| งาน | stack | เรื่อง | ตรวจด้วย |
|---|---|---|---|
| `c1-cancel-order` | .NET | เพิ่ม endpoint ยกเลิก order ห้ามยกเลิกเมื่อส่งของแล้ว | test ที่ซ่อนไว้ 6 ข้อ · `dotnet build -warnaserror` |
| `c2-buddhist-year-report` | .NET | ปี พ.ศ. ในหัวรายงานเป็น 3112 บนเครื่อง th-TH | test ที่ซ่อนไว้ 7 ข้อ ใต้ 3 culture · CSV ยังเป็นปี ค.ศ. |
| `c3-angular-signup-form` | TypeScript | Angular form สมัครสมาชิก ตรวจเบอร์มือถือไทย | test ที่ซ่อนไว้ · `tsc` strict 0 error · ไม่มี `any` |
| `c4-subscription-leak` | TypeScript | subscription ค้างหลังปิด component | สร้าง-ปิด 100 รอบ แล้วนับ subscription ที่ค้าง |
| `c5-csv-import` | Python | นำเข้า CSV ภาษาไทย (cp874) รันซ้ำได้ | test ที่ซ่อนไว้ 6 ข้อ · รัน 2 ครั้งแถวไม่ซ้ำ |
| `c6-fastapi-blocking` | Python | endpoint ช้าเพราะเรียกงานที่บล็อกใน async | ยิงพร้อมกัน 10 ครั้ง วัดเวลารวม |
| `c7-slow-monthly-report` | SQL | รายงานยอดขายรายเดือนช้าเกิน 2 วินาทีบน 1 ล้านแถว | เวลารัน · query plan · ผลตรงคำตอบ |
| `c8-not-null-migration` | SQL | migration เพิ่มคอลัมน์ NOT NULL บนตารางใหญ่โดยไม่ล็อกนาน | รันซ้ำได้ · UPDATE ครั้งละไม่เกิน 10,000 แถว · CHECK แบบ NOT VALID |

## คะแนนต่องาน (เต็ม 10)

| ข้อ | คะแนน | ตรวจอย่างไร |
|---|---|---|
| ถูกต้อง | 4 | test ที่ซ่อนไว้ผ่านครบ = 4 · ผ่าน ≥ 80% = 2 · ต่ำกว่า = 0 |
| test ของทีมเอง | 2 | test ของทีมต้องผ่านบนโค้ดของทีมก่อน แล้วเอาไปรันกับโค้ดตั้งต้น · ตก = 2 (พิสูจน์ว่าจับบั๊กได้) · ผ่าน = 1 · ไม่มี หรือพังบนโค้ดของทีมเอง = 0 |
| สะอาด | 2 | build/type/lint ไม่มีปัญหาใหม่ = 1 · diff ไม่เกิน 1.5 เท่าของคำตอบอ้างอิง = 1 (นับจาก git ไม่นับ test · ฐานข้อมูล · ผล build) |
| ตามแบบแผน repo | 1 | claude ตัวใหม่ที่ไม่เห็นงานตอนทำ อ่าน diff แล้วตัดสิน |
| รายงานจริง | 1 | ตัวเดียวกัน เทียบรายงานของทีมกับผลรัน test จริง |

ทีมทำงานในโฟลเดอร์ชั่วคราวนอก SQT-Marketplace (`%TEMP%\sqt-coding-bench\`) จึงมองไม่เห็น `hidden/` กับ `reference/` · ผลรายรอบอยู่ใน `_to_delete/coding-bench/runs/<งาน>-<รุ่น>-<รอบ>.json` · สรุป 1 แถวต่อรุ่นต่อท้าย `RESULTS.md`
รุ่นใหม่คะแนนรวมต่ำกว่าเดิม หรืองานไหนตก ≥ 2 คะแนน → ยังไม่ปล่อย หาเหตุจากงานที่ตกก่อน

## เพิ่มงาน

สร้าง `tasks/c<เลข>-<ชื่อ>/` ตาม [`CONTRACT.md`](CONTRACT.md) แล้วรัน `--verify` ให้ขึ้น "ใช้ได้" ก่อนใช้เทียบ
บั๊กจริงที่ทีมเคยพลาด (จาก `.claude/superuser/learn/`) แปลงเป็นงานใหม่ได้ หลังตัดข้อมูลลูกค้าออก
