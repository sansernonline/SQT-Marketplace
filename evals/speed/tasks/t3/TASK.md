# ทำ 4 โมดูลอรรถประโยชน์ภาษาไทย (แต่ละโมดูลไม่ขึ้นต่อกัน)

ทำทั้ง 4 ไฟล์ใน `src/` พร้อม unit test ของตัวเองต่อโมดูล (ESM · Node 22 · ห้ามใช้ dependency ภายนอก)

1. `src/thaiId.js` → `export function isValidThaiId(id)` ตรวจเลขบัตรประชาชน 13 หลักด้วย checksum มาตรฐาน · รับได้ทั้งแบบมีขีด (`1-1037-02071-81-1`) และไม่มีขีด · อย่างอื่นคืน `false`
2. `src/phone.js` → `export function normalizeThaiMobile(s)` รับเบอร์มือถือไทยหลายรูปแบบ (`081-234-5678` · `+66812345678` · `66 81 234 5678` · `0812345678`) คืน `+66812345678` · ไม่ใช่มือถือไทย (ขึ้นต้น 06/08/09 หลังแปลง 10 หลัก) → โยน `Error`
3. `src/bahtText.js` → `export function bahtText(amount)` แปลงเงินเป็นคำอ่านไทยแบบใบเสร็จ เช่น `1234.5` → `หนึ่งพันสองร้อยสามสิบสี่บาทห้าสิบสตางค์` · `21` → `ยี่สิบเอ็ดบาทถ้วน` · `0` → `ศูนย์บาทถ้วน` · `1000000` → `หนึ่งล้านบาทถ้วน` · `0.25` → `ยี่สิบห้าสตางค์` · ปัดสตางค์ 2 ตำแหน่ง
4. `src/buddhist.js` → `export function toBuddhistDate(iso)` รับ `YYYY-MM-DD` (ค.ศ.) คืน `DD/MM/YYYY` (พ.ศ.) เช่น `2026-10-19` → `19/10/2569` · วันที่ไม่มีจริง (เช่น `2026-02-30`) → โยน `Error`

รัน test ด้วย `npm test`
