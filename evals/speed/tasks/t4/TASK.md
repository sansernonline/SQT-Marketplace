# ชุดเครื่องมือออกใบเสร็จสำหรับลูกค้า (ส่งมอบลูกค้าใช้จริง)

ลูกค้าจะใช้ชุดนี้ออกใบเสร็จจริง ต้องถูกทุกกรณี มีงาน 5 ชิ้นที่ไม่ขึ้นต่อกัน:

1. `receipt.py` → `calc_receipt` ตาม `SPEC.md` ทุกกฎ (R1–R6) · test ด้วย `python3 -m pytest -q`
2. `src/thaiId.js` → `export function isValidThaiId(id)` ตรวจเลขบัตรประชาชน 13 หลักด้วย checksum มาตรฐาน · รับได้ทั้งแบบมีขีดและไม่มีขีด · อย่างอื่นคืน `false`
3. `src/phone.js` → `export function normalizeThaiMobile(s)` รับเบอร์มือถือไทยหลายรูปแบบ (`081-234-5678` · `+66812345678` · `66 81 234 5678` · `0812345678`) คืน `+66812345678` · ไม่ใช่มือถือไทย (ขึ้นต้น 06/08/09 หลังแปลง 10 หลัก) → โยน `Error`
4. `src/bahtText.js` → `export function bahtText(amount)` แปลงเงินเป็นคำอ่านไทยแบบใบเสร็จ เช่น `1234.5` → `หนึ่งพันสองร้อยสามสิบสี่บาทห้าสิบสตางค์` · `21` → `ยี่สิบเอ็ดบาทถ้วน` · `0` → `ศูนย์บาทถ้วน` · `1000000` → `หนึ่งล้านบาทถ้วน` · `0.25` → `ยี่สิบห้าสตางค์` · ปัดสตางค์ 2 ตำแหน่ง
5. `src/buddhist.js` → `export function toBuddhistDate(iso)` รับ `YYYY-MM-DD` (ค.ศ.) คืน `DD/MM/YYYY` (พ.ศ.) · วันที่ไม่มีจริง → โยน `Error`

ทุกชิ้นต้องมี unit test ของตัวเอง (JS: ESM · Node 22 · `npm test` · ห้ามใช้ dependency ภายนอก)
