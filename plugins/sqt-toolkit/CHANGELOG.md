# Changelog — sqt-toolkit

## 1.0.0 — 2026-10-22

- plugin ใหม่ แยกจาก `superuser` 3.0.0 — skill เอกสาร สไลด์ รูป ประชุม ข้อความ และชื่อ 15 ตัวที่ทุกสาขาใช้ร่วมกัน: `branded-document-design` · `diagram-figures` · `document-naming` · `html-slide-deck` · `image-generation` · `markdown-report-docx` · `markdown-visuals` · `meeting-prep-card` · `meeting-summary` · `polished-document-style` · `polite-message-th-en` · `pptx-to-html-deck` · `presentation-design` · `product-naming` · `spell-out-abbreviations` (เนื้อหาเท่าเดิม ชื่อเดิม)
- plugin สาขาทุกตัวประกาศ `{ "name": "sqt-toolkit", "version": "^1.0" }` ใน `dependencies` จึงติดตั้งมาเอง · ติดตั้ง `superuser` เดี่ยวแล้วอยากได้ skill ชุดนี้ → `/plugin install sqt-toolkit@sqt-marketplace`
- ไม่มี agent · hook · คำสั่ง — เป็น skill ล้วน ใช้กับ plugin ไหนก็ได้
