## 3 · คุณภาพของแต่ละไฟล์

- [ ] `.docx` ทุกไฟล์เปิด Navigation Pane แล้วเห็นหัวข้อครบ
- [ ] ทุกไฟล์มีหน้าประวัติการแก้ไข · เลขเวอร์ชัน · วันที่ · ผู้จัดทำ
- [ ] ตัวย่อทุกตัวกางเต็มครั้งแรกที่ปรากฏ
- [ ] ชื่อไฟล์ตรงตามรูปแบบใน `document-naming`
- [ ] เอกสารในชุดอ้างเวอร์ชันของกันและกันตรงกัน

## 4 · รูป

- [ ] ทุกรูปมีเลขรูป และถูกอ้างในเนื้อความอย่างน้อยหนึ่งครั้ง
- [ ] หัวรูปครบห้าอย่าง — ชื่อ · คำขยาย · เลขรูป · เวอร์ชันกับวันที่ · เจ้าของ
- [ ] ไฟล์ต้นทางอยู่ใน `docs/figures/src/` ครบทุกใบ
- [ ] รูปในเอกสารส่งมอบไม่ใช่ Mermaid ค่าเริ่มต้น
- [ ] ย่อรูปเหลือความกว้าง 25% แล้วยังแยกออกว่าอะไรอยู่ตรงไหน
- [ ] ข้อความไทยในรูปครบ ไม่มีสระหรือวรรณยุกต์หาย

## 5 · ความสม่ำเสมอของชุด

- [ ] ทุกไฟล์ต้นทางประกาศ `doc-theme` ค่าเดียวกัน
- [ ] สีในรูป สไลด์ และเอกสาร เป็นชุดเดียวกัน
- [ ] ฟอนต์และขนาดหัวข้อเหมือนกันทุกไฟล์
