## E. ข้อจำกัด

- runtime เห็นเฉพาะ request และ response ที่วิ่งผ่านจริงในฉากที่บันทึก · endpoint ที่ไม่ได้แตะไม่มีในเอกสารนี้ ซึ่งไม่ได้แปลว่าไม่มี
- ตรรกะฝั่ง server ดูจาก network ไม่ได้ ถ้าต้องรู้ให้ทำ CODEBASE-MAP หรือ SYSTEM-MAP ประกอบ
- TLS ที่ไม่ได้ถอดรหัสเห็นแค่ชื่อ host และขนาด ไม่เห็นเนื้อหา
