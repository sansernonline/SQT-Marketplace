# วิธีค้นข้อมูลออกแบบ

ใช้กับ `scripts/design_search.py` · ค้นได้ทั้งไทย อังกฤษ และปนกัน เพราะตัวค้นตัดคำไทยเองและมีตารางคำพ้องไทย-อังกฤษ

## ค้นอย่างไรให้เจอ

- **1 ครั้ง 1 เจตนา 2–5 คำ** เช่น `ร้านทองออนไลน์` · `date picker พ.ศ.` · `ฟอนต์ไทยมีหัว ทางการ` ถ้าใส่ทั้งย่อหน้า คำที่ไม่เกี่ยวจะดึงคะแนนกระจาย
- **เลือก domain ให้ตรงคำถาม** ถ้าไม่ใส่ ตัวค้นถือว่าเป็น `industry`

| อยากรู้ | domain | ตัวอย่างคำค้น |
|---|---|---|
| ธุรกิจนี้ควรมีบุคลิก look สี ฟอนต์แบบไหน | `industry` | `คลินิกทันตกรรม` · `cooperative savings` |
| พาเลต 2 โหมดตามอารมณ์หรือวัสดุ | `palette` | `ทอง หรู` · `calm green` |
| คู่ฟอนต์ไทย-ละติน | `font` | `มีหัว ทางการ` · `rounded friendly` |
| look (ความลึก การเคลื่อนไหว ข้อห้าม) | `look` | `editorial` · `งานมือไทย` |
| กฎ UX และกฎไทย | `ux` | `ช่องวันที่ พ.ศ.` · `touch target` |
| ข้อมูลแบบนี้ใช้กราฟอะไร | `chart` | `แนวโน้มยอดขายรายเดือน` |
| ลำดับ section ของหน้าแรก | `landing` | `สั่งซื้อผ่าน LINE` · `booking` |
| กฎเฉพาะเฟรมเวิร์ก | `stack` + `--stack <ชื่อ>` | `ฟอร์ม validation --stack blazor` |

- ดูชื่อ stack ที่มี: เปิดโฟลเดอร์ `data/stacks/` (1 ไฟล์ต่อ stack) หรือสั่งค้นด้วยชื่อที่ไม่มี ตัวค้นจะบอกรายชื่อ
- ต้องการผลไปใช้ต่อในสคริปต์ ใส่ `--json` · ต้องการมากกว่า 3 แถว ใส่ `-n 10`

## เมื่อค้นไม่เจอ

ตัวค้นตอบว่า "ไม่พบที่ตรง" เมื่อคำในโจทย์ที่มีอยู่ในข้อมูลถูกครอบคลุมไม่ถึง 25 % ให้ทำตามลำดับนี้:

1. เปลี่ยนเป็นคำที่คนในวงการใช้ หรือสลับภาษา 1 ครั้ง (`ร้านขายยา` → `pharmacy`)
2. ยังไม่เจอ ให้บอกผู้ใช้ตรง ๆ ว่าข้อมูลยังไม่มีแถวนี้ แล้วเลือกจากแถวที่ใกล้ที่สุดเอง พร้อมเขียนไว้ใน `## ตัดสินใจเอง`
3. ห้ามแต่ง id สี หรือฟอนต์ที่ตัวค้นไม่ได้คืนมา แล้วเล่าเหมือนมาจากข้อมูล

## อ่านผล

- `คะแนน` คือ BM25 ใช้เทียบในคำค้นเดียวกันเท่านั้น ข้ามคำค้นเทียบกันไม่ได้
- `ครอบคลุม` คือสัดส่วนคำในคำค้น (ถ่วงตามความหายาก) ที่แถวนั้นมี · ต่ำกว่า 50 % แปลว่าตรงบางส่วน ให้ดูแถวก่อนใช้
- พาเลตคืน 1 ผลต่อ id แต่ใน `--json` มีทั้ง 2 โหมด (`rows`)

## วัดความแม่น

`python scripts/design_search.py --eval references/relevance-cases.json` รายงาน % ที่ id ที่คาดอยู่ใน 3 อันดับแรก แยกชุด calibration กับ holdout และแยกไทยกับอังกฤษ · แก้ตัวค้นหรือคำค้นในชุด calibration ได้ · **ห้ามแก้เคส holdout ให้ผ่าน** เพราะชุดนั้นมีไว้วัดว่าตัวค้นใช้กับคำที่ไม่เคยเห็นได้จริง
