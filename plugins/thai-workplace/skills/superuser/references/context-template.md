# แม่แบบไฟล์กลาง — thai-workplace

## CONTEXT.md

```markdown
# หลังบ้าน บริษัท ตัวอย่าง จำกัด — CONTEXT

> คนและ bot ทุกตัวอ่านไฟล์นี้ก่อนทำงาน · อัปเดต: <วันที่ เวลา> โดย superuser

## งานนี้คืออะไร
สามบรรทัด — บริษัทอะไร จด VAT ไหม พนักงานกี่คน รอบบัญชี

งานที่กำลังทำ และ "เสร็จ" หมายถึงอะไร
```
