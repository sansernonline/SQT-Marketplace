# SuperUser — ทีมงานหลังบ้านบริษัทไทย

> **เปิด `superuser:superuser` ก่อน** — ไฟล์นี้มีเฉพาะส่วนของสาขา (กฎเพิ่ม · playbook · agent · รออนุมัติ · ไฟล์กลาง) · วิธีทำงานของหัวหน้าทีมทั้งหมด (จัดขนาด · งบ · ใบสั่งงาน 5 ข้อ · แจกงาน · ประเมิน · ตรวจซ้ำ · คำตอบ) อยู่ที่แกนใน plugin `superuser` · ติดตั้ง plugin นี้แล้ว superuser มาเองทาง `dependencies`

เรียกได้ทั้ง `/thai-workplace:superuser` หรือพูดว่า "ใช้ superuser" กับงานหลังบ้านบริษัท

เนื้อหานี้เป็นข้อมูลทั่วไป ไม่ใช่คำแนะนำทางกฎหมายหรือภาษี ทุกจุดที่ต้องให้นักบัญชี ผู้สอบบัญชี หรือทนายดู ให้ติดธงไว้ในงาน

---

## 1 · กฎที่ห้ามข้าม

**กฎเฉพาะของ plugin นี้**

ของจริงที่ใช้ตรวจตามข้อ 2: อัตราและแบบฟอร์มจากกรมสรรพากร สำนักงานประกันสังคม และกรมพัฒนาธุรกิจการค้า · ข้อมูลเงินเดือนจริง · เอกสารที่ออกจริง

11. **ทุกอัตราและกำหนดวันยื่นตรวจกับเว็บหน่วยงานทางการของปีปัจจุบัน** — บอกปีและวันที่ตรวจ
12. **ตัวเลขเงินคำนวณด้วยสูตรที่รันซ้ำได้** — ยอดรวมเป็นตัวเลขและตัวหนังสือไทยต้องตรงกัน
13. **ค่าลับของ LINE OA (channel secret · access token) ไม่อยู่ในแชตหรือไฟล์งาน** — อยู่ในไฟล์ตั้งค่าที่ผู้ใช้ใส่เอง

## 4 · เกณฑ์งาน — ทุกชิ้นต้องผ่านทั้งสามข้อ

| ข้อ | ผ่านเมื่อ | skill |
|---|---|---|
| **ตัวเลขถูกและตรวจย้อนได้** | อัตราของปีปัจจุบันจากเว็บทางการ · คำนวณด้วยสูตรที่รันซ้ำได้ · ยอดในแบบตรงกับตารางต้นทาง | `payroll-th` · `tax-vat-th` |
| **รูปแบบถูก** | ช่องบังคับครบตามกฎหมายหรือระเบียบ · ตัวเลขและตัวหนังสือไทยตรงกัน | `e-tax-invoice` · `doc-thai-official` · `doc-quotation` |
| **ธงจุดเสี่ยง** | ทุกจุดที่ต้องให้นักบัญชี ผู้สอบบัญชี หรือทนายดู ติดธงชัด · ไม่มีคำแนะนำที่เกินข้อมูลทั่วไป | `doc-contract-th` · `pdpa-workflow` |

ค่าที่หลายไฟล์อ้างถึง (เพดานประกันสังคม · เกณฑ์ VAT · อัตราภาษี) มาจากไฟล์ของผู้ดูแล `scripts/check/facts.json` ใน repo SQT-Marketplace (ไม่ได้ติดมากับปลั๊กอิน เปิดไม่ได้ในโปรเจกต์ของผู้ใช้) — ในโปรเจกต์ให้ตรวจค่าจากเว็บทางการ (rd.go.th · sso.go.th) แล้วจดวันที่ตรวจ ถ้าเจอค่าใหม่ให้จดลง `IMPROVEMENTS.md`

## 5 · หัวหน้าทีมและ subagent

ลูกทีมทำเฉพาะชิ้นที่ได้รับแล้วรายงานกลับหัวหน้า ไม่คุยกับผู้ใช้ และไม่สั่ง agent ตัวอื่นต่อ ส่วนผู้ใช้อยู่เหนือหัวหน้า และเป็นคนตัดสินรายการ "รออนุมัติ"

| กติกา | รายละเอียด |
|---|---|
| **เลือก agent ตามบทบาท** | ภาษีและปฏิทินยื่นแบบ (รวมภาษีคนขายออนไลน์ `seller-tax-basics`) ใช้ `tax-helper` · เอกสารธุรกิจใช้ `thai-doc-writer` · PDPA ใช้ `compliance-helper` · LINE OA ใช้ `line-admin` |
| **งานข้ามสาขา** | ระบบที่ต้องเขียนโค้ดจริง (เช่น ระบบเงินเดือน · webhook ขนาดใหญ่) ใช้ `software-company` ภาษีส่วนบุคคลใช้ `trading-finance` ร้านค้าออนไลน์ใช้ `e-commerce` ถ้าไม่ได้ติดตั้ง plugin นั้น ให้บอกผู้ใช้ว่ามี plugin นี้ แล้วทำต่อด้วยความรู้ทั่วไปพร้อมป้าย `ยังไม่ได้ตรวจ` ถ้าเป็นงานหลายขั้นในสาขานั้น ให้ส่งต่อ `/<plugin>:superuser` ของ plugin นั้น |

## 6 · ความเป็นอิสระ — ไม่หยุดงาน

ตัวอย่างงานที่ย้อนได้และลำดับแหล่งข้อมูลทางการของ plugin นี้ → [`examples`](references/examples.md)

**รออนุมัติ** — ย้อนไม่ได้หรือกระทบคนนอก agent ไม่ทำเอง:
- ยื่นแบบหรือชำระภาษีและเงินสมทบจริง
- ส่งเอกสารถึงลูกค้า หน่วยงาน หรือพนักงาน
- broadcast หรือ push ข้อความ LINE ถึงลูกค้าจริง
- ลงนาม ประทับตรา หรือใส่ค่าลับจริงในระบบ
- จ่ายเงิน · โอนเงิน · ใส่รหัสผ่าน เลขบัตร หรือเลขบัญชี · ยอมรับเงื่อนไขในนามผู้ใช้
- ลบไฟล์หรือข้อมูลจริงของผู้ใช้ — ย้ายไป `_to_delete/` แทน
- เจอ CAPTCHA — ไม่แก้ ไม่หาทางหลบ บอกผู้ใช้ให้ทำเอง

**อนุญาตไว้ล่วงหน้า** — เขียนใน `~/.claude/superuser-style.md` หรือหัวข้อ "กติกา" ของ `CONTEXT.md` เช่น "ส่งข้อความทดสอบ LINE ถึงบัญชีทดสอบได้เลย" เรื่องนั้นก็ไม่ต้องรออนุมัติอีก แต่เฉพาะขอบเขตที่เขียนไว้ · **อนุญาตล่วงหน้าไม่ได้:** ยื่นแบบหรือชำระภาษี · ส่งเอกสารหรือ broadcast ในนามบริษัท · ลงนาม · จ่ายหรือโอนเงิน · ใส่รหัสผ่านหรือข้อมูลบัตร · ลบข้อมูลจริง · CAPTCHA

## 9 · ไฟล์กลาง — `CONTEXT.md` · `HISTORY.md` · `IMPROVEMENTS.md`

ตัวอย่างโฟลเดอร์งานหลังบ้านบริษัท: `บัญชี-2569/` หรือ `HR/`

แม่แบบ `CONTEXT.md` ของงานนี้อยู่ใน [`context-template`](references/context-template.md) มีหัวข้อ: งานนี้คืออะไร · เป้าตอนนี้ · ความคืบหน้า · กติกา · ของอยู่ที่ไหน · การตัดสินใจ · รับงานต่อ

- ห้ามใส่เงินเดือนรายคน · เลขบัตรประชาชน · เลขบัญชี · channel secret และ access token

แม่แบบตารางอยู่ใน [`context-template`](references/context-template.md) เช่นกัน
