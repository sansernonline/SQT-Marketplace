# ตัวอย่างของ plugin นี้ — ระดับโมเดล · ความเป็นอิสระ · รูปแบบทีม

ย้ายมาจาก `SKILL.md` หัวข้อ 5 · 6 · 10 · กฎอยู่ใน `SKILL.md` ไฟล์นี้มีแต่ตัวอย่าง

## ระดับโมเดล — ตัวอย่างงาน (หัวข้อ 5)

กฎ ชื่อโมเดล และการสลับกลางทาง อยู่ในบล็อก `team` ของ `SKILL.md` · ไฟล์นี้มีแต่ตัวอย่างงานของแต่ละระดับ

มี 3 ระดับ หัวหน้าทีมเลือกเองตามงาน · **ใหญ่** — หาเหตุบิลขึ้นที่ซับซ้อน · วางระบบดูแลผู้สูงอายุ · เทียบใบเสนอราคาที่ขอบเขตไม่เท่ากัน · **กลาง** (ค่าเริ่มต้น) — ร่างเอกสาร · คำนวณตามสูตร · จัดตาราง · **เล็ก** — งานกลไกที่คำตอบชัด: ค้นไฟล์ · เปลี่ยนชื่อ · สรุปรายการ

## ความเป็นอิสระ — งานที่ย้อนได้และแหล่งข้อมูล (หัวข้อ 6)

| เจอ | ทำ |
|---|---|
| งานที่ย้อนกลับได้ — ร่างตาราง · ร่างข้อความ · ตั้งไฟล์เตือน | ทำเลย |
| ไม่รู้ข้อเท็จจริงสาธารณะ (อัตราค่าไฟและน้ำ · สิทธิ์สวัสดิการ · ขั้นตอนต่อภาษีรถ) | ค้นเอง ไล่แหล่งตามลำดับ: เว็บหน่วยงานรัฐและรัฐวิสาหกิจที่เกี่ยว → ราชกิจจานุเบกษา → สำนักข่าว · ใช้ได้ตามกฎ 3 แหล่งในหัวข้อ 6 ของ `superuser` |

## รูปแบบทีม — ใช้อย่างไรในงานนี้ (หัวข้อ 10)

วิธีทำ ต้นทุน และกับดักของแต่ละแบบอยู่ใน `agent-patterns`

| รูปแบบ | ในงานนี้ใช้อย่างไร |
|---|---|
| **Planning** | ปฏิทิน 12 เดือน → ทีละงาน |
| **ReAct** | อ่านบิล → เทียบ 3 เดือน → หาเหตุ |
| **Reflection** | `reviewer` ตัวใหม่ (อ่านอย่างเดียว ไม่ใช่ `home-manager` ที่ทำงานชิ้นนั้น) เทียบตัวเลขในตารางกับบิลจริง |
| **Multi-Agent** | `home-manager` ทำบิลและบ้าน · `family-planner` ทำอาหารและโรงเรียน |
| **Mixture-of-Agents (MoA)** | ใบเสนอราคาช่าง → 3 มุม: ราคา · ขอบเขต · ความเสี่ยง แล้วรวม |
| **Reranker** | เมนูหรือร้านค้าหลายสิบ → ให้คะแนนงบ · เวลา · โภชนาการ → เลือกสัปดาห์ละ 7 |
