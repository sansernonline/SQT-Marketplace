# Reverse Engineer

เครื่องมือวิเคราะห์ซอฟต์แวร์ที่เป็นเจ้าของหรือได้รับอนุญาต โดยยึดหลักฐานและบอกข้อจำกัดทุกครั้ง · วิเคราะห์สถิตด้วยเครื่องมือมาตรฐานที่ผู้ใช้ติดตั้งเอง ไม่ดาวน์โหลดเครื่องมือหรือแพ็กเกจจาก registry สาธารณะตอนรัน

## ตรวจเครื่องมือ

1. ตรวจเครื่องมือทั้งหมด: `npm run doctor`
2. ตรวจเฉพาะกลุ่ม: `npm run doctor -- --target android`
3. ต้องการผลแบบ JSON: `npm run doctor -- --json`

กลุ่มที่มี: `native`, `android`, `web`, `network`, `firmware` รายการและแหล่งติดตั้งทางการอยู่ใน `tools.json`

ตัวตรวจค้นหาเฉพาะคำสั่งบน PATH, ตำแหน่งติดตั้งมาตรฐาน และ Node package ไม่เปิดแอปเป้าหมาย ไม่ติดตั้งโปรแกรม และไม่รันเครื่องมือวิเคราะห์ คำว่า `missing` จึงไม่ได้ยืนยันว่าไม่ได้ติดตั้ง อาจเพียงไม่มีใน PATH หรืออยู่ใน WSL/container

เครื่องมือในแต่ละกลุ่มเป็นตัวเลือกตามงาน ไม่จำเป็นต้องติดตั้งครบทุกตัว เช่น native ใช้ Ghidra แทน IDA หรือ Hopper ได้ ผู้ใช้เป็นผู้ติดตั้งจากแหล่งทางการ และเครื่องมือเสียเงินต้องใช้สัญญาอนุญาตของผู้ใช้เอง

## ขอบเขตและความปลอดภัย

- เริ่มจากการอ่านไฟล์หรือ capture ที่มีอยู่ก่อน
- ต้องขออนุญาตแยกก่อนรันแอป ควบคุมอุปกรณ์ ดักทราฟฟิก หรือแก้ไขอุปกรณ์
- ทำกับสำเนาและเก็บผลแยกจากไฟล์ต้นฉบับ บันทึก SHA-256 ของต้นฉบับ
- เป้าหมายที่ไม่น่าไว้ใจรันได้เฉพาะใน sandbox ที่แยกจากเครื่องจริง
- ไฟล์ HAR, PCAP, proxy capture และผลดิบอาจมี cookie, token หรือข้อมูลส่วนบุคคล ห้าม commit หรือส่งออกนอกเครื่องโดยไม่ได้ตรวจและปิดค่าลับ

## ทดสอบ

`npm test` ตรวจโครงสร้างของ `tools.json` (ไอดีไม่ซ้ำ · ทุกตัวมีวิธีตรวจ · กลุ่มเป้าหมายถูกต้อง) ไม่ครอบคลุมการทำงานกับเครื่องมือภายนอกจริง
