# CODEBASE-MAP — แผนที่ระบบ <ชื่อระบบ> (อ่านโค้ดอย่างเดียว)

**วันที่ทำแผนที่:** <วันที่> · **วิธีทำ:** อ่านโค้ดอย่างเดียว ยังไม่ได้รันระบบเพื่อตรวจพฤติกรรม · <ใครอ่าน: agent กี่ตัว อ่านส่วนไหน · ใครเปิดบรรทัดสำคัญซ้ำ>

**วิธีอ่าน**
- path นับจาก `<โฟลเดอร์รากของระบบ>` เว้นแต่จะบอกไว้
- คอลัมน์ "ยืนยันจาก" = ไฟล์:บรรทัดที่เปิดดูจริง · **(ตรวจซ้ำ)** = มีคนเปิดซ้ำเองหลัง agent รายงาน · **อนุมาน** = ยังไม่ได้เปิดดูบรรทัดที่พิสูจน์ → ห้ามเอาแถวที่อนุมานไปตัดสินใจ
- ไม่ได้เปิด: <โฟลเดอร์/ไฟล์ที่ยังไม่ได้อ่าน>

## A. ภาพรวม

| เรื่อง | รายละเอียด | ยืนยันจาก |
|---|---|---|
| stack | <framework · ภาษา · เวอร์ชัน · ฐานข้อมูล> | <ไฟล์:บรรทัด> |
| build / รันยังไง | <คำสั่ง build · container · port> | <ไฟล์:บรรทัด> |
| ข้อมูลอยู่ที่ไหน | <memory · ไฟล์ · DB · localStorage ฝั่ง client> | <ไฟล์:บรรทัด> |
| auth | <วิธี login · session · cookie> | <ไฟล์:บรรทัด> |

|---|---|---|---|---|
| <path> | <ไฟล์> | <หน้าที่> | <server/client/คงที่> | <ไฟล์:บรรทัด> |
