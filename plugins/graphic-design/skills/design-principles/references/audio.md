# หลักคิด · Audio (เสียงของแบรนด์และคอนเทนต์: โลโก้เสียง จิงเกิล เสียงเล่า พอดแคสต์)
> ให้ผู้ฟังจำแบรนด์ได้จากเสียง ฟังคำพูดชัด ระดับเสียงสม่ำเสมอ และไม่เสี่ยงเรื่องลิขสิทธิ์

## งานดีคืออะไร
1. **เสียงแบรนด์ต้องจำได้และไม่เหมือนใคร** — เสียงที่เป็นเอกลักษณ์บอกความเป็นแบรนด์ได้แม้ไม่ต้องมองจอ ในงานวิจัยโฆษณา 2,000 ชิ้นของ Ipsos เสียงแบรนด์ดึงความสนใจได้ดีกว่าโลโก้ สโลแกน และมาสคอต · ตรวจด้วยตา: เปิดเสียงเปล่า ไม่มีภาพ ให้คนนอกทีมฟัง ทายได้ไหมว่าแบรนด์ไหน และเสียงตรงกับบุคลิกที่ตั้งไว้ (S1, S2, S3)
2. **ใช้เสียงชุดเดียวกันทุกจุดสัมผัส** — ความสม่ำเสมอข้ามช่องทางตัดสินว่าเสียงแบรนด์สำเร็จหรือไม่ ปรับจังหวะหรือพลังงานตามช่องทางได้ แต่ต้องมีรากดนตรีเดียวกัน · ตรวจด้วยตา: เรียงเสียงจากคลิป โฆษณา สายรอ พอดแคสต์ เปิดต่อกัน ต้องฟังเป็นแบรนด์เดียว (S1, S3, S2)
3. **เสียงพูดชัดมาก่อนดนตรี** — ดนตรี/เสียงพื้นหลังต้องเบากว่าเสียงพูดชัดเจน (ดูตัวเลขใน skill `video-editing`) และเสียงที่ฟังยากทำให้ผู้พูดดูน่าเชื่อถือน้อยลง · ตรวจด้วยตา: ฟังด้วยลำโพงโทรศัพท์ในที่มีเสียงรบกวน จับคำพูดได้ครบโดยไม่ต้องเร่งเสียง (S4, S5, S6)
4. **วัดความดังที่คนได้ยินเป็นหน่วย Loudness Units relative to Full Scale (LUFS) ไม่ใช่ยอดคลื่น และปรับให้ตรงเป้าที่แพลตฟอร์มแต่ละแห่งประกาศไว้** — ตัวเลขเป้าอยู่ใน `video-editing` · ตรวจด้วยตา: อ่านค่ารวมทั้งตอนจากมิเตอร์ แล้วเทียบกับเป้าที่ประกาศของช่องที่จะลง (S7, S8, S9, S10)
5. **เว้นที่ว่างกันเสียงแตก และให้ทุกตอนดังใกล้กัน** — ยอดสัญญาณจริง (true peak) ไม่เกิน −1 เดซิเบลทรูพีก (dBTP) และเสียงทุกตอน รวมโฆษณาที่แทรก ควรดังใกล้กัน ผู้ฟังจะไม่ต้องคอยปรับเสียง · ตรวจด้วยตา: เปิดสองตอนติดกัน แล้วเปิดโฆษณาแทรก ไม่มีตอนไหนดังหรือเบากว่ากันชัดเจน (S7, S8, S9, S10)
6. **ใช้เฉพาะเพลงและเสียงที่ได้สิทธิ์ถูกต้อง** — เพลงที่ไม่มีสิทธิ์ทำให้คลิปถูกเคลมหรือปิดเสียง และกฎหมายลิขสิทธิ์ไทยคุ้มครองงานดนตรี (เฉพาะประเทศไทย) · ตรวจด้วยตา: ทุกแทร็กในคลิปมีหลักฐานสิทธิ์ (ไลเซนส์หรือคลังฟรี) ติดกับไฟล์งาน (S11, S12, S13, S14)

## พลาดบ่อย
- ใช้เพลงดังจากเน็ต "แค่ท่อนสั้นๆ" → ถูก Content ID เคลม คลิปถูกปิดเสียง บล็อก หรือหารายได้ไม่ได้ (S11, S12, S14)
- เพลงประกอบดังเท่าเสียงพูด → กลบเนื้อหา ผู้ฟังหูไม่ดีตามไม่ได้ (S4, S5)
- ทำให้ดังที่สุดเพื่อ "ชนะ" ช่องอื่น → แพลตฟอร์มลดเสียงลงเอง เหลือแค่เสียงแบนและแตก (S7, S9, S10)
- ใช้เป้าความดังของโทรทัศน์กับพอดแคสต์มือถือ → เสียงเบาไป ฟังยากในที่ที่มีเสียงรบกวน (S10, S8)
- แต่ละแผนกเลือกเสียงเองไม่ดูแนวเดียวกัน → เสียงแบรนด์กระจัดกระจาย จำไม่ได้ (S3, S1)
- โลโก้เสียงยาวหรือซับซ้อนจนต้องฟังจบถึงรู้ว่าแบรนด์ไหน → ไม่ทันในฟีดและโฆษณาสั้น (S3)
