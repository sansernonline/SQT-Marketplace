# หลักคิด · LINE stickers and rich menu
> สติกเกอร์ต้องอ่านอารมณ์ออกในพริบตาในแชทเล็ก ๆ; rich menu ต้องให้ลูกค้าเจอและกดสิ่งที่ต้องการได้ทันที.

## งานดีคืออะไร
### Stickers
1. **อารมณ์ชัดในภาพเดียว** — สติกเกอร์ใช้แทนคำตอบ ถ้าต้องคิดก่อนแชทจะสะดุด [S1,S2,S4,S5] · ตรวจด้วยตา: ย่อเหลือขนาดในแชท แล้วยังบอกได้ทันทีว่า "ดีใจ/เหนื่อย/ขอบคุณ".
2. **ข้อความสั้น ตัวใหญ่ มีขอบ** — ตัวเล็กหรือไม่มีขอบจะอ่านไม่ออกเมื่อย่อ [S1,S3,S4,S5] · ตรวจด้วยตา: ย่อรูปแล้วอ่านคำได้ครบ ตัวอักษรไม่ชนขอบภาพ ไม่กลืนกับตัวการ์ตูน.
3. **ขอบสะอาด อ่านได้ทั้งพื้นสว่างและมืด** — พื้นหลังแชทเปลี่ยนตามธีมผู้ใช้ [S3,S4,S6] · ตรวจด้วยตา: ดูตัวอย่างโหมด Light และ Dark แล้วไม่มีขอบขาว รอยตัดหยาบ หรือส่วนที่หายไป.
4. **แต่ละรูปใช้ในสถานการณ์ต่างกัน** — ชุดที่ซ้ำหรือไม่หลากหลายถูกตีตกและไม่มีใครใช้ [S2,S3,S4] · ตรวจด้วยตา: เรียงทั้งชุด 1 หน้า ทุกรูปตอบคนละอารมณ์/คนละจังหวะแชท ไม่ใช่แค่เปลี่ยนสี.

### Rich menu
1. **ปุ่มไม่เกิน 6** — เกินนี้คนหาไม่เจอ ถ้ามีมากให้จัดกลุ่มแล้วเปิดเมนูย่อย [R1,R2,R3,R4] · ตรวจด้วยตา: นับปุ่ม; ปิดตา 3 วินาทีแล้วเปิดดู ต้องบอกได้ว่ามีอะไรบ้าง.
2. **มีปุ่มสำคัญหนึ่งปุ่มที่เด่นสุด** — ถ้าเด่นทุกปุ่มก็ไม่มีปุ่มไหนเด่น [R1,R2,R3] · ตรวจด้วยตา: หรี่ตามอง สายตาต้องไปที่ปุ่มหลักก่อน (เช่น สั่งซื้อ/จอง).
3. **ป้ายสั้น บอกว่ากดแล้วได้อะไร** — คำกว้างอย่าง "แนะนำ" ไม่บอกอะไร [R1,R2,R3,R5] · ตรวจด้วยตา: ทุกป้ายเป็นคำกริยา/ประโยชน์ไม่เกินไม่กี่คำ ภาษาที่ลูกค้าอ่านออก และชื่อ action ตรงกับป้าย.
4. **พื้นที่กดใหญ่พอและไม่ชิดกัน** — เป้าเล็กกดพลาดและช้า [A1,A2,A3] · ตรวจด้วยตา: บนมือถือจริง แต่ละช่องกว้างอย่างน้อยราว 1 ซม. (44–48 หน่วยของระบบ) และมีช่องว่างคั่น.
5. **ดูออกว่ากดได้ เรียบ ตัดกันชัด** — พื้นรกหรือสีเยอะทำให้ตัวหนังสือจม [R1,R2,R4,A2] · ตรวจด้วยตา: ฟอนต์ไม่เกิน 2 แบบ สีหลัก 1–2 สี ตัวหนังสือตัดกับพื้นชัด และดูตัวอย่างแล้วไม่เพี้ยนบนแต่ละเครื่อง.
6. **สดและตรงบริบท ไม่ใช่โฆษณาล้วน** — เมนูเก่าหรือขายอย่างเดียวทำให้คนเมินหรือบล็อก [R2,R3,R5,R6,R7] · ตรวจด้วยตา: มีทั้งปุ่มโปรโมชันและปุ่มช่วยลูกค้า (ติดต่อ/เวลาเปิด) และช่วงแสดงผลไม่หมดอายุ.

## พลาดบ่อย
- ใส่ปุ่ม 7+ หรือเน้นทุกปุ่มเท่ากัน → หาไม่เจอ กดผิด ไม่รู้ว่าอะไรสำคัญ.
- ใช้รูปถ่ายรกเป็นพื้นแล้ววางตัวหนังสือทับ → ป้ายอ่านไม่ออก ปุ่มดูไม่กดได้.
- ป้ายคลุมเครือหรือเป็นอังกฤษล้วน → ลูกค้าไม่รู้ว่ากดแล้วได้อะไร ไม่กด.
- ข้อความสติกเกอร์ยาว ตัวเล็ก ไม่มีขอบ → ย่อในแชทแล้วอ่านไม่ออก.
- ภาพชิดขอบ ตัดหยาบ ไม่ลองพื้นมืด → ขอบขาด/หายในบางธีม ไม่ผ่านรีวิว.
- ทั้งชุดท่าเดียวเปลี่ยนแค่สีหรือคำ → ใช้ซ้ำจนเบื่อ และถูกมองว่าขาดความหลากหลาย.
