# playbook · money-plan — แผนการเงินส่วนบุคคล

ใช้เมื่อ: ทำงบรายเดือน · เงินสำรองฉุกเฉิน · ปลดหนี้ · วางแผนเกษียณ · ทบทวนประกัน · เลือกกองทุน
skill หลัก: `personal-budget` · `emergency-fund` · `debt-payoff` · `retirement-plan` · `insurance-review` · `mutual-fund-picker`

## ขั้นตอน (คัดลง todo ตรงตัว)

1. เก็บตัวเลขจริง — รายรับ รายจ่ายจาก statement หนี้ ประกัน เงินออม ตัวไหนไม่มีให้ใส่ `[...]`
2. ทำตามลำดับ: งบรายเดือน → เงินสำรองฉุกเฉิน → หนี้ดอกสูง → เกษียณและการลงทุน
3. ใช้ skill ของแต่ละเรื่อง และตรวจอัตราและกฎของปีปัจจุบันกับแหล่งทางการ
4. ทุกทางเลือกแสดงตัวเลขเทียบกัน ไม่ชี้ว่าต้องเลือกทางไหน
5. ตรวจ — สูตรคำนวณซ้ำได้ และยอดรวมรายรับรายจ่ายตรงกับ statement

## จบเมื่อ

แผนเป็นตารางที่คำนวณซ้ำแล้ว ทุกอัตรามีแหล่ง และทางเลือกพร้อมตัวเลขให้ผู้ใช้ตัดสินเอง
