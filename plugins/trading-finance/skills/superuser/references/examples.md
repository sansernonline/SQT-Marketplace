# ตัวอย่างของ plugin นี้ — ระดับโมเดล · ความเป็นอิสระ · รูปแบบทีม

ย้ายมาจาก `SKILL.md` หัวข้อ 5 · 6 · 10 · กฎอยู่ใน `SKILL.md` ไฟล์นี้มีแต่ตัวอย่าง

## ระดับโมเดล — ตัวอย่างงาน (หัวข้อ 5)

กฎอยู่ในบล็อก `team` ของ `SKILL.md` · ข้อความเดิม:

มี 3 ระดับ หัวหน้าตัดสินเองตามงาน · **ใหญ่** — หารูปแบบความผิดพลาดจากบันทึกยาว · วางแผนภาษีที่มีรายได้หลายประเภท · ตรวจกรณีสงสัยมิจฉาชีพ · **กลาง** (ค่าเริ่มต้น) — ร่างเอกสาร · คำนวณตามสูตร · จัดตาราง · **เล็ก** — งานกลไกที่คำตอบชัด: ค้นไฟล์ · เปลี่ยนชื่อ · สรุปรายการ ถ้าไม่แน่ใจให้ใช้กลาง ถ้าโมเดลเล็กทำพลาดหรือตรวจไม่ผ่าน ให้ขยับขึ้น 1 ระดับ ไม่ลองซ้ำกับตัวเดิม · ชื่อจริงตอนนี้: ใหญ่ = `opus` · กลาง = `sonnet` · เล็ก = `haiku` · สลับกลางทางได้ แต่ต้องอัปเดต "รับงานต่อ" ก่อนสลับ

## ความเป็นอิสระ — งานที่ย้อนได้และแหล่งข้อมูล (หัวข้อ 6)

| เจอ | ทำ |
|---|---|
| งานที่ย้อนกลับได้ — ร่างแผน · คำนวณในสเปรดชีตหรือสคริปต์ · บันทึกพอร์ตจำลอง · จัดไฟล์บันทึกการเทรด | ทำเลย |
| ไม่รู้ข้อเท็จจริงสาธารณะ (อัตราภาษีและเพดานลดหย่อน · กฎตลาด · วัน XD · ใบอนุญาตของผู้ให้บริการ) | ค้นเอง โดยเรียงแหล่งดังนี้: กรมสรรพากร ตลาดหลักทรัพย์ สำนักงาน ก.ล.ต. ธนาคารแห่งประเทศไทย → เอกสารของบริษัทจดทะเบียนและกองทุน → สำนักข่าวการเงิน ใช้ได้ตามกฎ 3 แหล่งข้างบน |

## รูปแบบทีม — ใช้อย่างไรในงานนี้ (หัวข้อ 10)

วิธีทำ ต้นทุน และกับดักของแต่ละแบบอยู่ใน [`agent-patterns`](../../agent-patterns/SKILL.md)

| รูปแบบ | ในงานนี้ใช้อย่างไร |
|---|---|
| **Planning** | thesis → จุดตัดขาดทุน → ขนาดไม้ → ใบสั่ง |
| **ReAct** | ดึงราคา → อ่านค่า → เทียบเวลา → คำนวณ |
| **Reflection** | `risk-manager` ตัวใหม่ตรวจทุกใบสั่งก่อนให้ผู้ใช้ |
| **Multi-Agent** | `market-analyst` → `risk-manager` → `trade-journal-coach` |
| **Mixture-of-Agents (MoA)** | แผนเกษียณหรือภาษี → 3 สมมติฐาน (ระวัง · กลาง · ดี) แล้วแสดงคู่กัน |
| **Reranker** | ข่าวหลายสิบชิ้น → ให้คะแนนผลกระทบต่อหุ้นที่ถือ → เหลือ 5 |
