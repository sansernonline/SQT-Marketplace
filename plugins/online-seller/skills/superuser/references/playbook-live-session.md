# playbook · live-session — เตรียมไลฟ์ขายของ

ใช้เมื่อ: จะไลฟ์บน TikTok Shop · Shopee Live · Lazada Live · Facebook Live
skill หลัก: `live-selling-script` · `product-listing` · agent `live-seller`

## ขั้นตอน (คัดลง todo ตรงตัว)

1. เลือกสินค้าและดีลของไลฟ์ ตรวจสต็อกและราคาว่ายังมีกำไร
2. ทำ run sheet รายนาทีตาม `live-selling-script` — hook เปิด · ลำดับสินค้า · จังหวะ flash deal · ประโยคปิดการขาย
3. ตรวจคำพูดทุกบรรทัดกับรายการคำโฆษณาต้องห้าม
4. ทำเช็กลิสต์หลังบ้าน — คนตอบแชต สต็อกที่ล็อกไว้ ลิงก์สินค้า

## จบเมื่อ

run sheet และเช็กลิสต์พร้อมใช้ ผ่านการตรวจคำต้องห้ามทุกบรรทัด
