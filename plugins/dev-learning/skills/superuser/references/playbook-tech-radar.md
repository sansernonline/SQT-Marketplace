# playbook · tech-radar — เรดาร์เทคโนโลยีประจำสัปดาห์

ใช้เมื่อ: ตามข่าวของไลบรารีและเครื่องมือที่ใช้ · "สัปดาห์นี้มีอะไรเปลี่ยน"
skill หลัก: `tech-radar`

## ขั้นตอน (คัดลง todo ตรงตัว)

1. อ่านรายการที่ติดตามจากไฟล์เรดาร์ของผู้ใช้ ถ้ายังไม่มีไฟล์ ให้สร้างจาก dependency ของโปรเจกต์ผู้ใช้
2. ดู release notes และ changelog ทางการของแต่ละตัว นับจากรอบที่แล้วถึงวันนี้
3. คัดเหลือเฉพาะที่กระทบงานของผู้ใช้ — breaking change · ช่องโหว่ · ฟีเจอร์ที่ช่วยงานตรง ๆ
4. เขียนรายงานเรดาร์ตามแม่แบบ — เปลี่ยนอะไร · สำคัญอย่างไร · ทำอะไรต่อ · อะไรข้ามได้
5. ตรวจว่าทุกข้อมีลิงก์ทางการและเลขเวอร์ชัน

## จบเมื่อ

รายงานเรดาร์ที่ทุกข้อมีลิงก์ทางการ และไฟล์เรดาร์อัปเดตวันที่รอบนี้
