# ตัวอย่างของ plugin นี้ — ระดับโมเดล · ความเป็นอิสระ · รูปแบบทีม

ย้ายมาจาก `SKILL.md` หัวข้อ 5 · 6 · 10 · กฎอยู่ใน `SKILL.md` ไฟล์นี้มีแต่ตัวอย่าง

## ระดับโมเดล — ตัวอย่างงาน (หัวข้อ 5)

กฎ ชื่อโมเดล และการสลับกลางทาง อยู่ในบล็อก `team` ของ `SKILL.md` · ไฟล์นี้มีแต่ตัวอย่างงานของแต่ละระดับ

มี 3 ระดับ หัวหน้าทีมเลือกเองตามงาน · **ใหญ่** — วิเคราะห์ว่ากรณีเข้าสิทธิ์ข้อไหน · เรียงขั้นบันไดของเรื่องที่ซับซ้อน · ตรวจร่างจดหมายก่อนส่ง · **กลาง** (ค่าเริ่มต้น) — ร่างเอกสาร · คำนวณตามสูตร · จัดตาราง · **เล็ก** — งานกลไกที่คำตอบชัด: ค้นไฟล์ · เปลี่ยนชื่อ · สรุปรายการ

## ความเป็นอิสระ — งานที่ย้อนได้และแหล่งข้อมูล (หัวข้อ 6)

| เจอ | ทำ |
|---|---|
| งานที่ย้อนกลับได้ — ร่างจดหมาย · ทำตารางเปรียบเทียบ · จัดทะเบียน · เรียงไทม์ไลน์ | ทำเลย |
| ไม่รู้ข้อเท็จจริงสาธารณะ (กรอบเวลาของสิทธิ์ · ช่องทางร้องเรียน · เงื่อนไขของแพลตฟอร์มและธนาคาร) | ค้นเอง ตามลำดับแหล่ง: เว็บหน่วยงานรัฐและกฎหมายที่เกี่ยว → หน้าช่วยเหลือของแพลตฟอร์มหรือธนาคาร → สำนักข่าว ข้อมูล ใช้ได้ตามกฎ 3 แหล่งใน `SKILL.md` หัวข้อ 6 |

## รูปแบบทีม — ใช้อย่างไรในงานนี้ (หัวข้อ 10)

วิธีทำ ต้นทุน และกับดักของแต่ละแบบอยู่ใน `agent-patterns`

| รูปแบบ | ในงานนี้ใช้อย่างไร |
|---|---|
| **Planning** | ไทม์ไลน์ → ขั้นบันไดร้องเรียน → ทีละขั้น |
| **ReAct** | ร่างจดหมาย → เทียบหลักฐาน → แก้ |
| **Reflection** | `reviewer` ตัวใหม่ (อ่านอย่างเดียว ไม่ใช่ `consumer-advocate` ที่ทำงานชิ้นนั้น) อ่านจดหมายแบบเจ้าหน้าที่รับเรื่อง |
| **Multi-Agent** | ชิ้นหลักฐาน · ชิ้นจดหมาย · ชิ้นช่องทางร้องเรียน แยกกันทำ |
| **Mixture-of-Agents (MoA)** | ซื้อของราคาสูง → 3 มุม: ราคาตลอดอายุ · การรับประกัน · รีวิวจริง แล้วรวม |
| **Reranker** | รีวิวสินค้า 20–30 รีวิว → ให้คะแนนความน่าเชื่อถือ → อ่านเต็ม 3–5 รีวิวบนสุด |
