# แบ่งบิลร้านอาหารตามคน ยอดรวมไม่ตรงกับใบเสร็จ

ร้านเรามีฟังก์ชัน `split_bill` ใน `billing.py` ไว้แบ่งบิลให้แต่ละคนในโต๊ะจ่าย ตอนนี้ยอดรวมของทุกคนไม่ตรงกับยอดบิลจริง เพราะเศษสตางค์หายหรือเกิน และปัดเศษไม่เหมือนกับระบบบัญชีของร้าน

`split_bill(items, discount=0, service_pct=0, vat_pct=0)` คืน dict ชื่อคน → ยอดที่ต้องจ่าย เงินทุกจำนวนเป็นสตางค์ (จำนวนเต็ม) `service_pct` กับ `vat_pct` เป็นเปอร์เซ็นต์จำนวนเต็ม เช่น 10 และ 7 แต่ละรายการมีรูปแบบ `{"name": ..., "price": สตางค์, "people": [ชื่อ, ...]}` และ `people` คือคนที่หารรายการนั้น

กติกาที่อยากได้

1. รายการที่หารหลายคน แบ่งเท่า ๆ กัน ถ้าหารไม่ลงตัว เศษสตางค์ให้คนที่อยู่ต้นลิสต์ `people` คนละ 1 สตางค์ จนหมดเศษ
2. ส่วนลดเป็นยอดรวมทั้งบิล ลดตามสัดส่วนยอดของแต่ละคน ถ้าส่วนลดมากกว่ายอดบิล ให้ลดแค่เท่ายอดบิล
3. ค่าบริการคิดจากยอดบิลหลังหักส่วนลด ส่วน VAT คิดจากยอดหลังหักส่วนลดรวมค่าบริการ ทั้ง 2 อย่างคิดทั้งบิลก่อน แล้วปัดเศษเป็นสตางค์แบบ 0.5 ปัดขึ้น (ไม่ใช่ปัดเข้าหาเลขคู่) แล้วจึงแบ่งให้แต่ละคน โดยค่าบริการแบ่งตามยอดหลังหักส่วนลดของแต่ละคน ส่วน VAT แบ่งตามยอดหลังหักส่วนลดรวมค่าบริการของแต่ละคน
4. ทุกครั้งที่แบ่งยอดตามสัดส่วน (ส่วนลด ค่าบริการ VAT) ผลรวมของทุกคนต้องเท่ากับยอดทั้งบิลเป๊ะ เศษสตางค์ที่เหลือให้คนที่มีเศษทศนิยมมากสุดก่อน ถ้าเท่ากันให้คนที่ปรากฏก่อนในบิล
5. dict ที่คืนเรียงตามลำดับที่แต่ละคนปรากฏครั้งแรกในบิล และคนที่ยอดเป็น 0 (เช่นกินของฟรี) ก็ยังอยู่ใน dict บิลที่ยอดรวมเป็น 0 ต้องไม่ล้ม
