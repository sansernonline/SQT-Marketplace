# ฟอร์มสมัครสมาชิก: ขอเพิ่มช่องเบอร์มือถือ

ฟอร์มสมัครสมาชิก (`src/signup-form.ts` ใช้ Angular Reactive Forms ของ `@angular/forms`) ตอนนี้มีแค่ชื่อ อีเมล รหัสผ่าน ฝ่ายขายขอให้เก็บเบอร์มือถือลูกค้าด้วย

ที่ต้องการ:

1. เพิ่มช่อง `phone` ในฟอร์ม (`form.get("phone")`) ต้องกรอก ถ้าว่างให้เป็น error `required`
2. รับเฉพาะเบอร์มือถือไทย 10 หลัก ขึ้นต้น 06, 08 หรือ 09 เช่น `0812345678`
3. ลูกค้าพิมพ์มีขีดหรือช่องว่างได้ เช่น `081-234-5678`, `081 234 5678` และพิมพ์แบบ `+66` ได้ เช่น `+66 81 234 5678`
4. เบอร์ที่ไม่ใช่มือถือไทย (เช่น เบอร์บ้าน `02...`, ขาดหรือเกินหลัก, มีตัวอักษร) ให้ช่อง `phone` มี error ชื่อ `thaiMobile` และฟอร์มไม่ผ่าน
5. `toPayload()` ต้องคืน `phone` เป็นรูปแบบเดียวคือ `0XXXXXXXXX` (ตัวเลข 10 หลัก ไม่มีขีด ไม่มี +66) ช่องอื่นคงเดิม
6. ใน `src` ห้ามใช้ `any` (ทั้ง `: any`, `as any`, `<any>`) และ `npx tsc --noEmit` ต้องไม่มี error (เปิด `strict` อยู่แล้ว)

ชื่อที่ใช้อยู่ต้องคงไว้: class `SignupForm`, property `form`, getter `valid`, method `toPayload()`

รัน test: `npm test` · ตรวจ type: `npx tsc --noEmit`
