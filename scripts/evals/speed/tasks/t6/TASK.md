# สรุปประชุมส่งผู้บริหาร

ผู้จัดการขอสรุปประชุมโครงการเปิดสาขาใหม่ เพื่ออ่านก่อนประชุมบอร์ดพรุ่งนี้ เขียนลง `report.md` ที่รากโฟลเดอร์นี้

ข้อมูลอยู่ใน `notes/meeting-2026-10-20.md` (บันทึกดิบ) และ `data/sales.csv` (ยอดขายสาขาทดลอง)

ต้องการ:
- ภาษาไทย ย่อหน้าแรกเป็นข้อสรุป อ่านย่อหน้าเดียวต้องรู้ว่าตัดสินอะไรไปแล้ว งบเท่าไร และเปิดเมื่อไร
- หัวข้อ `## ตัดสินใจแล้ว` เฉพาะเรื่องที่ตกลงกันแล้วจริง เรื่องที่ยังไม่ตัดสินใส่ไว้ในหัวข้อ `## ยังไม่ตัดสิน`
- หัวข้อ `## งานที่ต้องทำ` เป็นตาราง มีคอลัมน์ งาน · ผู้รับผิดชอบ · กำหนด
- ยอดขายรวมของสาขาทดลองจาก `data/sales.csv` (บาท)
- ตัวเลขใช้ค่าล่าสุดที่ที่ประชุมตกลง ไม่ต้องใส่ค่าเดิมที่ถูกแก้แล้ว
- ไม่เกิน 60 บรรทัด ไม่ใส่อีโมจิ
