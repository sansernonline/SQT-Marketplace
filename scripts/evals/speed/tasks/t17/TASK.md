# ร่างนโยบายลาพักร้อน

ฝ่ายบุคคลขอร่างนโยบายลาพักร้อนของบริษัท จะแจกพนักงานสัปดาห์หน้า เขียนลง `policy.md` ที่รากโฟลเดอร์นี้

ข้อมูลอยู่ในบันทึกประชุม 2 ครั้งใน `notes/` (`meeting-2026-09-02.md` และ `meeting-2026-10-14.md`) บางข้อสองครั้งพูดไม่ตรงกัน ให้ถือครั้งหลังเป็นหลัก

ต้องการ:
- ภาษาไทย ขึ้นต้นด้วย `# นโยบายลาพักร้อน`
- มีหัวข้อ `## สิทธิ์วันลา` · `## การขอลา` · `## วันลาสะสม` · `## ยังไม่ตัดสิน`
- ตัวเลขวันลาและเงื่อนไขใช้ค่าล่าสุดที่ที่ประชุมตกลง ไม่ต้องใส่ค่าเดิมที่ถูกแก้แล้ว
- เรื่องที่ที่ประชุมยังไม่ตัดสิน ให้ใส่ไว้ในหัวข้อ `## ยังไม่ตัดสิน` และเขียนชัดว่ายังไม่ตัดสิน ห้ามเขียนเป็นนโยบายในหัวข้ออื่น
- ไม่เกิน 50 บรรทัด ไม่ใส่อีโมจิ
