# ทีมความปลอดภัยแจ้งช่องโหว่ใน `src/handlers.mjs`

ผลสแกนบอกว่า 3 ฟังก์ชันใน `src/handlers.mjs` มีช่องโหว่ ช่วยแก้ให้ปลอดภัยโดยการใช้งานปกติยังได้ผลเหมือนเดิม
- `readUserFile(root, name)` อ่านไฟล์ของผู้ใช้ในโฟลเดอร์ `root`
- `buildUserQuery(name)` สร้างคำสั่ง SQL ส่งให้ไลบรารีฐานข้อมูล (ไลบรารีรับ `{ sql, params }` และแทน `?` ด้วย params ให้เอง)
- `greeting(name)` คืน HTML ทักทายที่จะแสดงบนหน้าเว็บ
