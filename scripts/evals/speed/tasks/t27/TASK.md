# กระทบยอดธนาคารเดือนตุลาคม (ส่งฝ่ายบัญชี)

`data/bank.csv` (statement ธนาคาร) กับ `data/ledger.csv` (สมุดบัญชีของเรา) จับคู่ด้วยเลขอ้างอิง `ref`
เขียน `recon.json` ตามรูปแบบนี้ (เงินเป็นจำนวนสตางค์เต็ม · รายการเรียงตาม ref):

```json
{ "missing_in_ledger": ["ref ที่มีในธนาคารแต่ไม่มีในบัญชี"],
  "missing_in_bank": ["ref ที่มีในบัญชีแต่ไม่มีในธนาคาร"],
  "amount_mismatch": [{ "ref": "...", "bank": 0, "ledger": 0 }],
  "bank_total": 0, "ledger_total": 0 }
```

ทั้ง 2 ไฟล์มาจากคนละระบบ รูปแบบตัวเลขไม่เหมือนกัน ตรวจให้ละเอียด ตัวเลขผิดฝ่ายบัญชีปิดงบไม่ได้
