# กราฟแท่งยอดขายใส่สไลด์ผู้บริหาร

จาก `data/sales.csv` ทำกราฟแท่งเป็นไฟล์ `chart.svg` (SVG ล้วน ไม่ใช้ JavaScript ไม่ดึงไฟล์ภายนอก) ใส่สไลด์ได้เลย
- แท่งละ 1 `<rect>` ต่อเดือน เรียงตามเดือนในไฟล์ · ใส่ attribute `data-month` เป็นเดือนตามไฟล์ (เช่น `2026-06`) บนแท่งทุกแท่ง
- ความสูงแท่งเป็นสัดส่วนกับยอดขาย · มีชื่อเดือนภาษาไทยแบบย่อ (มิ.ย. ...) และตัวเลขยอดกำกับทุกแท่ง
- มี `viewBox` และมีชื่อกราฟใน `<title>` ให้โปรแกรมอ่านหน้าจออ่านได้
