# บทที่ 3 เครื่องและบัญชีไอที

## รับเครื่อง
- รับโน้ตบุ๊กที่ห้องไอที ชั้น 3 วันแรกของการทำงานเวลา 14:00
- ฝ่ายไอทีเปิดบัญชีอีเมลและระบบภายในให้ล่วงหน้า 2 วันทำงานก่อนวันเริ่มงาน

## บัญชีและรหัสผ่าน
- รหัสผ่านยาวอย่างน้อย 12 ตัวอักษร และเปลี่ยนทุก 90 วัน
- ต้องเปิดการยืนยันตัวตน 2 ชั้นทุกบัญชีภายในวันแรก

## VPN
ใช้โปรแกรม WireGuard เมื่อทำงานนอกออฟฟิศ

## แจ้งปัญหา
โทรฝ่ายไอที ต่อ 4100
