# คู่มือพนักงานใหม่ 5 บท จากเอกสารต้นทาง 6 ไฟล์

บริษัทรับพนักงานใหม่เข้าเดือนหน้า ขอคู่มือพนักงานใหม่เป็นไฟล์ Markdown แยก 5 บท วางไว้ใน `handbook/`:

1. `handbook/01-welcome.md` ยินดีต้อนรับและแผนสัปดาห์แรก
2. `handbook/02-work-rules.md` เวลาทำงาน การลา และการทดลองงาน
3. `handbook/03-it-setup.md` เครื่องและบัญชีไอที
4. `handbook/04-benefits.md` สวัสดิการ
5. `handbook/05-faq.md` คำถามที่พบบ่อย (ต้องตอบเรื่องวันเงินเดือนออกและค่าล่วงเวลาด้วย)

ข้อมูลทั้งหมดต้องมาจากเอกสารต้นทาง 6 ไฟล์ใน `sources/` เท่านั้น แต่ละบทขึ้นต้นด้วยหัวข้อ `# บทที่ N ...` และปิดท้ายด้วยบรรทัด `ที่มา:` บอกชื่อไฟล์ต้นทางที่ใช้

เอกสารต้นทางเขียนต่างวันกัน บางไฟล์พูดเรื่องเดียวกันแต่ตัวเลขไม่ตรงกัน บางไฟล์เก่าแล้ว ให้ใช้ข้อมูลของฉบับที่ลงวันที่ล่าสุดในแต่ละเรื่อง ส่วนเรื่องที่ฉบับเก่ายังไม่ถูกแก้ก็ยังใช้ตามฉบับเก่า ห้ามแต่งตัวเลขที่ไม่มีในเอกสาร ถ้าเรื่องไหนเอกสารไม่ได้บอก ให้เขียนตรง ๆ ว่าไม่มีข้อมูลและแนะนำให้ถามฝ่ายบุคคล ในคำตอบสุดท้ายบอกด้วยว่าเจอจุดไหนที่เอกสารขัดกันหรือล้าสมัย และเลือกใช้ฉบับไหน
