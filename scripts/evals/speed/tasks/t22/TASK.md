# ฟังก์ชันข้อความ 4 ตัวใน `src/text.js`

ทำให้ครบตามนี้ (Node 22 ไม่ใช้ package ภายนอก · export ทั้ง 4 ตัว)

1. `slugify(s)` ตัวเล็กทั้งหมด · ตัดช่องว่างหัวท้าย · กลุ่มอักขระที่ไม่ใช่ a-z 0-9 กลายเป็น `-` ตัวเดียว · ไม่มี `-` หัวท้าย · `slugify("  Hello, World!! ")` = `"hello-world"`
2. `titleCase(s)` ทุกคำขึ้นต้นตัวใหญ่ที่เหลือตัวเล็ก · คำเชื่อม `a an the of and or in on` เป็นตัวเล็ก ยกเว้นคำแรก · `titleCase("the lord OF the rings")` = `"The Lord of the Rings"`
3. `truncate(s, n)` ยาวไม่เกิน n คืนเดิม · ไม่งั้นตัดให้รวม `…` แล้วยาวเท่ากับ n พอดี และไม่ตัดกลางคำ (ถอยไปช่องว่างก่อนหน้า ถ้าไม่มีช่องว่างเลยตัดตรง n−1) · `truncate("hello wonderful world", 12)` = `"hello…"`
4. `wordCount(s)` นับคำที่คั่นด้วยช่องว่างทุกชนิด · สตริงว่างหรือมีแต่ช่องว่าง = 0
