# แก้บั๊ก: วันที่ในหัวรายงานผิด

ลูกค้าแจ้ง: หัวรายงาน (`src/report.js`) แสดงวันที่ผิด
- รายงานวันที่ 19 ต.ค. 2569 เวลา 10:00 น. (เวลาไทย) แสดงเป็น "19 พ.ย. 2569"
- รายงานที่ออกตอน 01:30 น. เวลาไทย ของวันที่ 1 ม.ค. 2570 แสดงเป็นวันที่ของปีก่อน
- รายงานเดือนธันวาคมแสดงเดือนเป็น "undefined"

ต้องการ: `formatThaiDate(date)` คืน "วัน เดือนย่อ ปีพ.ศ." ตามเวลาไทย (UTC+7) ทุกกรณี ไม่ขึ้นกับ timezone ของเครื่องที่รัน
รัน test ด้วย `npm test`
