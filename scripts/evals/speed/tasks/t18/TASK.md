# สรุปยอดขายรายสาขา รวมข้อมูลระบบเก่ากับระบบใหม่

บริษัทย้ายระบบขายกลางเดือน ข้อมูลเลยแยกอยู่ 2 ไฟล์คนละรูปแบบ ผู้จัดการขอไฟล์สรุปยอดขายรายสาขา

เขียน `summarize.py` (Python 3 ใช้เฉพาะ standard library) รันด้วย `python summarize.py` จากรากโฟลเดอร์นี้ โดยอ่านไฟล์ใน `data/` แล้วเขียน `summary.csv` ไว้ที่โฟลเดอร์ที่รันอยู่ จากนั้นรันสคริปต์กับข้อมูลที่ให้เพื่อสร้าง `summary.csv` จริง

ข้อมูล:
- `data/old.json` ระบบเก่า รูปแบบ `{"records": [{"branch": "...", "date": "2026-09-30", "amount": 1500.5}]}` หน่วย `amount` เป็นบาท
- `data/new.json` ระบบใหม่ รูปแบบ `[{"store": "...", "sold_at": "2026-10-01T14:30:00+07:00", "amount_satang": 150050, "status": "ok"}]` หน่วย `amount_satang` เป็นสตางค์
- `data/branches.csv` ตารางชื่อสาขา คอลัมน์ `alias,branch` บอกว่าชื่อที่สะกดแบบไหนคือสาขาใด

กติกา:
- รวมยอดตามชื่อสาขาใน `branch` ของตาราง หาชื่อโดยตัดช่องว่างหัวท้ายและไม่สนตัวพิมพ์เล็กใหญ่ ถ้าไม่อยู่ในตารางให้ใช้ชื่อที่ตัดช่องว่างหัวท้ายแล้วเป็นชื่อสาขา
- ระบบใหม่นับเฉพาะรายการที่ `status` เป็น `ok` รายการอื่นไม่นับ
- ระบบเก่าปิดใช้งานสิ้นวันที่ 2026-09-30 รายการระบบเก่าที่ลงวันที่ตั้งแต่ 2026-10-01 เป็นต้นไปเป็นข้อมูลซ้ำกับระบบใหม่ ไม่ต้องนับ
- `summary.csv` ใช้ UTF-8 บรรทัดแรกเป็น `branch,orders,total_baht` ตามด้วยบรรทัดละ 1 สาขา `orders` คือจำนวนรายการที่นับ `total_baht` เป็นบาท ทศนิยม 2 ตำแหน่งเสมอ
- เรียงตาม `total_baht` จากมากไปน้อย ถ้าเท่ากันเรียงตามชื่อสาขาจากน้อยไปมาก
- ยอดเงินต้องตรงถึงสตางค์
