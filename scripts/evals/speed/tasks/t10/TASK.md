# รายงานยอดขายไตรมาส 3 ทั้ง 4 สาขา ส่งผู้บริหาร

ข้อมูลยอดขาย ก.ค.–ก.ย. 2569 อยู่ใน `data/` สาขาละไฟล์ (`bangna.csv` · `rangsit.csv` · `chonburi.csv` · `rayong.csv`) คอลัมน์ `date,product,qty,unit_price`
ไฟล์มาจากคนละระบบ รูปแบบวันที่ไม่เหมือนกันทุกไฟล์ และมีข้อมูลเสียปนอยู่

กฎคิดยอด:
- ยอดขาย = qty × unit_price · qty ติดลบคือคืนสินค้า ให้หักออก (นับปกติ)
- แถวที่ซ้ำกันทุกช่องในไฟล์เดียวกัน นับครั้งเดียว (แถวแรก) แถวที่ซ้ำคือปัญหาข้อมูลชนิด `duplicate`
- แถวที่ไม่มี unit_price ไม่นับ และเป็นปัญหาข้อมูลชนิด `missing_price`
- เลขบรรทัดนับจากบรรทัดหัวตารางเป็นบรรทัด 1

ส่งมอบ 2 ไฟล์ที่รากโฟลเดอร์นี้:

1. `summary.json` รูปแบบนี้ (ชื่อสาขาใช้ชื่อไฟล์ไม่มีนามสกุล · ตัวเลขเงินเป็นจำนวนเต็มบาท · growth ปัด 1 ตำแหน่ง)

```json
{
  "branches": {
    "bangna": { "total": 0, "jul": 0, "aug": 0, "sep": 0, "growth_sep_vs_jul_pct": 0.0, "top_product": "" }
  },
  "grand_total": 0,
  "top_branch": "",
  "issues": [ { "file": "bangna.csv", "line": 0, "type": "duplicate" } ]
}
```

2. `report.md` ภาษาไทย มีหัวข้อ `## สรุป` (ย่อหน้าแรกบอกยอดรวมทั้ง 4 สาขาและสาขาที่ขายได้มากสุด) · `## รายสาขา` (ตาราง) · `## ปัญหาข้อมูล` (ทุกแถวที่มีปัญหา บอกไฟล์และบรรทัด)
