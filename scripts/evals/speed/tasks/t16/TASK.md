# ทำ 3 ไฟล์ช่วยงานคลังสินค้า (แต่ละไฟล์ไม่ขึ้นต่อกัน)

ทำทั้ง 3 ไฟล์ใน `src/` พร้อม test ของตัวเองใน `test/` (ESM · Node 22 · ห้ามใช้ dependency ภายนอก) รัน test ด้วย `npm test`

**1. `src/tokenize.js`** → `export function tokenize(text, words)` ตัดคำค้นภาษาไทยอย่างง่ายตามรายการคำ `words` ที่ให้มา
- เดินจากซ้ายไปขวา ที่แต่ละตำแหน่งเลือกคำใน `words` ที่ตรงและ **ยาวที่สุด** (ไม่ใช่คำแรกในรายการ)
- ตัวอักษรที่ไม่ตรงคำไหนเลย ให้รวมติดกันเป็น 1 token จนกว่าจะเจอคำถัดไป
- ช่องว่าง (space · tab · ขึ้นบรรทัดใหม่) เป็นตัวแบ่ง token และไม่ติดไปใน token
- คืน array ของ string · ข้อความว่างหรือมีแต่ช่องว่างคืน `[]`
- ตัวอย่าง: `words = ["ตา","ตาก","ลม"]` · `"ตากลม"` → `["ตาก","ลม"]`

**2. `src/tracking.js`** → `export function formatTracking(s)` จัดรูปเลขพัสดุ
- ก่อนตัดสิน ให้ตัดช่องว่างกับขีดทิ้ง และแปลงเป็นตัวพิมพ์ใหญ่
- Kerry: `KEX` ตามด้วยเลข 10 หลัก → `KEX-1234567890`
- Flash: `TH` ตามด้วยเลข 10 หลัก แล้วตามด้วยตัวอักษร 1 ตัว → `TH-1234567890-A`
- ไปรษณีย์ไทย: ตัวอักษร 2 ตัว ตามด้วยเลข 9 หลัก แล้วตามด้วย `TH` → `EB-123456789-TH`
- ไม่ตรงรูปแบบไหนเลย คืน `null` · ถ้า `s` ไม่ใช่ string ก็คืน `null`

**3. `src/postcode.js`** → `export function provinceOfPostcode(code)` ตรวจรหัสไปรษณีย์ไทย 5 หลักแล้วคืนชื่อจังหวัด ตามช่วง (รวมหัวท้าย):

| ช่วง | จังหวัด |
|---|---|
| 10000–10990 | กรุงเทพมหานคร |
| 11000–11160 | นนทบุรี |
| 12000–12190 | ปทุมธานี |
| 50000–50360 | เชียงใหม่ |
| 83000–83150 | ภูเก็ต |
| 90000–90190 | สงขลา |

- `code` ต้องเป็น string ที่เป็นเลข 5 หลักพอดี ไม่เช่นนั้นโยน `Error`
- เป็นเลข 5 หลักแต่ไม่อยู่ในช่วงใดเลย คืน `null`
