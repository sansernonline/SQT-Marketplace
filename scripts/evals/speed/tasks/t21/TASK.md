# สรุป ticket ลูกค้าสัปดาห์นี้

ticket ทั้งหมดอยู่ใน `tickets/` (ไฟล์ละ 1 ใบ มี หมวด · ความด่วน · เนื้อหา) เขียนสรุปลง `report.md` ส่งหัวหน้าทีม

- หัวข้อ `## จำนวนตามหมวด` เป็นตาราง หมวด | จำนวน ของทุกหมวดที่มี
- หัวข้อ `## ด่วน` รายการ id ของ ticket ที่ความด่วนเป็น `สูง` พร้อมเรื่องสั้น ๆ
- ภาษาไทย ไม่เกิน 40 บรรทัด
