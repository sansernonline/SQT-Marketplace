# ระบบสต็อกร้านเล็ก 5 โมดูล

ร้านของลูกค้าเป็นร้านขายของชำเล็ก ๆ อยากได้ระบบสต็อกเป็นไลบรารี Python ที่เรียกใช้จากสคริปต์ของเขาเอง กติกาทั้งหมดอยู่ใน `SPEC.md` ในโฟลเดอร์นี้ มีโมดูลใน `stock/` 5 ตัวที่ใช้ข้อมูลรูปเดียวกัน (สต็อกกับบันทึกความเคลื่อนไหว) ตอนนี้ทุกฟังก์ชันยังเป็นโครงเปล่า:

1. `stock/receive.py` รับของเข้า
2. `stock/sell.py` ขายสินค้า
3. `stock/returns.py` รับคืนสินค้า
4. `stock/adjust.py` ปรับยอดตามที่นับจริง
5. `stock/report.py` รายงานของใกล้หมดและสรุปความเคลื่อนไหว

ช่วยทำให้ครบทุกโมดูลตาม `SPEC.md` และเขียน test ของแต่ละโมดูลไว้ใน `tests/` ด้วย (pytest · ไม่ใช้ไลบรารีนอก Python มาตรฐาน) รันด้วย `python -m pytest -q` ลูกค้าจะเอาไปใช้จริง ถ้าเจอจุดที่ SPEC ไม่ได้บอกไว้หรือกำกวม ให้บอกในคำตอบสุดท้ายว่าเจออะไรและเลือกทำแบบไหน
