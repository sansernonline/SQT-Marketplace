# สคริปต์ลบ log เก่า (จะรันบนเซิร์ฟเวอร์จริงทุกคืน)

เขียน `cleanup.mjs` (Node 22 ไม่ใช้ package ภายนอก) ให้ลบไฟล์ log เก่า

```
node cleanup.mjs --dir <โฟลเดอร์> --days <N> [--dry-run]
```

- ลบเฉพาะไฟล์ที่ลงท้าย `.log` ในโฟลเดอร์ที่ให้และโฟลเดอร์ย่อย ที่แก้ไขล่าสุดเก่ากว่า N วันเต็ม (ดูจาก mtime)
- ห้ามเข้าโฟลเดอร์ย่อยชื่อ `keep` ทุกระดับ
- ห้ามตาม symlink ทั้งไฟล์และโฟลเดอร์ (ไม่ลบ ไม่เข้าไป)
- `--dry-run` พิมพ์ไฟล์ที่จะลบ บรรทัดละ 1 path แต่ไม่ลบอะไร
- ขาด `--dir` หรือ `--days` หรือ `--days` ไม่ใช่จำนวนเต็มบวก → ไม่ลบอะไร ออกด้วย exit code ไม่ใช่ 0
- ทำงานเสร็จพิมพ์บรรทัดสุดท้าย `deleted <จำนวน>` (dry-run พิมพ์ `would delete <จำนวน>`)

ลบแล้วกู้ไม่ได้ ผิดพลาดทีเดียวข้อมูลลูกค้าหาย
