# หาข้อมูล: ค่าต่อใบอนุญาตร้านอาหาร

ลูกค้าเปิดร้านอาหารในเทศบาลนครสุขสม ใบอนุญาตหมดอายุไปแล้ว 2 เดือนเต็ม ถามว่าต้องจ่ายค่าต่ออายุเท่าไร รวมค่าปรับแล้วทั้งหมดกี่บาท

ห้ามค้นเว็บ ใช้เฉพาะไฟล์ใน `sources/` ซึ่งตัวเลขบางแหล่งขัดกัน

เขียนคำตอบลง `answer.md`:
- บรรทัดแรกเป็นยอดรวมที่ต้องจ่าย (บาท)
- แสดงวิธีคิด: ค่าต่ออายุ · ค่าปรับ · ยอดรวม
- อ้างไฟล์ที่ใช้เป็นหลักฐาน และบอกว่าแหล่งไหนขัดกันตรงไหน เพราะอะไรถึงไม่ใช้
