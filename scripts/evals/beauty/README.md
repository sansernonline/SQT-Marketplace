# beauty — ชุดวัดความสวยด้วยตาเจ้าของ

ใช้ดูว่าแก้ skill งานภาพแล้วงานสวยขึ้นจริงไหม โดยใช้โจทย์ 5 ข้อเดิมทุกรอบ (`briefs.json`) แล้วให้เจ้าของให้คะแนนรูปจริง ชุดนี้ไม่มีตัวรันอัตโนมัติ เพราะคนที่ตัดสินคือเจ้าของ ไม่ใช่ model

## เมื่อไรควรรัน

แก้ `design-by-type` · `no-ai-look` · `design-references` · `design-critic` · `brand-kit` หรือ skill งานภาพตัวอื่นที่เปลี่ยนหน้าตาผลงาน

## ขั้นตอน

1. แตก worktree ของรุ่นที่จะวัด แล้วสั่งงานทีละโจทย์ใน session ใหม่ ข้อความสั่งคือ `brief` ของข้อนั้นใน `briefs.json` ตามตรง และให้ทำ 3 แนวเหมือนงานจริง
2. เก็บผลไว้ที่ `_to_delete/<วันที่>-beauty-<รุ่น>/<id>/` เรนเดอร์ HTML เป็น PNG ขนาดตาม `size` ด้วย
   `python scripts/evals/beauty/render.py <ไฟล์.html> <กว้าง> <สูง>` (ต้องมี Python playwright และ Chrome)
3. ส่ง PNG ให้ `design-critic` ตัวใหม่ตรวจด่านตา `no-ai-look` ข้อ 3.2 คำถามความแข็ง 6 ข้อ และคะแนนว้าว จดคะแนน n/9 จำนวนข้อที่แข็ง และคะแนนว้าว n/10
4. ให้เจ้าของดูรูปทั้ง 15 รูปโดยไม่บอกว่ารูปไหนมาจากรุ่นไหน แล้วให้คะแนนตามตารางข้างล่าง
5. ต่อท้ายผลใน `RESULTS.md` บรรทัดใหม่อยู่ล่างสุด พร้อมวันที่และรุ่นของ plugin

## ตารางคะแนน (ผู้ตรวจและเจ้าของใช้ชุดเดียวกัน)

คะแนนว้าว 5 ข้อ ข้อละ 0–2 รวม 10 ตาม `plugins/graphic-design/skills/design-by-type/references/wow-score.md`

| ข้อ | ถาม |
|---|---|
| หยุดสายตา | ย่อเหลือ 300 px ดู 1 วินาที มีชิ้นที่จำได้ไหม |
| ไอเดียของงานนี้ | เปลี่ยนชื่อเป็นคู่แข่งแล้วยังใช้ได้ไหม (ใช้ได้ = 0) |
| ลูกเล่นที่มีความหมาย | มีจุดเล่น 1–2 จุดที่เล่าเรื่องงาน ไม่ใช่แค่ประดับ |
| มิติและแสง | มีชั้นลึก แสงทางเดียว จับต้องได้ |
| ความประณีต | ซูม 200% แล้วขอบ ตัวอักษร สระไทย ภาพ คมทุกจุด |

ส่งได้เมื่อได้ 7 ขึ้นไปและไม่มีข้อไหนได้ 0

นอกจากคะแนน ให้เจ้าของเลือกแนวที่ชอบที่สุดของแต่ละโจทย์ด้วย และจดคำวิจารณ์ตามที่พูดลงใน `~/.claude/superuser-style.md` ตาม `design-references`

## ข้อควรรู้

- โจทย์ทุกข้อเป็นเรื่องสมมติ ด่านตาข้อ 1 (ปิดโลโก้แล้วยังรู้ไหมว่าของใคร) จึงตกเกือบทุกรอบ ให้ดูเทียบระหว่างรุ่นแทน
- ห้ามแก้ข้อความใน `briefs.json` ถ้าต้องเปลี่ยน ให้เพิ่มข้อใหม่และเริ่มนับผลใหม่
- ผลแกว่งตามรอบ ตัดสินว่าดีขึ้นเมื่อคะแนนเจ้าของเฉลี่ยสูงขึ้นอย่างน้อย 0.5 ใน 2 รอบขึ้นไป (เกณฑ์ตั้งเอง 2026-11-19 ยังไม่ได้ทดสอบว่าเหมาะ)
