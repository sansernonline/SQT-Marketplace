# คู่มือผู้ใช้ ร้านค้าออนไลน์ตลาดดีมาร์ท เรื่องส่วนลด (เวอร์ชัน 2.3)

## ใช้โค้ดส่วนลดตอนชำระเงิน

1. เลือกสินค้าลงตะกร้า แล้วกด **ชำระเงิน**
2. ที่ช่อง **โค้ดส่วนลด** พิมพ์โค้ด เช่น `NEWYEAR100` แล้วกด **ใช้โค้ด**
3. ระบบหักส่วนลดจากยอดสินค้าทันที และแสดงยอดใหม่ก่อนกดยืนยัน

## เงื่อนไขของโค้ดส่วนลด

- ใช้ได้ 1 โค้ดต่อคำสั่งซื้อ
- โค้ดส่วนลดลดได้เฉพาะค่าสินค้า ไม่รวมค่าส่ง
- โค้ดที่หมดอายุจะขึ้นข้อความ "โค้ดนี้หมดอายุแล้ว" ใต้ช่องกรอก

## ดูโค้ดส่วนลดที่มีอยู่

เข้าเมนู **บัญชีของฉัน > โค้ดส่วนลดของฉัน** จะเห็นโค้ดที่ยังใช้ได้พร้อมวันหมดอายุ
