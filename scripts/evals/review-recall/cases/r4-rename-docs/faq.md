# คำถามที่พบบ่อย เรื่องส่วนลด

**ถาม:** โค้ดส่วนลดใช้กับสินค้าลดราคาได้ไหม
**ตอบ:** ได้ ยกเว้นสินค้าที่ติดป้าย "ราคาพิเศษสุด"

**ถาม:** ใช้โค้ดส่วนลดหลายโค้ดในคำสั่งซื้อเดียวได้ไหม
**ตอบ:** ไม่ได้ ใช้ได้ 1 โค้ดต่อคำสั่งซื้อ

**ถาม:** กรอกโค้ดแล้วขึ้นว่า "โค้ดนี้หมดอายุแล้ว" ทำอย่างไร
**ตอบ:** โค้ดนั้นเลยวันใช้งานแล้ว ดูโค้ดที่ยังใช้ได้ในเมนู **บัญชีของฉัน > คูปองของฉัน**

**ถาม:** ยกเลิกคำสั่งซื้อแล้ว โค้ดส่วนลดจะได้คืนไหม
**ตอบ:** ได้คืนภายใน 24 ชั่วโมง ถ้าโค้ดยังไม่หมดอายุ

**ถาม:** โค้ดส่วนลดลดค่าส่งได้ไหม
**ตอบ:** ไม่ได้ ลดเฉพาะค่าสินค้า ค่าส่งใช้โค้ดส่งฟรีแยกต่างหาก
