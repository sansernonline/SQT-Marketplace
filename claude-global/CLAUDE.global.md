# กฎประจำตัว — ใช้กับทุกโปรเจกต์

> ไฟล์นี้อยู่ใน context ตลอดเวลา จึงมีแต่กฎที่ต้อง**อยู่ในสายตาตอนกำลังจะพลาด**
> รายละเอียดทั้งหมดอยู่ใน skill ซึ่งโหลดเมื่อจำเป็น

## งบ context

- **อ่านไฟล์เกิน 300 บรรทัด → อ่านเฉพาะช่วง** (`offset`/`limit` หรือ `sed -n`) ไม่ใช่ทั้งไฟล์
- **ต้องเปิดดูเกิน 3 ไฟล์เพื่อตอบคำถามเดียว → ส่ง subagent ไปแทน** แล้วรับกลับมาแค่ข้อสรุป
- **`grep`/`rg` ต้องจำกัดขอบเขตเสมอ** — ใส่ `--glob` และปิดท้ายด้วย `| head -50`
- **ผลลัพธ์กลางทางเขียนลงไฟล์** ใน `_to_delete/` แล้วอ่านเฉพาะส่วนที่ใช้ ไม่ถือทั้งก้อนไว้ในบทสนทนา
- ก่อนรันคำสั่งที่อาจได้ output ยาว ให้ `wc -l` ดูขนาดก่อน

รายละเอียดและข้อยกเว้น → skill `context-budget`

## การตอบ

- คำตอบขึ้นก่อน ไม่เกริ่น ไม่ทวนคำถาม
- เทียบของตั้งแต่ 2 อย่างขึ้นไป = ตาราง
- ตัวย่อทุกตัวเขียนเต็มครั้งแรก แล้ววงเล็บตัวย่อไว้

## ไฟล์

- ของชั่วคราวทุกอย่างลง `_to_delete/` ที่รากโปรเจกต์ — ห้ามวางปนกับไฟล์งาน
- ไม่ลบไฟล์ของผู้ใช้โดยไม่ถาม
